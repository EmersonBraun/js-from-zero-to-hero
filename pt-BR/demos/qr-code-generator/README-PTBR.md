# Gerador de QR Code

> [versão em inglês](README.md)

Um gerador de QR Code simples e poderoso construído com JavaScript vanilla. Gere QR codes para URLs, texto, informações de contato e muito mais.

![Gerador de QR Code](gifs/class.gif)

## AULA

Funcionalidade básica de geração de QR Code:
- Insira texto ou URL para gerar QR code
- Interface limpa e moderna
- Design responsivo
- Funcionalidades de gerar e limpar

### Recursos:
- Geração de QR code em tempo real
- Suporte para qualquer texto ou URL
- UI limpa e moderna com fundo gradiente
- Design responsivo para mobile
- Suporte à tecla Enter para geração rápida

## DESAFIO 01

Gerador de QR Code aprimorado com recursos adicionais:
- Seleção de tamanho (Pequeno, Médio, Grande)
- Funcionalidade de download
- Experiência do usuário melhorada

### Novos Recursos:
- Múltiplas opções de tamanho (128px, 200px, 256px)
- Download do QR code como imagem PNG
- Melhores estados dos botões e feedback
- Estilização e layout aprimorados

![Desafio 1](gifs/challenge-1.gif)

## DESAFIO 02

Gerador de QR Code avançado com recursos profissionais:
- Personalização de cores (primeiro plano e fundo)
- Níveis de correção de erro
- Funcionalidade de copiar para área de transferência
- Mensagens de status e feedback

### Recursos Avançados:
- Cores personalizadas de primeiro plano e fundo
- Níveis de correção de erro (L, M, Q, H)
- Copiar QR code para área de transferência
- Mensagens de status em tempo real
- Regeração automática ao alterar cores
- Opção de tamanho extra grande (320px)

![Desafio 2](gifs/challenge-2.gif)

## Tecnologias Utilizadas

- HTML5
- CSS3 (com gradientes modernos e animações)
- JavaScript Vanilla (ES6+)
- Biblioteca QRCode.js para geração de QR code

## Como Usar

1. Abra `index.html` no seu navegador
2. Digite qualquer texto ou URL no campo de entrada
3. Clique em "Generate QR Code" ou pressione Enter
4. Use o QR code gerado ou faça o download
