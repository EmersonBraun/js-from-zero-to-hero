Timers & Animações

JavaScript pode agendar código para executar no futuro, repetir em um intervalo e sincronizar com o ciclo de renderização do navegador. Essas capacidades são a base de contadores regressivos, jogos e animações suaves.

Teoria​

setTimeout​

setTimeout agenda uma função para executar uma vez após um atraso (em milissegundos).

const id = setTimeout(() => {
  console.log("This runs after 2 seconds");
}, 2000);

// Cancelar antes de disparar:
clearTimeout(id);

O callback é colocado na fila de tarefas após o atraso e executa quando a pilha de chamadas está vazia — portanto os atrasos são tempos mínimos, não garantidos.

Referência MDN: setTimeout

setInterval​

setInterval chama uma função repetidamente em um intervalo fixo.

let count = 0;
const id = setInterval(() => {
  count++;
  console.log(`Tick ${count}`);
  if (count === 5) clearInterval(id);
}, 1000);

Sempre armazene o ID para poder parar o intervalo com clearInterval quando terminar — esquecer de limpar é uma fonte comum de vazamento de memória.

Referência MDN: setInterval

clearTimeout e clearInterval​

Tanto clearTimeout quanto clearInterval aceitam o ID numérico retornado por suas respectivas funções de agendamento.

const timerId = setTimeout(fn, 5000);
clearTimeout(timerId); // fn nunca executa

const intervalId = setInterval(fn, 500);
clearInterval(intervalId); // para as chamadas repetidas

requestAnimationFrame​

requestAnimationFrame (rAF) agenda um callback para executar antes do próximo repaint, aproximadamente 60 vezes por segundo (a cada ~16,7 ms). É a ferramenta preferida para animações porque:

  • Pausa quando a aba está oculta (economiza CPU/bateria).
  • Sincroniza com a taxa de atualização do display.
  • Evita a tremulação visual que setInterval pode causar.
function animate(timestamp) {
  // timestamp é um DOMHighResTimeStamp
  draw(timestamp);
  requestAnimationFrame(animate); // agendando o próximo frame
}
requestAnimationFrame(animate); // iniciando o loop

Para parar um loop rAF, chame cancelAnimationFrame(id) com o ID retornado.

Referência MDN: requestAnimationFrame

Animações CSS Disparadas por JavaScript​

Você pode iniciar animações CSS alternando classes com JavaScript:

/* style.css */
.ball {
  transition: transform 0.5s ease;
}
.ball.jump {
  transform: translateY(-150px);
}
const ball = document.querySelector(".ball");
ball.classList.add("jump");

setTimeout(() => ball.classList.remove("jump"), 500);

Para sequências mais complexas, a Web Animations API permite controlar animações inteiramente pelo JS:

element.animate(
  [{ transform: "translateY(0)" }, { transform: "translateY(-150px)" }],
  { duration: 400, easing: "ease-out", fill: "forwards" }
);

Referência MDN: Web Animations API

Game Loops​

Um game loop atualiza o estado e redesenha a tela o mais rápido possível. Usar requestAnimationFrame fornece um loop suave e eficiente em termos de bateria:

let lastTime = 0;

function gameLoop(timestamp) {
  const delta = timestamp - lastTime; // tempo desde o último frame (ms)
  lastTime = timestamp;

  update(delta); // mover objetos, verificar colisões
  render();      // desenhar tudo

  requestAnimationFrame(gameLoop);
}

requestAnimationFrame(gameLoop);

Usar delta (tempo decorrido) em vez de um passo fixo torna o jogo independente da taxa de frames — ele roda na mesma velocidade em um display de 60 Hz e de 120 Hz.

Projeto 1: Timer de Contagem Regressiva​

Um timer de contagem regressiva visual que mostra minutos e segundos, com controles de iniciar, pausar e reiniciar.

Demonstração ao Vivo​

Como Funciona​

O estado do timer é um objeto simples atualizado por setInterval:

let intervalId = null;
let remaining = 0; // seconds

function start() {
  if (intervalId) return; // already running
  intervalId = setInterval(() => {
    if (remaining <= 0) {
      clearInterval(intervalId);
      intervalId = null;
      onFinish();
      return;
    }
    remaining--;
    render();
  }, 1000);
}

function pause() {
  clearInterval(intervalId);
  intervalId = null;
}

function reset(seconds) {
  pause();
  remaining = seconds;
  render();
}

function render() {
  const m = String(Math.floor(remaining / 60)).padStart(2, "0");
  const s = String(remaining % 60).padStart(2, "0");
  display.textContent = `${m}:${s}`;
}

Pontos-chave:

  • Armazene o ID do intervalo para poder limpá-lo.
  • Rastreie remaining separadamente do display.
  • padStart(2, "0") garante formatação de dois dígitos.

Desafio 1 – Som de Alarme​

Quando o timer chegar a zero, reproduza um bipe curto usando a Web Audio API em vez de um alert estático. Use AudioContext para gerar um tom de 440 Hz por 0,3 segundos.

Desafio 2 – Modo Pomodoro​

Implemente um timer Pomodoro: 25 minutos de trabalho seguidos de uma pausa de 5 minutos, ciclando automaticamente. Rastreie o número de Pomodoros completos.

Projeto 2: Mario Jump​

Um jogo de plataforma com rolagem lateral em que Mario deve pular sobre obstáculos. Construído com requestAnimationFrame e alternância de classes CSS.

Demonstração ao Vivo​

Como Funciona​

const mario = document.querySelector(".mario");
const obstacle = document.querySelector(".obstacle");

let gameOver = false;
let animationId;

function jump() {
  if (mario.classList.contains("jump")) return;
  mario.classList.add("jump");
  setTimeout(() => mario.classList.remove("jump"), 500);
}

function checkCollision() {
  const marioRect = mario.getBoundingClientRect();
  const obstacleRect = obstacle.getBoundingClientRect();
  return (
    marioRect.right > obstacleRect.left &&
    marioRect.left < obstacleRect.right &&
    marioRect.bottom > obstacleRect.top &&
    marioRect.top < obstacleRect.bottom
  );
}

function gameLoop() {
  if (checkCollision()) {
    gameOver = true;
    obstacle.style.animation = "none";
    return;
  }
  animationId = requestAnimationFrame(gameLoop);
}

document.addEventListener("keydown", (e) => {
  if (e.code === "Space" && !gameOver) jump();
});

requestAnimationFrame(gameLoop);

O movimento horizontal do obstáculo é tratado por uma animação de keyframe CSS, mantendo o loop JS focado puramente na detecção de colisões.

Desafio 1 – Pulo Duplo​

Permita que Mario pule uma segunda vez enquanto estiver no ar (pulo duplo). Rastreie a contagem de pulos com uma variável e redefina-a quando Mario aterrissar.

Desafio 2 – Contador de Pontuação​

Adicione uma pontuação ao vivo que aumenta a cada segundo que o jogador sobrevive. Mostre a pontuação máxima no localStorage para que persista entre sessões.

Resumo​

  • setTimeout executa código uma vez após um atraso; sempre armazene e limpe o ID quando terminar.
  • setInterval repete código em um agendamento fixo; sempre limpe-o para evitar vazamentos de memória.
  • requestAnimationFrame é a ferramenta certa para animações e game loops — sincroniza com a tela, pausa quando a aba está oculta e evita tremulação.
  • Alternar classes CSS é uma forma limpa de disparar transições e animações de keyframe CSS a partir do JavaScript.
  • Delta time torna os game loops independentes da taxa de frames: multiplique as velocidades pelo tempo decorrido em vez de um passo fixo.
  • O padrão debounce (construído sobre setTimeout) evita que uma função que dispara rapidamente execute até que o usuário faça uma pausa.
