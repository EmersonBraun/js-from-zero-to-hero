# Operators & Conditionals

In this module you will learn how to perform calculations, compare values, and make decisions in your code. These are the building blocks that make programs dynamic and interactive.

## Arithmetic Operators

JavaScript supports all basic math operations:

| Operator | Name | Example | Result |
|---|---|---|---|
| `+` | Addition | `5 + 3` | `8` |
| `-` | Subtraction | `10 - 4` | `6` |
| `*` | Multiplication | `3 * 7` | `21` |
| `/` | Division | `20 / 4` | `5` |
| `%` | Modulo (remainder) | `10 % 3` | `1` |
| `**` | Exponentiation | `2 ** 3` | `8` |

The **modulo operator** (`%`) returns the remainder of a division. It is very useful for checking if a number is even or odd:

```javascript
10 % 2  // 0 → even (no remainder)
7 % 2   // 1 → odd (remainder of 1)
```

> **MDN Reference:** [Arithmetic operators](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Operators#arithmetic_operators)

## Comparison Operators

Comparison operators compare two values and return a **boolean** (`true` or `false`):

| Operator | Meaning | Example | Result |
|---|---|---|---|
| `===` | Strict equality | `5 === 5` | `true` |
| `!==` | Strict inequality | `5 !== 3` | `true` |
| `>` | Greater than | `10 > 5` | `true` |
| `<` | Less than | `3 < 7` | `true` |
| `>=` | Greater than or equal | `5 >= 5` | `true` |
| `<=` | Less than or equal | `3 <= 2` | `false` |

### `===` vs `==`

JavaScript has two equality operators:

- **`===` (strict equality)** — compares both value AND type. **Always use this.**
- **`==` (loose equality)** — compares values with type coercion (can produce unexpected results)

```javascript
5 === 5      // true (same value, same type)
5 === "5"    // false (different types: number vs string)
5 == "5"     // true (loose: converts string to number!)
```

**Rule of thumb:** Always use `===` and `!==` to avoid bugs caused by type coercion.

> **MDN Reference:** [Comparison operators](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Operators/Comparison_Operators)

## Logical Operators

Logical operators combine boolean expressions:

| Operator | Name | Description |
|---|---|---|
| `&&` | AND | `true` if BOTH sides are true |
| `\|\|` | OR | `true` if AT LEAST ONE side is true |
| `!` | NOT | Inverts the boolean value |

```javascript
true && true    // true
true && false   // false
true || false   // true
false || false  // false
!true           // false
!false          // true
```

Practical example:

```javascript
let age = 25;
let hasLicense = true;

// Can drive: must be 18+ AND have a license
let canDrive = age >= 18 && hasLicense;  // true
```

> **MDN Reference:** [Logical operators](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Operators/Logical_AND)

## `if / else` Statements

The `if` statement executes code only when a condition is `true`:

```javascript
let temperature = 35;

if (temperature > 30) {
  console.log("It's hot outside!");
}
```

Add an `else` block for when the condition is `false`:

```javascript
let temperature = 15;

if (temperature > 30) {
  console.log("It's hot outside!");
} else {
  console.log("It's not that hot.");
}
```

Use `else if` for multiple conditions:

```javascript
let temperature = 15;

if (temperature > 30) {
  console.log("It's hot!");
} else if (temperature > 20) {
  console.log("It's warm.");
} else if (temperature > 10) {
  console.log("It's cool.");
} else {
  console.log("It's cold!");
}
```

> **MDN Reference:** [if...else](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Statements/if...else)

## `switch` Statement

When you need to compare one value against many options, `switch` is cleaner than multiple `if/else if`:

```javascript
let day = "Monday";

switch (day) {
  case "Monday":
    console.log("Start of the week");
    break;
  case "Friday":
    console.log("Almost weekend!");
    break;
  case "Saturday":
  case "Sunday":
    console.log("Weekend!");
    break;
  default:
    console.log("Regular day");
}
```

**Important:** Don't forget the `break` statement! Without it, execution "falls through" to the next case.

> **MDN Reference:** [switch](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Statements/switch)

## Ternary Operator

The ternary operator is a shorthand for simple `if/else` statements:

```javascript
// Syntax: condition ? valueIfTrue : valueIfFalse

let age = 20;
let status = age >= 18 ? "adult" : "minor";
// status is "adult"
```

This is equivalent to:

```javascript
let status;
if (age >= 18) {
  status = "adult";
} else {
  status = "minor";
}
```

The ternary operator is great for short, simple conditions. For complex logic, stick with `if/else`.

> **MDN Reference:** [Conditional (ternary) operator](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Operators/Conditional_operator)

## Project: Switch Light

Now let's apply what you learned to a real project! **Switch Light** is an interactive light bulb that responds to mouse events using conditionals.

### How It Works

The project has a light bulb image that changes based on user interaction:

- **Hover** over the bulb → light turns ON
- **Move mouse away** → light turns OFF
- **Click** the bulb → light BREAKS (and stays broken)

The core logic uses **conditionals** and **boolean flags** to control the state:

```javascript
let broken = false;

function changeLight(element, type) {
  // If already broken, do nothing (early return with conditional)
  if (broken === true) return;

  element.srcElement.src = `images/light-${type}.png`;

  if (type === 'broken') {
    broken = true;  // Once broken, it stays broken
  }
}
```

Key concepts demonstrated:
- **Boolean variables** (`broken`) to track state
- **`if` statements** for conditional logic and early returns
- **Template literals** for dynamic strings
- **Event listeners** (`mouseenter`, `mouseleave`, `click`) for user interaction

### Step-by-Step Walkthrough

**1. HTML Structure**

The HTML is simple — an image and a button:

```html
<div class="container">
  <div class="box">
    <img id="light" src="images/light-off.png" alt="light">
  </div>
  <div class="box">
    <button id="btn" class="button" onclick="toogleType()">NORMAL</button>
  </div>
</div>
<script src="index.js"></script>
```

**2. State Variables**

Three variables track the current state of the light:

```javascript
let broken = false;  // Is the light broken?
let on = true;       // Is the light currently on?
let type = 'NORMAL'; // Current mode: NORMAL or SWITCH
```

**3. Event Listeners**

The light image listens for three events:

```javascript
const light = document.getElementById('light');

light.addEventListener('mouseenter', (element) => changeLight(element, 'on'));
light.addEventListener('mouseleave', (element) => changeLight(element, 'off'));
light.addEventListener('click', (element) => {
  if (type === 'NORMAL') {
    changeLight(element, 'broken');
  } else {
    toogleLight(element);
  }
});
```

Notice how the `click` handler uses an **`if/else`** to decide behavior based on the current mode.

**4. The Ternary Operator in Action**

The mode toggle button uses a **ternary operator**:

```javascript
function toogleType() {
  type = type === 'NORMAL' ? 'SWITCH' : 'NORMAL';
  document.getElementById('btn').textContent = type;
  broken = false;
}
```

**5. Conditional Early Return**

The `changeLight` function uses an early return pattern with conditionals:

```javascript
function changeLight(element, tipo) {
  if (broken === true || type === 'SWITCH') return;
  element.srcElement.src = `images/light-${tipo}.png`;
  if (tipo === 'broken') {
    broken = true;
  }
}
```

The `||` (OR) operator combines two conditions: if the light is broken OR the mode is SWITCH, do nothing.
