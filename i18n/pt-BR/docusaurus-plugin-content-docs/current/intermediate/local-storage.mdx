# Local Storage & Persistência de Dados

Navegadores modernos fornecem APIs de armazenamento integradas que permitem que suas aplicações JavaScript se lembrem de dados entre recarregamentos de página e sessões do navegador — sem precisar de um servidor ou banco de dados. Neste módulo você vai dominar `localStorage`, `sessionStorage` e os padrões de serialização JSON necessários para armazenar dados complexos.

**Referências MDN:**
- [Window.localStorage](https://developer.mozilla.org/en-US/docs/Web/API/Window/localStorage)
- [Window.sessionStorage](https://developer.mozilla.org/en-US/docs/Web/API/Window/sessionStorage)

## Teoria

### A API localStorage

`localStorage` é um armazenamento chave-valor vinculado à origem atual (protocolo + hostname + porta). Os dados persistem indefinidamente até serem explicitamente limpos.

```js
// Armazenar um valor
localStorage.setItem('username', 'Alice');

// Recuperar um valor (retorna null se a chave não existir)
const name = localStorage.getItem('username'); // 'Alice'

// Remover uma chave específica
localStorage.removeItem('username');

// Limpar TODAS as chaves desta origem
localStorage.clear();

// Verificar quantas chaves estão armazenadas
console.log(localStorage.length);

// Iterar sobre todas as chaves
for (let i = 0; i < localStorage.length; i++) {
  const key = localStorage.key(i);
  const value = localStorage.getItem(key);
  console.log(key, value);
}
```

> **Importante:** `localStorage` armazena apenas strings. Para armazenar objetos ou arrays, você deve serializá-los.

---

### JSON.stringify e JSON.parse

Como `localStorage` aceita apenas strings, `JSON.stringify` converte objetos/arrays para strings JSON, e `JSON.parse` os converte de volta:

```js
// Armazenando um objeto
const user = { name: 'Alice', age: 30, hobbies: ['coding', 'reading'] };
localStorage.setItem('user', JSON.stringify(user));

// Recuperando e fazendo parse
const stored = localStorage.getItem('user');
const parsed = JSON.parse(stored);
console.log(parsed.name); // 'Alice'

// Parse seguro (trata null e JSON malformado)
function safeGet(key, defaultValue = null) {
  try {
    const item = localStorage.getItem(key);
    return item !== null ? JSON.parse(item) : defaultValue;
  } catch (e) {
    return defaultValue;
  }
}
```

### Padrões CRUD

Um padrão padrão para gerenciar uma coleção em `localStorage`:

```js
const STORAGE_KEY = 'my-todos';

// Criar — adicionar um novo item
function createItem(text) {
  const items = readAll();
  const newItem = { id: Date.now(), text, done: false, createdAt: new Date().toISOString() };
  items.push(newItem);
  localStorage.setItem(STORAGE_KEY, JSON.stringify(items));
  return newItem;
}

// Ler — obter todos os itens
function readAll() {
  const raw = localStorage.getItem(STORAGE_KEY);
  return raw ? JSON.parse(raw) : [];
}

// Atualizar — alternar status done
function updateItem(id, changes) {
  const items = readAll();
  const updated = items.map(item => item.id === id ? { ...item, ...changes } : item);
  localStorage.setItem(STORAGE_KEY, JSON.stringify(updated));
}

// Deletar — remover por id
function deleteItem(id) {
  const items = readAll().filter(item => item.id !== id);
  localStorage.setItem(STORAGE_KEY, JSON.stringify(items));
}
```

### Estratégias de Persistência de Dados

Ao projetar aplicações com `localStorage`, considere:

- **Versionamento:** Armazene uma chave `_version` junto com seus dados. Se a versão armazenada diferir da versão da aplicação, migre ou redefina os dados.
- **Cota:** `localStorage` é tipicamente limitado a ~5MB por origem. Armazene apenas o necessário.
- **Expiração:** `localStorage` não tem TTL integrado. Se precisar de expiração, armazene um timestamp e verifique-o ao ler.

```js
function setWithExpiry(key, value, ttlMs) {
  const item = { value, expiry: Date.now() + ttlMs };
  localStorage.setItem(key, JSON.stringify(item));
}

function getWithExpiry(key) {
  const raw = localStorage.getItem(key);
  if (!raw) return null;
  const item = JSON.parse(raw);
  if (Date.now() > item.expiry) {
    localStorage.removeItem(key);
    return null;
  }
  return item.value;
}
```

---

### sessionStorage vs localStorage

| Característica | `localStorage` | `sessionStorage` |
|---|---|---|
| Persistência | Até ser explicitamente limpo | Até a aba/janela fechar |
| Escopo | Todas as abas da mesma origem | Apenas uma aba |
| Capacidade | ~5MB | ~5MB |
| API | Idêntica | Idêntica |

Use `sessionStorage` para estado temporário como rascunhos de formulários ou etapas de um wizard onde você não quer que os dados persistam entre sessões.

### Projeto 1: Lista de Tarefas com Persistência

Uma aplicação de tarefas completa que lembra suas tarefas entre recarregamentos de página usando `localStorage`.

**Conceitos-chave:** Operações CRUD, serialização JSON, delegação de eventos, renderização dinâmica do DOM a partir do estado armazenado.

#### Como Funciona

Na carga da página, as tarefas são lidas do `localStorage` e renderizadas no DOM. Cada mutação (adicionar, alternar, deletar) atualiza tanto o DOM quanto o `localStorage` imediatamente.

```js
const STORAGE_KEY = 'js-hero-todos';

function loadTodos() {
  return JSON.parse(localStorage.getItem(STORAGE_KEY) || '[]');
}

function saveTodos(todos) {
  localStorage.setItem(STORAGE_KEY, JSON.stringify(todos));
}

function renderTodo(todo, listEl) {
  const li = document.createElement('li');
  li.dataset.id = todo.id;
  if (todo.done) li.classList.add('done');

  const span = document.createElement('span');
  span.textContent = todo.text;

  const toggleBtn = document.createElement('button');
  toggleBtn.className = 'toggle';
  toggleBtn.textContent = 'Done';

  const deleteBtn = document.createElement('button');
  deleteBtn.className = 'delete';
  deleteBtn.textContent = 'Remove';

  li.append(span, toggleBtn, deleteBtn);
  listEl.appendChild(li);
}

function renderTodos(todos, listEl) {
  listEl.replaceChildren(); // limpar itens existentes com segurança
  todos.forEach(todo => renderTodo(todo, listEl));
}
```

function saveGame(state) {
  localStorage.setItem('memory-game', JSON.stringify(state));
}

function loadGame() {
  try {
    return JSON.parse(localStorage.getItem('memory-game'));
  } catch {
    return null;
  }

#### Como Funciona

Cada dia recebe sua própria chave no `localStorage` baseada na data atual (ex.: `water-2024-03-15`). Chaves antigas são automaticamente limpas na carga.

```js
function getTodayKey() {
  return `water-${new Date().toISOString().split('T')[0]}`;
}

function getIntake() {
  return parseInt(localStorage.getItem(getTodayKey()) || '0', 10);
}

function addCup(ml) {
  const current = getIntake();
  localStorage.setItem(getTodayKey(), String(current + ml));
  updateUI();
}
```

## Resumo

Neste módulo você aprendeu:

- As APIs `localStorage` e `sessionStorage`: `setItem`, `getItem`, `removeItem`, `clear`.
- Por que a serialização JSON é necessária e como usar `JSON.stringify` e `JSON.parse` com segurança.
- Um **padrão CRUD** completo para gerenciar coleções no armazenamento do lado do cliente.
- Estratégias para lidar com cota de armazenamento, expiração de dados com TTL e migrações de schema.
- As principais diferenças entre `localStorage` (persistente, entre abas) e `sessionStorage` (escopo de aba, efêmero).

A persistência de dados é a porta de entrada para aplicações reais. A Lista de Tarefas, o Jogo de Memória e o Rastreador de Água demonstram como a mesma API simples pode alimentar uma ampla variedade de projetos práticos.
