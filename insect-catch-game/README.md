# Insect Catch Game

> [pt-br version](README-PTBR.md)

A fun and interactive insect catching game where players click on insects as fast as they can to score points!

## CLASS

### Features
- **Insect Selection**: Choose from 4 different insects (Fly, Mosquito, Spider, Roach)
- **Real-time Scoring**: Track your score and time as you play
- **Dynamic Gameplay**: Insects appear randomly across the game area
- **Smooth Animations**: Catch animations and hover effects
- **Responsive Design**: Works on desktop and mobile devices

### Controls
- **Mouse Click**: Click on insects to catch them
- **Start Button**: Begin the game after selecting an insect
- **Restart Button**: Restart the current game session
- **Play Again**: Return to the main menu after game over

### Game Mechanics
- Insects appear randomly on the screen
- Each caught insect adds 1 point to your score
- Insects disappear after 2 seconds if not caught
- Game continues indefinitely (no time limit)
- Track your performance with real-time score and time display

## How to Play

1. **Select an Insect**: Click on one of the four insect options
2. **Start Game**: Click the "Start Game" button
3. **Catch Insects**: Click on insects as they appear on screen
4. **Track Progress**: Monitor your score and time in real-time
5. **Restart or Play Again**: Use buttons to restart or return to menu
