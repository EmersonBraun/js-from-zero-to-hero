# DOM Basics

The **DOM** (Document Object Model) is how JavaScript interacts with HTML. When a browser loads a page, it creates a tree-like structure of all the elements — that tree is the DOM. JavaScript can read, modify, add, and remove any part of it.

## Selecting Elements

### `getElementById`

Select an element by its `id` attribute:

```javascript
const title = document.getElementById("title");
console.log(title.textContent);  // The text inside the element
```

### `querySelector`

Select the **first** element matching a CSS selector:

```javascript
const paragraph = document.querySelector("p");          // First <p>
const box = document.querySelector(".box");             // First .box
const btn = document.querySelector("#submit-btn");       // Element with id
const nested = document.querySelector(".card > h2");     // Nested selector
```

### `querySelectorAll`

Select **all** elements matching a CSS selector (returns a NodeList):

```javascript
const allButtons = document.querySelectorAll("button");
allButtons.forEach(btn => console.log(btn.textContent));
```

> **MDN Reference:** [querySelector](https://developer.mozilla.org/en-US/docs/Web/API/Document/querySelector)

## Modifying Elements

### Text Content

```javascript
const heading = document.getElementById("title");
heading.textContent = "New Title";  // Change the text
```

### CSS Styles

```javascript
const box = document.querySelector(".box");
box.style.backgroundColor = "blue";
box.style.color = "white";
box.style.padding = "20px";
```

### CSS Classes

```javascript
const element = document.querySelector(".card");
element.classList.add("active");     // Add a class
element.classList.remove("hidden");  // Remove a class
element.classList.toggle("open");    // Toggle a class on/off
element.classList.contains("active"); // Check if class exists → true/false
```

### Attributes

```javascript
const link = document.querySelector("a");
link.setAttribute("href", "https://example.com");
link.getAttribute("href");  // "https://example.com"
link.removeAttribute("target");
```

> **MDN Reference:** [Element](https://developer.mozilla.org/en-US/docs/Web/API/Element)

## Event Listeners

Events are things that happen in the browser: clicks, key presses, mouse movements, form submissions. You use `addEventListener` to react to them:

```javascript
const button = document.querySelector("#myBtn");

button.addEventListener("click", function() {
  console.log("Button clicked!");
});
```

### Common Events

| Event | Triggers When |
|---|---|
| `click` | Element is clicked |
| `dblclick` | Element is double-clicked |
| `mouseenter` | Mouse enters the element |
| `mouseleave` | Mouse leaves the element |
| `keydown` | A key is pressed |
| `keyup` | A key is released |
| `input` | Input value changes |
| `submit` | Form is submitted |
| `load` | Page finishes loading |

### The Event Object

Event listeners receive an **event object** with information about what happened:

```javascript
document.addEventListener("keydown", function(event) {
  console.log(event.key);     // The key that was pressed ("a", "Enter", etc.)
  console.log(event.code);    // Physical key code ("KeyA", "Enter")
  console.log(event.keyCode); // Numeric key code (deprecated but common)
});

button.addEventListener("click", function(event) {
  console.log(event.target);  // The element that was clicked
});
```

> **MDN Reference:** [addEventListener](https://developer.mozilla.org/en-US/docs/Web/API/EventTarget/addEventListener)

## Creating and Removing Elements

### Creating Elements

```javascript
const newParagraph = document.createElement("p");
newParagraph.textContent = "I was created by JavaScript!";
newParagraph.classList.add("highlight");

document.body.appendChild(newParagraph);  // Add to end of body
```

### Removing Elements

```javascript
const element = document.querySelector("#old-element");
element.remove();
```

## Project: Event Keycodes

The **Event Keycodes** project is a keyboard event inspector that shows key information in real-time when you press any key. It demonstrates event listeners, the event object, and DOM manipulation.

### Key Concepts

```javascript
document.addEventListener('keydown', function(e) {
  e.preventDefault();

  // Access event properties
  const keyData = {
    key: e.key,        // "a", "Enter", "Shift"
    code: e.code,      // "KeyA", "Enter", "ShiftLeft"
    keyCode: e.keyCode // 65, 13, 16 (numeric, deprecated)
  };

  // Update the DOM with the key information
  document.getElementById('keyValue').textContent = keyData.key;
  document.getElementById('keyCode').textContent = keyData.code;
  document.getElementById('keyCodeNumber').textContent = keyData.keyCode;
});
```

## Project: Progress Steps

The **Progress Steps** project demonstrates DOM manipulation with a multi-step form. It uses `classList`, style manipulation, and event listeners to create an interactive step-by-step wizard.

### Key Concepts

```javascript
const circles = document.querySelectorAll('.circle');
let currentActive = 1;

// Update visual state of step circles
function updateCircles() {
  circles.forEach((circle, index) => {
    if (index < currentActive) {
      circle.classList.add('active');
    } else {
      circle.classList.remove('active');
    }
  });
}

// Update progress bar width
function updateProgress() {
  const progressPercent = ((currentActive - 1) / (circles.length - 1)) * 100;
  document.getElementById('progress').style.width = progressPercent + '%';
}
```
