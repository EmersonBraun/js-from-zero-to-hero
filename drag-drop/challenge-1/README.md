# Drag and Drop - Challenge 1

> [pt-br version](README-PTBR.md)

A modern file upload interface with drag and drop functionality, file validation, and preview capabilities.

## CLASS

Basic drag and drop file upload with:
- Drag and drop file upload
- File validation and size limits
- File preview and information display
- Download functionality
- Modal file preview
- Status messages and feedback

## CHALLENGE 01

Implement a complete drag and drop file upload system:

### Requirements:
- [x] **Drag and Drop Interface**: Visual drag area with hover effects
- [x] **File Validation**: Check file size, type, and count limits
- [x] **File Information Display**: Show file details in a grid layout
- [x] **File Previews**: Thumbnail previews for images and icons for documents
- [x] **Modal Preview**: Click to view full file content in modal
- [x] **File Management**: Remove individual files or clear all
- [x] **Download Functionality**: Download all files individually
- [x] **Status Messages**: User feedback for all actions
- [x] **Responsive Design**: Works on all screen sizes

### Features:
- **Multiple File Support**: Upload multiple files at once
- **File Type Validation**: Images, PDFs, documents, and text files
- **Size Limits**: Configurable maximum file size (default 10MB)
- **Visual Feedback**: Drag over effects and hover animations
- **File Icons**: Appropriate icons for different file types
- **Text Preview**: Read text files directly in the modal
- **Image Preview**: Full-size image viewing
- **Error Handling**: Clear error messages for invalid files

### Supported File Types:
- **Images**: All image formats (jpg, png, gif, etc.)
- **Documents**: PDF, DOC, DOCX
- **Text Files**: TXT files with preview
- **Others**: Generic file icon for unsupported types

### Controls:
- **Drag & Drop**: Drag files directly onto the upload area
- **Click to Browse**: Click upload area to open file dialog
- **Remove Files**: Individual remove buttons on file items
- **Clear All**: Remove all uploaded files
- **Download All**: Download each file individually
- **Preview**: Click file previews to open modal
