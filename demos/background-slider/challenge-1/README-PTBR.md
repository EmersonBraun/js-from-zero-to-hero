# Background Slider - Challenge 1

> [versão em inglês](README.md)

Um slider de imagens de fundo dinâmico com transições suaves e controles interativos.

## CLASS

Slider básico com:
- Múltiplas imagens de fundo
- Transições suaves de fade
- Setas de navegação
- Indicadores de pontos
- Funcionalidade de reprodução automática
- Controles de play/pause
- Modo tela cheia
- Navegação por teclado
- Suporte a toque/deslizar

## CHALLENGE 01

Aprimore o slider básico com:

### Requisitos:
- [x] **Transições Suaves**: Implementar transições fade entre slides
- [x] **Controles de Navegação**: Adicionar botões anterior/próximo e indicadores de pontos
- [x] **Reprodução Automática**: Progressão automática de slides com toggle play/pause
- [x] **Informações do Slide**: Exibir número e título do slide atual
- [x] **Modo Tela Cheia**: Alternar visualização em tela cheia
- [x] **Suporte ao Teclado**: Teclas de seta para navegação, espaço para play/pause
- [x] **Suporte ao Toque**: Gestos de deslizar para dispositivos móveis
- [x] **Design Responsivo**: Funciona em todos os tamanhos de tela

### Funcionalidades:
- **5 Imagens de Fundo Bonitas**: Paisagens de montanha, florestas, oceanos, pôr do sol e desertos
- **Controles Interativos**: Navegação por clique, atalhos de teclado e gestos de toque
- **Feedback Visual**: Indicadores de pontos ativos e contador de slides
- **Animações Suaves**: Transições CSS para aparência profissional
- **Otimizado para Mobile**: Interface amigável ao toque com suporte a deslizar

### Controles:
- **Mouse**: Clique nas setas, pontos ou botões de controle
- **Teclado**: 
  - Seta Esquerda/Direita: Navegar slides
  - Espaço: Play/pause reprodução automática
  - F: Alternar tela cheia
- **Toque**: Deslizar esquerda/direita para navegar
