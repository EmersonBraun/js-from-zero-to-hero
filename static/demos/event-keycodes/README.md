# Event Keycodes

> [pt-br version](README-PTBR.md)

An interactive keyboard event inspector that displays key information, codes, and provides visual feedback.

![Event Keycodes](gifs/class.gif)

## CLASS

### Features

- **Real-time Key Detection**: Display key information as you type
- **Multiple Event Types**: Monitor keydown, keyup, and keypress events
- **Visual Keyboard Layout**: Interactive keyboard with pressed key highlighting
- **Key History**: Track and display recent key presses
- **Copy Functionality**: Copy key information to clipboard
- **Display Modes**: Simple, detailed, and history views
- **Keyboard Shortcuts**: Quick access to common functions
- **Responsive Design**: Works on desktop and mobile devices

### How to Use

1. **Press Any Key**: See real-time key information displayed
2. **View Details**: Check key, code, and keyCode values
3. **Switch Event Types**: Choose between keydown, keyup, and keypress
4. **Browse History**: View recent key presses in history mode
5. **Use Keyboard**: Click on virtual keyboard keys
6. **Copy Information**: Copy last pressed key details

### Keyboard Shortcuts

- `Any Key`: Display key information
- `Ctrl+C`: Copy last key information
- `Escape`: Reset display
- `Arrow Keys`: Navigate through options

### Key Information Displayed

- **Key**: The actual character or key name
- **Code**: The physical key code (e.g., "KeyA", "Space")
- **Key Code**: The numeric key code (deprecated but shown for reference)

### Technologies Used

- HTML5
- CSS3 (with animations and visual effects)
- Vanilla JavaScript
- Local Storage API
- Google Fonts (Roboto)
