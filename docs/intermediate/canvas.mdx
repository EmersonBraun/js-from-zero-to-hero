# Canvas API

The HTML5 Canvas element provides a powerful 2D drawing surface that you can control entirely with JavaScript. From simple shapes to complex animations and even pixel manipulation, the Canvas API is a cornerstone of browser-based graphics.

**MDN References:**
- [HTMLCanvasElement](https://developer.mozilla.org/en-US/docs/Web/API/HTMLCanvasElement)
- [CanvasRenderingContext2D](https://developer.mozilla.org/en-US/docs/Web/API/CanvasRenderingContext2D)
- [requestAnimationFrame](https://developer.mozilla.org/en-US/docs/Web/API/window/requestAnimationFrame)

---

## Theory

### Getting Started with Canvas

The `<canvas>` element is just a blank drawing surface. You gain access to its drawing context via `getContext('2d')`:

```js
const canvas = document.getElementById('myCanvas');
const ctx = canvas.getContext('2d');
```

The coordinate system starts at the top-left corner `(0, 0)`, with `x` increasing to the right and `y` increasing downward.

---

### Drawing Rectangles

Rectangles are the simplest shape on canvas:

```js
// Filled rectangle
ctx.fillStyle = 'blue';
ctx.fillRect(x, y, width, height);

// Outlined rectangle
ctx.strokeStyle = 'red';
ctx.lineWidth = 2;
ctx.strokeRect(x, y, width, height);

// Clear a rectangular area
ctx.clearRect(x, y, width, height);
```

---

### Paths, Lines, and Arcs

Most complex shapes are built using paths:

```js
ctx.beginPath();
ctx.moveTo(50, 50);       // Move to start point without drawing
ctx.lineTo(200, 50);      // Draw a line to this point
ctx.lineTo(200, 150);
ctx.closePath();           // Close the path back to the start
ctx.stroke();              // Render the path outline

// Circles and arcs
ctx.beginPath();
ctx.arc(x, y, radius, startAngle, endAngle, anticlockwise);
// Full circle: startAngle = 0, endAngle = Math.PI * 2
ctx.fill();
```

---

### Fill and Stroke Styles

You can use colors, gradients, and patterns as fill or stroke styles:

```js
// Solid color
ctx.fillStyle = '#ff6347';

// Linear gradient
const gradient = ctx.createLinearGradient(0, 0, 200, 0);
gradient.addColorStop(0, 'red');
gradient.addColorStop(1, 'blue');
ctx.fillStyle = gradient;

// Radial gradient
const radial = ctx.createRadialGradient(75, 50, 5, 75, 50, 100);
radial.addColorStop(0, 'white');
radial.addColorStop(1, 'black');
ctx.fillStyle = radial;
```

---

### Drawing Text

Canvas supports rendering text with full style control:

```js
ctx.font = '30px Arial';
ctx.fillStyle = 'black';
ctx.textAlign = 'center';    // 'left' | 'right' | 'center' | 'start' | 'end'
ctx.textBaseline = 'middle'; // 'top' | 'middle' | 'bottom' | 'alphabetic'

ctx.fillText('Hello, Canvas!', x, y);
ctx.strokeText('Outlined Text', x, y);

// Measure text width
const metrics = ctx.measureText('Hello');
console.log(metrics.width);
```

---

### Animation with requestAnimationFrame

`requestAnimationFrame` schedules a function to run before the next repaint, enabling smooth 60fps animations:

```js
function animate() {
  ctx.clearRect(0, 0, canvas.width, canvas.height); // Clear previous frame
  // ... draw updated scene ...
  requestAnimationFrame(animate); // Schedule next frame
}

requestAnimationFrame(animate); // Start the loop
```

---

### Pixel Manipulation

You can read and write individual pixels using `ImageData`:

```js
// Get pixel data for the entire canvas
const imageData = ctx.getImageData(0, 0, canvas.width, canvas.height);
const data = imageData.data; // Uint8ClampedArray: [R, G, B, A, R, G, B, A, ...]

// Modify a pixel at (x, y)
const index = (y * canvas.width + x) * 4;
data[index]     = 255; // Red
data[index + 1] = 0;   // Green
data[index + 2] = 0;   // Blue
data[index + 3] = 255; // Alpha

// Put the modified data back
ctx.putImageData(imageData, 0, 0);
```

function createAnimator() {
  let frame = 0;
  let running = false;
  const log = [];

  function tick() {
    if (!running) return;
    frame++;
    log.push(frame);
  }

  return {
    start() { running = true; },
    stop() { running = false; },
    tick,
    getFrame() { return frame; },
    getLog() { return log; },
    reset() { frame = 0; log.length = 0; }
  };
}

const animator = createAnimator();

function runAnimation(steps) {
  animator.start();
  for (let i = 0; i < steps; i++) {
    animator.tick();
  }
  animator.stop();
  return animator.getFrame();
}

function wrapText(text, maxWidth, charWidth) {
  // Simple word-wrap based on estimated char width
  const words = text.split(' ');
  const lines = [];
  let currentLine = '';

  for (const word of words) {
    const testLine = currentLine ? currentLine + ' ' + word : word;
    if (testLine.length * charWidth > maxWidth && currentLine) {
      lines.push(currentLine);
      currentLine = word;
    } else {
      currentLine = testLine;
    }
  }
  if (currentLine) lines.push(currentLine);
  return lines;
}

function centerText(text, canvasWidth, charWidth) {
  const textWidth = text.length * charWidth;
  return (canvasWidth - textWidth) / 2;
}

function stackedTextPositions(lines, startY, lineHeight) {
  return lines.map((line, i) => ({ text: line, y: startY + i * lineHeight }));
}

### Project 1: Matrix Rain Effect

The classic green cascading characters from The Matrix — built entirely on canvas using `requestAnimationFrame`.

**Key concepts:** Canvas columns, random characters, semi-transparent overlays for the trail effect, `requestAnimationFrame` loop.

<iframe
  src="/js-from-zero-to-hero/demos/matrix/index.html"
  width="100%"
  height="500"
  style={{border: '1px solid var(--ifm-color-emphasis-300)', borderRadius: '8px'}}
  title="Matrix Rain Effect Demo"
/>

#### How it works

1. Create a `<canvas>` that fills the viewport.
2. Divide the canvas width into columns of `fontSize` pixels each.
3. Track a `drops` array — one value per column, representing the current y-position of the falling character.
4. On each frame:
   - Draw a semi-transparent black rectangle over the whole canvas (creates the fade trail).
   - For each drop, draw a random character at `(col * fontSize, drop * fontSize)`.
   - Randomly reset a drop to `0` when it reaches the bottom.

```js
const canvas = document.getElementById('canvas');
const ctx = canvas.getContext('2d');
canvas.width = window.innerWidth;
canvas.height = window.innerHeight;

const fontSize = 16;
const columns = Math.floor(canvas.width / fontSize);
const drops = new Array(columns).fill(1);
const chars = 'アイウエオ...ABCDEFGHIJKLMNOPQRSTUVWXYZ0123456789';

function draw() {
  ctx.fillStyle = 'rgba(0, 0, 0, 0.05)';
  ctx.fillRect(0, 0, canvas.width, canvas.height);

  ctx.fillStyle = '#0F0';
  ctx.font = `${fontSize}px monospace`;

  drops.forEach((y, i) => {
    const char = chars[Math.floor(Math.random() * chars.length)];
    ctx.fillText(char, i * fontSize, y * fontSize);
    if (y * fontSize > canvas.height && Math.random() > 0.975) {
      drops[i] = 0;
    }
    drops[i]++;
  });
}

setInterval(draw, 33);
```

#### Challenge 1

Change the character color from green to a gradient that shifts between green and white depending on the drop's position — characters near the top of a trail should be bright white.

#### Challenge 2

Add a "freeze" mode: pressing the spacebar pauses and resumes the animation. Use a boolean flag and `cancelAnimationFrame` to implement it cleanly.

### Project 2: Canvas Drawing Tool

A freehand drawing application using mouse events and canvas paths.

**Key concepts:** `mousedown`, `mousemove`, `mouseup` events, `beginPath`/`moveTo`/`lineTo`, dynamic line width and color.

  title="Canvas Drawing Tool Demo"

#### How it works

1. Track whether the mouse button is pressed (`isDrawing`).
2. On `mousedown`: set `isDrawing = true`, call `beginPath()`, `moveTo(x, y)`.
3. On `mousemove`: if drawing, call `lineTo(x, y)` and `stroke()`, then `moveTo(x, y)`.
4. On `mouseup` / `mouseleave`: set `isDrawing = false`.

```js
let isDrawing = false;
let lastX = 0, lastY = 0;

canvas.addEventListener('mousedown', (e) => {
  isDrawing = true;
  [lastX, lastY] = [e.offsetX, e.offsetY];
});

canvas.addEventListener('mousemove', (e) => {
  if (!isDrawing) return;
  ctx.beginPath();
  ctx.moveTo(lastX, lastY);
  ctx.lineTo(e.offsetX, e.offsetY);
  ctx.stroke();
  [lastX, lastY] = [e.offsetX, e.offsetY];
});

canvas.addEventListener('mouseup', () => isDrawing = false);
canvas.addEventListener('mouseleave', () => isDrawing = false);
```

#### Challenge 1

Add a color picker and a line-width slider that update `ctx.strokeStyle` and `ctx.lineWidth` in real time. Let users choose between round and square line caps (`ctx.lineCap`).

#### Challenge 2

Implement an **undo** feature using an array of `ImageData` snapshots. Save the canvas state on every `mousedown`, and restore the previous snapshot when the user presses `Ctrl+Z`.

### Project 3: Paint App

A full-featured paint application combining shapes, a color palette, bucket fill, and text tool.

**Key concepts:** Tool selection state machine, flood-fill algorithm, `ctx.save()`/`ctx.restore()` for tool previews.

#### How it works

The paint app uses a **current tool** state to determine what happens on mouse events:

- **Pencil** — freehand drawing (same as the drawing tool above).
- **Rectangle / Circle** — on `mousedown`, record the start point. On `mousemove`, clear a preview and draw the shape. On `mouseup`, commit the shape.
- **Bucket fill** — on click, run a flood-fill algorithm using `getImageData`/`putImageData`.
- **Text** — on click, prompt for text and render it at the clicked position with `fillText`.

```js
let tool = 'pencil';
let startX, startY;
let snapshot; // ImageData taken on mousedown for shape preview

canvas.addEventListener('mousedown', (e) => {
  startX = e.offsetX;
  startY = e.offsetY;
  snapshot = ctx.getImageData(0, 0, canvas.width, canvas.height);
});

canvas.addEventListener('mousemove', (e) => {
  if (tool === 'rectangle') {
    ctx.putImageData(snapshot, 0, 0); // Restore before drawing preview
    ctx.strokeRect(startX, startY, e.offsetX - startX, e.offsetY - startY);
  }
});
```

## Summary

In this module you learned:

- How to obtain and use a `CanvasRenderingContext2D` via `getContext('2d')`.
- Drawing primitives: rectangles, arcs, and arbitrary paths with lines and curves.
- Styling with solid colors, linear gradients, and radial gradients.
- Rendering and measuring text on canvas.
- Creating smooth animations using `requestAnimationFrame` and a game loop.
- Reading and writing pixel data with `getImageData` and `putImageData`.

The Canvas API is foundational for browser games, data visualizations, image editors, and creative coding. The projects above — Matrix Rain, the Drawing Tool, and the Paint App — each apply a different slice of these capabilities in a real, interactive context.
