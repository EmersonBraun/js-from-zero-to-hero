# Funciones

Las funciones son bloques de código reutilizables que realizan una tarea específica. Son uno de los conceptos más importantes en JavaScript — te ayudan a organizar el código, evitar la repetición y construir programas complejos a partir de piezas más pequeñas.

## Declaración de Función

La forma clásica de definir una función:

```javascript
function greet(name) {
  return "Hello, " + name + "!";
}

console.log(greet("Alice"));  // "Hello, Alice!"
```

Partes de una función:
- Palabra clave **`function`**
- **Nombre** (`greet`)
- **Parámetros** (`name`) — entradas que acepta la función
- **Cuerpo** (`{ ... }`) — el código que se ejecuta
- **`return`** — el valor de salida (opcional)

> **Referencia MDN:** [Funciones](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide/Functions)

## Expresión de Función

Una función almacenada en una variable:

```javascript
const greet = function(name) {
  return "Hello, " + name + "!";
};
```

La diferencia: las declaraciones de función se **elevan** (pueden llamarse antes de ser definidas), las expresiones de función **no**.

## Arrow Functions

Una sintaxis más corta introducida en ES6:

```javascript
const greet = (name) => {
  return "Hello, " + name + "!";
};

// Aún más corta para expresiones simples:
const greet = (name) => "Hello, " + name + "!";

// Un solo parámetro — paréntesis opcional:
const double = n => n * 2;
```

> **Referencia MDN:** [Arrow functions](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Functions/Arrow_functions)

## Parámetros y Argumentos

- Los **parámetros** son los nombres listados en la definición de la función
- Los **argumentos** son los valores reales pasados al llamar la función

```javascript
function add(a, b) {   // a, b son parámetros
  return a + b;
}

add(3, 5);  // 3, 5 son argumentos
```

### Parámetros por Defecto

Proporciona valores de reserva cuando no se pasan argumentos:

```javascript
function greet(name = "World") {
  return `Hello, ${name}!`;
}

greet();        // "Hello, World!"
greet("Alice"); // "Hello, Alice!"
```

### Parámetros Rest

Recopila múltiples argumentos en un array:

```javascript
function sum(...numbers) {
  let total = 0;
  for (const num of numbers) {
    total += num;
  }
  return total;
}

sum(1, 2, 3);     // 6
sum(10, 20, 30, 40); // 100
```

## Valores de Retorno

Las funciones pueden devolver un valor usando `return`. Si no se usa ninguna sentencia `return`, la función devuelve `undefined`:

```javascript
function add(a, b) {
  return a + b;  // Devuelve un valor
}

function logMessage(msg) {
  console.log(msg);  // Sin return — devuelve undefined
}
```

Una función deja de ejecutarse cuando llega a un `return`:

```javascript
function checkAge(age) {
  if (age < 0) return "Invalid age";  // Retorno anticipado
  if (age >= 18) return "Adult";
  return "Minor";
}
```

## Alcance (Scope)

El **alcance** determina dónde es accesible una variable:

```javascript
let globalVar = "Soy global";

function myFunction() {
  let localVar = "Soy local";
  console.log(globalVar);  // OK — puede acceder a global
  console.log(localVar);   // OK — puede acceder a local
}

myFunction();
// console.log(localVar);  // ERROR — localVar no está definido aquí
```

Las funciones crean su propio alcance. Las variables declaradas dentro de una función **no son accesibles** fuera de ella.

> **Referencia MDN:** [Scope](https://developer.mozilla.org/en-US/docs/Glossary/Scope)

## Proyecto: Calculadora de IMC

¡Apliquemos las funciones a un proyecto real! La **Calculadora de IMC** toma la altura y el peso como entradas y calcula el Índice de Masa Corporal.

### Cómo Funciona

La fórmula del IMC es: `IMC = peso (kg) / altura (m)²`

La función principal demuestra **parámetros**, **valores de retorno** y **retornos anticipados**:

```javascript
function calculate() {
  const height = document.getElementById('height').value;
  const weight = document.getElementById('weight').value;
  if (!height || !weight) return;  // Retorno anticipado si las entradas están vacías
  const bmi = weight / height ** 2;
  document.getElementById('bmi').textContent = `${(bmi * 10000).toFixed(2)} BMI`;
}
```

Conceptos clave:
- **Función sin parámetros** — lee valores del DOM
- Patrón de **retorno anticipado** — `if (!height || !weight) return`
- **Operador de exponenciación** `**` y `.toFixed(2)` para el formato

#### Desafío 1: Categorías de IMC

Extiende la calculadora para mostrar la categoría del IMC (Delgadez Severa, Normal, Sobrepeso, etc.) usando una función con múltiples sentencias `if`:

```javascript
function getBMIType(value) {
  if (value < 16) return 'Severe Thinness';
  if (value <= 17) return 'Moderate Thinness';
  if (value <= 18.5) return 'Mild Thinness';
  if (value <= 25) return 'Normal';
  if (value <= 30) return 'Overweight';
  if (value <= 35) return 'Obese Class I';
  if (value <= 40) return 'Obese Class II';
  return 'Obese Class III';
}
```
