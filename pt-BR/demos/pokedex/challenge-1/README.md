# Pokedex

> [pt-br version](README-PTBR.md)

A Pokemon search application that allows users to search for Pokemon by name or ID and displays their information including stats, types, and official artwork.

## CLASS

Basic Pokemon search functionality with API integration.

### Features:
- Search Pokemon by name or ID
- Display Pokemon information (name, ID, types, stats)
- Show official Pokemon artwork
- Responsive design with modern UI
- Error handling for invalid searches
- Loading states

### Technologies:
- HTML5
- CSS3 (with gradients and animations)
- JavaScript (ES6+)
- PokeAPI integration

## CHALLENGE 01

Enhanced Pokemon search with additional features and improved UX.

### Additional Features:
- Type-based color coding for Pokemon types
- Detailed stats display (HP, Attack, Defense, Speed)
- Smooth animations and transitions
- Better error handling and user feedback
- Responsive design for mobile devices
- Search by pressing Enter key
- Default Pokemon display on page load

### Technical Improvements:
- Async/await for API calls

- Hover effects and visual feedback

## Demo

The application allows users to:
1. Enter a Pokemon name or ID in the search field
2. Click "Search" or press Enter to find the Pokemon
3. View detailed information including:
   - Official artwork
   - Pokemon name and ID
   - Type badges with color coding
   - Base stats (HP, Attack, Defense, Speed)
4. Handle errors gracefully with user-friendly messages

## API Used

This project uses the [PokeAPI](https://pokeapi.co/) to fetch Pokemon data, providing access to comprehensive Pokemon information including stats, types, sprites, and more.
