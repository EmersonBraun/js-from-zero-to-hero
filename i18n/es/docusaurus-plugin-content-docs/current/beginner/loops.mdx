# Bucles

Los bucles te permiten repetir un bloque de código varias veces. Son esenciales para iterar sobre datos, automatizar tareas repetitivas y construir aplicaciones dinámicas.

## Bucle `for`

El bucle más común. Controlas el **inicio**, la **condición** y el **paso**:

```javascript
for (let i = 0; i < 5; i++) {
  console.log(i);  // 0, 1, 2, 3, 4
}
```

Las tres partes:
1. **Inicialización:** `let i = 0` — se ejecuta una vez antes de que comience el bucle
2. **Condición:** `i < 5` — se verifica antes de cada iteración; el bucle se detiene cuando es false
3. **Actualización:** `i++` — se ejecuta después de cada iteración

### Patrones Comunes

```javascript
// Contar hacia atrás
for (let i = 10; i > 0; i--) {
  console.log(i);  // 10, 9, 8, ..., 1
}

// Paso de 2 en 2
for (let i = 0; i <= 10; i += 2) {
  console.log(i);  // 0, 2, 4, 6, 8, 10
}
```

> **Referencia MDN:** [for](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Statements/for)

## Bucle `while`

Se repite mientras una condición sea `true`. Úsalo cuando no sabes cuántas iteraciones necesitas:

```javascript
let count = 0;
while (count < 5) {
  console.log(count);  // 0, 1, 2, 3, 4
  count++;
}
```

**Advertencia:** ¡Si la condición nunca se vuelve false, obtienes un **bucle infinito** que congela tu programa!

## Bucle `do...while`

Como `while`, pero garantiza al menos **una ejecución**:

```javascript
let num = 10;
do {
  console.log(num);  // 10 (se ejecuta una vez aunque la condición sea false)
  num++;
} while (num < 5);
```

> **Referencia MDN:** [while](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Statements/while), [do...while](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Statements/do...while)

## Bucle `for...of`

Itera sobre **valores** de objetos iterables (arrays, strings):

```javascript
const fruits = ["apple", "banana", "cherry"];
for (const fruit of fruits) {
  console.log(fruit);  // "apple", "banana", "cherry"
}

// También funciona con strings
for (const char of "Hello") {
  console.log(char);  // "H", "e", "l", "l", "o"
}
```

## Bucle `for...in`

Itera sobre **claves** (nombres de propiedades) de un objeto:

```javascript
const person = { name: "Alice", age: 25, city: "NYC" };
for (const key in person) {
  console.log(`${key}: ${person[key]}`);
}
// "name: Alice", "age: 25", "city: NYC"
```

**Consejo:** Usa `for...of` para arrays, `for...in` para objetos.

> **Referencia MDN:** [for...of](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Statements/for...of), [for...in](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Statements/for...in)

## `break` y `continue`

- **`break`** — sale del bucle inmediatamente
- **`continue`** — salta a la siguiente iteración

```javascript
// break: detenerse cuando encontramos 3
for (let i = 0; i < 10; i++) {
  if (i === 3) break;
  console.log(i);  // 0, 1, 2
}

// continue: saltar números pares
for (let i = 0; i < 6; i++) {
  if (i % 2 === 0) continue;
  console.log(i);  // 1, 3, 5
}
```

## Resumen

En este módulo aprendiste:

- Bucle **`for`** — cuando conoces el número de iteraciones
- Bucle **`while`** — cuando necesitas iterar hasta que se cumpla una condición
- **`do...while`** — garantiza al menos una ejecución
- **`for...of`** — itera sobre valores (arrays, strings)
- **`for...in`** — itera sobre claves (objetos)
- **`break`** sale del bucle, **`continue`** salta a la siguiente iteración
- Cómo resolver problemas comunes con bucles: sumas, inversiones, búsquedas
