# Star Wars Intro

> [pt-br version](README-PTBR.md)

A Star Wars-style scrolling text intro generator with customizable text, speed, and colors.

![Star Wars Intro](gifs/class.gif)

## CLASS

### Features

- **Customizable Text**: Edit the intro text to create your own Star Wars-style story
- **Speed Control**: Adjust the scrolling speed from slow to fast
- **Color Options**: Choose from multiple text colors including the classic yellow
- **Play Controls**: Play, pause, and reset the animation
- **Keyboard Shortcuts**: Space to play/pause, R to reset
- **Responsive Design**: Works on desktop and mobile devices

### How to Use

1. **Edit Text**: Modify the text in the textarea to create your own story
2. **Adjust Speed**: Use the slider to control how fast the text scrolls
3. **Choose Color**: Select from different text colors
4. **Control Playback**: Use the Play, Pause, and Reset buttons
5. **Keyboard Shortcuts**:
   - `Spacebar`: Play/Pause
   - `R`: Reset animation

### Technologies Used

- HTML5
- CSS3 (with 3D transforms and animations)
- Vanilla JavaScript
- Google Fonts (Roboto)
