Fundamentos del DOM

El DOM (Document Object Model) es cómo JavaScript interactúa con HTML. Cuando un navegador carga una página, crea una estructura en forma de árbol de todos los elementos — ese árbol es el DOM. JavaScript puede leer, modificar, agregar y eliminar cualquier parte de él.

Seleccionar Elementos​

getElementById​

Selecciona un elemento por su atributo id:

const title = document.getElementById("title");
console.log(title.textContent);  // El texto dentro del elemento

querySelector​

Selecciona el primer elemento que coincide con un selector CSS:

const paragraph = document.querySelector("p");          // Primer <p>
const box = document.querySelector(".box");             // Primer .box
const btn = document.querySelector("#submit-btn");       // Elemento con id
const nested = document.querySelector(".card > h2");     // Selector anidado

querySelectorAll​

Selecciona todos los elementos que coinciden con un selector CSS (devuelve un NodeList):

const allButtons = document.querySelectorAll("button");
allButtons.forEach(btn => console.log(btn.textContent));

Referencia MDN: querySelector

Modificar Elementos​

Contenido de Texto​

const heading = document.getElementById("title");
heading.textContent = "Nuevo Título";  // Cambia el texto

Estilos CSS​

const box = document.querySelector(".box");
box.style.backgroundColor = "blue";
box.style.color = "white";
box.style.padding = "20px";

Clases CSS​

const element = document.querySelector(".card");
element.classList.add("active");     // Agregar una clase
element.classList.remove("hidden");  // Eliminar una clase
element.classList.toggle("open");    // Alternar una clase activada/desactivada
element.classList.contains("active"); // Verificar si existe la clase → true/false

Atributos​

const link = document.querySelector("a");
link.setAttribute("href", "https://example.com");
link.getAttribute("href");  // "https://example.com"
link.removeAttribute("target");

Referencia MDN: Element

Event Listeners​

Los eventos son cosas que suceden en el navegador: clics, pulsaciones de teclas, movimientos del mouse, envíos de formularios. Usa addEventListener para reaccionar a ellos:

const button = document.querySelector("#myBtn");

button.addEventListener("click", function() {
  console.log("¡Botón clicado!");
});

Eventos Comunes​

EventoSe activa cuando
clickSe hace clic en el elemento
dblclickSe hace doble clic en el elemento
mouseenterEl mouse entra al elemento
mouseleaveEl mouse sale del elemento
keydownSe presiona una tecla
keyupSe suelta una tecla
inputEl valor del input cambia
submitSe envía un formulario
loadLa página termina de cargar

El Objeto Evento​

Los event listeners reciben un objeto evento con información sobre lo que sucedió:

document.addEventListener("keydown", function(event) {
  console.log(event.key);     // La tecla presionada ("a", "Enter", etc.)
  console.log(event.code);    // Código de tecla física ("KeyA", "Enter")
  console.log(event.keyCode); // Código de tecla numérico (obsoleto pero común)
});

button.addEventListener("click", function(event) {
  console.log(event.target);  // El elemento que fue clicado
});

Referencia MDN: addEventListener

Crear y Eliminar Elementos​

Crear Elementos​

const newParagraph = document.createElement("p");
newParagraph.textContent = "¡Fui creado por JavaScript!";
newParagraph.classList.add("highlight");

document.body.appendChild(newParagraph);  // Agregar al final del body

Eliminar Elementos​

const element = document.querySelector("#old-element");
element.remove();

Proyecto: Códigos de Tecla de Eventos​

El proyecto Códigos de Tecla de Eventos es un inspector de eventos de teclado que muestra información de teclas en tiempo real cuando presionas cualquier tecla. Demuestra event listeners, el objeto evento y manipulación del DOM.

Conceptos Clave​

document.addEventListener('keydown', function(e) {
  e.preventDefault();

  // Acceder a las propiedades del evento
  const keyData = {
    key: e.key,        // "a", "Enter", "Shift"
    code: e.code,      // "KeyA", "Enter", "ShiftLeft"
    keyCode: e.keyCode // 65, 13, 16 (numérico, obsoleto)
  };

  // Actualizar el DOM con la información de la tecla
  document.getElementById('keyValue').textContent = keyData.key;
  document.getElementById('keyCode').textContent = keyData.code;
  document.getElementById('keyCodeNumber').textContent = keyData.keyCode;
});

Proyecto: Pasos de Progreso​

El proyecto Pasos de Progreso demuestra la manipulación del DOM con un formulario de varios pasos. Utiliza classList, manipulación de estilos y event listeners para crear un asistente interactivo paso a paso.

Conceptos Clave​

const circles = document.querySelectorAll('.circle');
let currentActive = 1;

// Actualizar el estado visual de los círculos de pasos
function updateCircles() {
  circles.forEach((circle, index) => {
    if (index < currentActive) {
      circle.classList.add('active');
    } else {
      circle.classList.remove('active');
    }
  });
}

// Actualizar el ancho de la barra de progreso
function updateProgress() {
  const progressPercent = ((currentActive - 1) / (circles.length - 1)) * 100;
  document.getElementById('progress').style.width = progressPercent + '%';
}
