# Callbacks & Funções de Alta Ordem

Funções são **cidadãos de primeira classe** em JavaScript — elas podem ser armazenadas em variáveis, passadas como argumentos e retornadas por outras funções. Este módulo explora essa ideia por meio de callbacks e funções de alta ordem.

## Teoria

### Funções de Primeira Classe

JavaScript trata funções como qualquer outro valor. Você pode:

```js
// Atribuir a uma variável
const greet = function(name) { return `Hello, ${name}!`; };

// Armazenar em um array
const operations = [Math.sqrt, Math.abs, Math.ceil];

// Passar como argumento
setTimeout(() => console.log("delayed"), 1000);
```

Referência MDN: [First-class Function](https://developer.mozilla.org/en-US/docs/Glossary/First-class_Function)

### Callbacks

Um **callback** é uma função passada para outra função para ser chamada mais tarde — de forma síncrona ou assíncrona.

```js
function doTwice(fn) {
  fn();
  fn();
}

doTwice(() => console.log("hello")); // "hello" impresso duas vezes
```

Padrões comuns onde callbacks aparecem:

- Métodos de array (`forEach`, `map`, `filter`, `sort`)
- Event listeners (`addEventListener`)
- Operações assíncronas (`setTimeout`, `fetch`)

### Funções de Alta Ordem (HOF)

Uma **função de alta ordem** pode:
1. Aceitar uma função como argumento, ou
2. Retornar uma função.

```js
// Aceita uma função
function applyToAll(arr, fn) {
  return arr.map(fn);
}

// Retorna uma função
function multiplier(factor) {
  return (n) => n * factor;
}
const double = multiplier(2);
double(5); // 10
```

Referência MDN: [Functions](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide/Functions)

### map, filter e reduce em Profundidade

Esses três métodos de array são a base do processamento declarativo de arrays.

#### map

Transforma cada elemento; retorna um novo array do mesmo tamanho.

```js
const prices = [10, 20, 30];
const withTax = prices.map(p => p * 1.2); // [12, 24, 36]
```

#### filter

Mantém apenas os elementos onde o callback retorna `true`.

```js
const ages = [12, 20, 17, 25];
const adults = ages.filter(age => age >= 18); // [20, 25]
```

#### reduce

Acumula todos os elementos em um único valor. O callback recebe `(accumulator, currentValue)`.

```js
const numbers = [1, 2, 3, 4];
const sum = numbers.reduce((acc, n) => acc + n, 0); // 10

// Construir um objeto a partir de um array
const inventory = [
  { name: "apple", qty: 5 },
  { name: "banana", qty: 3 },
];
const totals = inventory.reduce((acc, item) => {
  acc[item.name] = item.qty;
  return acc;
}, {});
// { apple: 5, banana: 3 }
```

Referências MDN: [map](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Array/map) | [filter](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Array/filter) | [reduce](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Array/reduce)

### Estilo Declarativo vs Imperativo

**Imperativo** — descreve *como* fazer algo passo a passo:

```js
const result = [];
for (let i = 0; i < numbers.length; i++) {
  if (numbers[i] % 2 === 0) {
    result.push(numbers[i] * 2);
  }
}
```

**Declarativo** — descreve *o que* você quer:

```js
const result = numbers.filter(n => n % 2 === 0).map(n => n * 2);
```

O estilo declarativo é mais curto, mais fácil de testar e mais próximo de como você pensa sobre o problema.

### Composição de Funções

Combinar funções pequenas em funções maiores:

```js
const compose = (...fns) => (x) => fns.reduceRight((v, f) => f(v), x);

const add1 = x => x + 1;
const double = x => x * 2;
const square = x => x * x;

const transform = compose(square, double, add1);
transform(3); // square(double(add1(3))) = square(double(4)) = square(8) = 64
```

Este projeto converte inteiros em algarismos romanos usando uma tabela de consulta e `reduce`.

### Como Funciona

```js
const romanNumerals = [
  [1000, "M"], [900, "CM"], [500, "D"], [400, "CD"],
  [100, "C"],  [90, "XC"],  [50, "L"],  [40, "XL"],
  [10, "X"],   [9, "IX"],   [5, "V"],   [4, "IV"],
  [1, "I"],
];

function toRoman(num) {
  return romanNumerals.reduce((result, [value, symbol]) => {
    while (num >= value) {
      result += symbol;
      num -= value;
    }
    return result;
  }, "");
}
```

O callback do `reduce` aqui funciona como um iterador sobre a tabela de consulta — um padrão clássico de função de alta ordem.

### Como Funciona

```js
function binaryToDecimal(binaryStr) {
  return binaryStr
    .split("")
    .reverse()
    .reduce((acc, bit, index) => acc + Number(bit) * Math.pow(2, index), 0);
}
```

Observe como `reduce` substitui o loop `for` manual — o acumulador constrói o valor decimal bit a bit.

## Resumo

- Funções são valores de primeira classe — armazene, passe e retorne-as livremente.
- Um **callback** é simplesmente uma função que você entrega a outra função para invocar no momento certo.
- Uma **função de alta ordem** é qualquer função que recebe ou retorna uma função.
- `map`, `filter` e `reduce` formam o núcleo do processamento declarativo de arrays — prefira-os em vez de loops `for` ao transformar dados.
- **Composição de funções** permite construir pipelines poderosos a partir de peças pequenas e reutilizáveis.
- O estilo declarativo torna sua intenção mais clara e seu código mais fácil de testar.
