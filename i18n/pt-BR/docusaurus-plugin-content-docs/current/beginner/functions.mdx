# Funções

Funções são blocos de código reutilizáveis que realizam uma tarefa específica. Elas são um dos conceitos mais importantes em JavaScript — ajudam você a organizar o código, evitar repetição e construir programas complexos a partir de peças menores.

## Declaração de Função

A forma clássica de definir uma função:

```javascript
function greet(name) {
  return "Hello, " + name + "!";
}

console.log(greet("Alice"));  // "Hello, Alice!"
```

Partes de uma função:
- Palavra-chave **`function`**
- **Nome** (`greet`)
- **Parâmetros** (`name`) — entradas que a função aceita
- **Corpo** (`{ ... }`) — o código que executa
- **`return`** — o valor de saída (opcional)

> **Referência MDN:** [Functions](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide/Functions)

## Expressão de Função

Uma função armazenada em uma variável:

```javascript
const greet = function(name) {
  return "Hello, " + name + "!";
};
```

A diferença: declarações de função sofrem **hoisting** (podem ser chamadas antes de serem definidas), expressões de função **não**.

## Arrow Functions

Uma sintaxe mais curta introduzida no ES6:

```javascript
const greet = (name) => {
  return "Hello, " + name + "!";
};

// Ainda mais curta para expressões simples:
const greet = (name) => "Hello, " + name + "!";

// Parâmetro único — parênteses opcionais:
const double = n => n * 2;
```

> **Referência MDN:** [Arrow functions](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Functions/Arrow_functions)

## Parâmetros e Argumentos

- **Parâmetros** são os nomes listados na definição da função
- **Argumentos** são os valores reais passados ao chamar a função

```javascript
function add(a, b) {   // a, b são parâmetros
  return a + b;
}

add(3, 5);  // 3, 5 são argumentos
```

### Parâmetros Padrão

Forneça valores de fallback quando argumentos não forem passados:

```javascript
function greet(name = "World") {
  return `Hello, ${name}!`;
}

greet();        // "Hello, World!"
greet("Alice"); // "Hello, Alice!"
```

### Parâmetros Rest

Colete múltiplos argumentos em um array:

```javascript
function sum(...numbers) {
  let total = 0;
  for (const num of numbers) {
    total += num;
  }
  return total;
}

sum(1, 2, 3);     // 6
sum(10, 20, 30, 40); // 100
```

## Valores de Retorno

Funções podem retornar um valor usando `return`. Se nenhuma declaração `return` for usada, a função retorna `undefined`:

```javascript
function add(a, b) {
  return a + b;  // Retorna um valor
}

function logMessage(msg) {
  console.log(msg);  // Sem return — retorna undefined
}
```

Uma função para de executar quando chega em um `return`:

```javascript
function checkAge(age) {
  if (age < 0) return "Invalid age";  // Retorno antecipado
  if (age >= 18) return "Adult";
  return "Minor";
}
```

## Escopo

**Escopo** determina onde uma variável é acessível:

```javascript
let globalVar = "I'm global";

function myFunction() {
  let localVar = "I'm local";
  console.log(globalVar);  // OK — pode acessar global
  console.log(localVar);   // OK — pode acessar local
}

myFunction();
// console.log(localVar);  // ERRO — localVar não está definida aqui
```

Funções criam seu próprio escopo. Variáveis declaradas dentro de uma função **não são acessíveis** fora dela.

> **Referência MDN:** [Scope](https://developer.mozilla.org/en-US/docs/Glossary/Scope)

## Projeto: Calculadora de IMC

Vamos aplicar funções em um projeto real! A **Calculadora de IMC** recebe altura e peso como entradas e calcula o Índice de Massa Corporal.

### Como Funciona

A fórmula do IMC é: `IMC = peso (kg) / altura (m)²`

A função principal demonstra **parâmetros**, **valores de retorno** e **retornos antecipados**:

```javascript
function calculate() {
  const height = document.getElementById('height').value;
  const weight = document.getElementById('weight').value;
  if (!height || !weight) return;  // Retorno antecipado se entradas estiverem vazias
  const bmi = weight / height ** 2;
  document.getElementById('bmi').textContent = `${(bmi * 10000).toFixed(2)} BMI`;
}
```

Conceitos-chave:
- **Função sem parâmetros** — lê valores do DOM
- Padrão de **retorno antecipado** — `if (!height || !weight) return`
- **Operador de exponenciação** `**` e `.toFixed(2)` para formatação

#### Desafio 1: Categorias de IMC

Estenda a calculadora para mostrar a categoria do IMC (Magreza Severa, Normal, Sobrepeso, etc.) usando uma função com múltiplas declarações `if`:

```javascript
function getBMIType(value) {
  if (value < 16) return 'Severe Thinness';
  if (value <= 17) return 'Moderate Thinness';
  if (value <= 18.5) return 'Mild Thinness';
  if (value <= 25) return 'Normal';
  if (value <= 30) return 'Overweight';
  if (value <= 35) return 'Obese Class I';
  if (value <= 40) return 'Obese Class II';
  return 'Obese Class III';
}
```

  const idealWeight = (height ** 2 * 22.5 / 10000).toFixed(2);

}
