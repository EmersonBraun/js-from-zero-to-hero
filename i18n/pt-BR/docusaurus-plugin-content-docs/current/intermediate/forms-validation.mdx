# Formulários & Validação

Formulários são como os usuários enviam dados para sua aplicação. JavaScript permite ler valores, responder à entrada do usuário em tempo real, validar dados antes do envio e fornecer feedback claro — tudo sem recarregar a página.

## Teoria

### Elementos de Formulário

Os principais elementos de formulário e como acessá-los em JavaScript:

| Elemento | Como obter o valor |
|---------|-----------------|
| `<input type="text">` | `element.value` |
| `<input type="number">` | `Number(element.value)` |
| `<input type="checkbox">` | `element.checked` |
| `<input type="radio">` | `element.checked` em cada opção |
| `<select>` | `element.value` |
| `<textarea>` | `element.value` |

```js
const nameInput = document.querySelector("#name");
const ageInput  = document.querySelector("#age");
const colorSelect = document.querySelector("#color");

console.log(nameInput.value);   // texto atual
console.log(Number(ageInput.value));
console.log(colorSelect.value);
```

Referência MDN: [HTMLInputElement](https://developer.mozilla.org/en-US/docs/Web/API/HTMLInputElement) | [HTMLSelectElement](https://developer.mozilla.org/en-US/docs/Web/API/HTMLSelectElement)

### Obtendo e Definindo Valores de Formulário

Leia valores com `.value`, defina-os da mesma forma:

```js
// Ler
const text = input.value.trim(); // .trim() remove espaços ao redor

// Escrever (atualizar a UI)
input.value = "default text";
checkbox.checked = true;
select.value = "option2"; // seleciona o <option> correspondente
```

Para ler todos os campos de uma vez, use `FormData`:

```js
const form = document.querySelector("form");
const data = new FormData(form);

data.get("username"); // valor do input[name="username"]
Object.fromEntries(data); // converter todos os campos para um objeto simples
```

Referência MDN: [FormData](https://developer.mozilla.org/en-US/docs/Web/API/FormData)

### Eventos de Formulário

| Evento | Quando dispara |
|-------|--------------|
| `input` | Em cada tecla pressionada / mudança de valor |
| `change` | Quando um elemento perde o foco após seu valor mudar |
| `focus` | Quando um elemento ganha foco |
| `blur` | Quando um elemento perde o foco |
| `submit` | Quando o formulário é enviado |
| `reset` | Quando o formulário é reiniciado |

```js
input.addEventListener("input", (e) => {
  console.log(e.target.value); // valor ao vivo em cada tecla pressionada
});

form.addEventListener("submit", (e) => {
  e.preventDefault(); // impede o recarregamento da página
  validate(new FormData(form));
});
```

Referência MDN: [HTMLElement: input event](https://developer.mozilla.org/en-US/docs/Web/API/HTMLElement/input_event) | [HTMLFormElement: submit event](https://developer.mozilla.org/en-US/docs/Web/API/HTMLFormElement/submit_event)

### Padrões Básicos de Validação

**Validação manual** — verifique os valores você mesmo e mostre mensagens de erro:

```js
function validate(fields) {
  const errors = {};

  if (!fields.name || fields.name.trim().length < 2) {
    errors.name = "Name must be at least 2 characters.";
  }

  if (isNaN(fields.age) || fields.age < 0 || fields.age > 120) {
    errors.age = "Age must be a number between 0 and 120.";
  }

  return errors; // objeto vazio significa válido
}
```

**Constraint Validation API** — o navegador valida usando atributos HTML:

```html
<input type="email" required minlength="5" />
```

```js
input.checkValidity();   // true / false
input.validationMessage; // mensagem de erro embutida
form.checkValidity();    // true se todos os campos são válidos
```

### Fundamentos de Expressões Regulares

Uma **expressão regular** (regex) é um padrão para correspondência de strings.

```js
// Testar se uma string corresponde ao padrão
/^\d{4}$/.test("2024");  // true — exatamente 4 dígitos
/^\d{4}$/.test("24");    // false

// Padrões comuns
const emailPattern = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;
const phonePattern = /^\+?[\d\s\-()]{7,15}$/;
const upperPattern = /[A-Z]/;
const numberPattern = /[0-9]/;
const specialPattern = /[!@#$%^&*]/;
```

Referência MDN: [Regular Expressions](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide/Regular_expressions)

### Exibindo Feedback de Validação

Um padrão comum é adicionar/remover classes CSS no elemento contêiner:

```js
function showError(input, message) {
  const field = input.parentElement;
  field.classList.add("error");
  field.classList.remove("success");
  field.querySelector(".error-msg").textContent = message;
}

function showSuccess(input) {
  const field = input.parentElement;
  field.classList.remove("error");
  field.classList.add("success");
  field.querySelector(".error-msg").textContent = "";
}
```

### Como Funciona

O gerador lê os estados dos checkboxes e um input range para compor um conjunto de caracteres:

```js
const CHARS = {
  lowercase: "abcdefghijklmnopqrstuvwxyz",
  uppercase: "ABCDEFGHIJKLMNOPQRSTUVWXYZ",
  numbers:   "0123456789",
  symbols:   "!@#$%^&*()_+-=[]{}|;:,.<>?",
};

function generatePassword(options) {
  const { length, useLower, useUpper, useNumbers, useSymbols } = options;

  let charset = "";
  if (useLower)   charset += CHARS.lowercase;
  if (useUpper)   charset += CHARS.uppercase;
  if (useNumbers) charset += CHARS.numbers;
  if (useSymbols) charset += CHARS.symbols;

  if (!charset) return ""; // nenhuma opção selecionada

  return Array.from({ length }, () =>
    charset[Math.floor(Math.random() * charset.length)]
  ).join("");
}
```

O formulário escuta eventos `input` no slider de comprimento para atualizar o display em tempo real:

```js
lengthSlider.addEventListener("input", () => {
  lengthDisplay.textContent = lengthSlider.value;
});

generateBtn.addEventListener("click", () => {
  const options = {
    length:     Number(lengthSlider.value),
    useLower:   lowercaseCheckbox.checked,
    useUpper:   uppercaseCheckbox.checked,
    useNumbers: numbersCheckbox.checked,
    useSymbols: symbolsCheckbox.checked,
  };
  output.value = generatePassword(options);
});
```

### Como Funciona

As perguntas são armazenadas como um array de objetos:

```js
const questions = [
  {
    question: "What does typeof null return?",
    choices: ["null", "undefined", "object", "string"],
    answer: "object",
  },
  {
    question: "Which method adds an element to the end of an array?",
    choices: ["push", "pop", "shift", "unshift"],
    answer: "push",
  },
];
```

O estado é rastreado em um objeto simples:

```js
let state = {
  currentIndex: 0,
  score: 0,
  answers: [],
};
```

O handler de `submit` lê o radio button marcado, verifica contra a resposta e avança para a próxima pergunta:

```js
form.addEventListener("submit", (e) => {
  e.preventDefault();
  const selected = form.querySelector("input[name='choice']:checked");
  if (!selected) return; // nenhuma escolha feita

  const answer = selected.value;
  const correct = questions[state.currentIndex].answer;
  const isCorrect = answer === correct;

  state.answers.push({ answer, isCorrect });
  if (isCorrect) state.score++;
  state.currentIndex++;

  if (state.currentIndex < questions.length) {
    renderQuestion();
  } else {
    renderResults();
  }
});
```

## Resumo

- Acesse valores de formulário com `.value` (texto, número, select, textarea) e `.checked` (checkbox, radio).
- Use `e.preventDefault()` no evento `submit` para lidar com formulários sem recarregar a página.
- O evento `input` dispara em cada tecla pressionada — ótimo para feedback em tempo real. O evento `change` dispara quando o foco sai.
- `FormData` converte um formulário inteiro em uma coleção chave-valor com uma linha.
- Validação manual retorna um objeto de erros; mostre mensagens ao usuário e nunca assuma que a entrada é segura.
- Expressões regulares são poderosas para correspondência de padrões (emails, senhas, números de telefone) — teste-as em [regex101.com](https://regex101.com).
- Sempre sanitize a entrada do usuário antes de exibi-la de volta na página para evitar XSS.
