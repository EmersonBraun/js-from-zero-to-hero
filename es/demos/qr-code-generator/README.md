# QR Code Generator

> [pt-br version](README-PTBR.md)

A simple and powerful QR Code generator built with vanilla JavaScript. Generate QR codes for URLs, text, contact information, and more.

![QR Code Generator](gifs/class.gif)

## CLASS

Basic QR Code generation functionality:
- Input text or URL to generate QR code
- Clean and modern interface
- Responsive design
- Generate and clear functionality

### Features:
- Real-time QR code generation
- Support for any text or URL
- Clean, modern UI with gradient background
- Mobile responsive design
- Enter key support for quick generation

## CHALLENGE 01

Enhanced QR Code generator with additional features:
- Size selection (Small, Medium, Large)
- Download functionality
- Improved user experience

### New Features:
- Multiple size options (128px, 200px, 256px)
- Download QR code as PNG image
- Better button states and feedback
- Enhanced styling and layout

![Challenge 1](gifs/challenge-1.gif)

## CHALLENGE 02

Advanced QR Code generator with professional features:
- Color customization (foreground and background)
- Error correction levels
- Copy to clipboard functionality
- Status messages and feedback

### Advanced Features:
- Custom foreground and background colors
- Error correction levels (L, M, Q, H)
- Copy QR code to clipboard
- Real-time status messages
- Auto-regeneration on color changes
- Extra large size option (320px)

![Challenge 2](gifs/challenge-2.gif)

## Technologies Used

- HTML5
- CSS3 (with modern gradients and animations)
- Vanilla JavaScript (ES6+)
- QRCode.js library for QR code generation

## How to Use

1. Open `index.html` in your browser
2. Enter any text or URL in the input field
3. Click "Generate QR Code" or press Enter
4. Use the generated QR code or download it
