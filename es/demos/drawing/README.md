# Drawing App

> [pt-br version](README-PTBR.md)

A comprehensive drawing application with multiple tools, effects, and canvas customization options.

![Drawing App](gifs/class.gif)

## CLASS

### Features

- **Multiple Drawing Tools**: Brush, eraser, line, rectangle, circle, text, fill, and eyedropper
- **Customizable Brushes**: Adjustable size, color, and opacity
- **Canvas Controls**: Resizable canvas with custom background colors
- **Color Palette**: Predefined color swatches and custom color picker
- **Undo/Redo**: Full history management with undo and redo functionality
- **File Operations**: Save, load, and export drawings in multiple formats
- **Drawing History**: Track and manage previous drawing sessions
- **Responsive Design**: Works perfectly on all devices

### How to Use

1. **Select Tools**: Choose from various drawing tools in the toolbar
2. **Adjust Settings**: Modify brush size, color, and opacity
3. **Draw Freely**: Use the canvas to create your artwork
4. **Manage History**: Use undo/redo to correct mistakes
5. **Save Work**: Export your drawings in PNG or JPG format
6. **Customize Canvas**: Adjust canvas size and background color

### Drawing Tools

- **🖌️ Brush Tool**: Freehand drawing with customizable brush
- **🧽 Eraser**: Remove drawn content
- **📏 Line Tool**: Draw straight lines
- **⬜ Rectangle Tool**: Draw rectangles and squares
- **⭕ Circle Tool**: Draw circles and ellipses
- **T Text Tool**: Add text to your drawing
- **🎨 Fill Tool**: Fill enclosed areas with color
- **👁️ Eyedropper**: Pick colors from the canvas

### Controls

- **Brush Size**: Adjust from 1px to 50px
- **Color Picker**: Choose any color for drawing
- **Opacity**: Control transparency from 1% to 100%
- **Canvas Size**: Customize width and height (100-2000px)
- **Background Color**: Set canvas background color

### File Operations

- **Save Image**: Save current drawing to local storage
- **Load Image**: Load previously saved drawings
- **Download PNG**: Export as PNG with transparency
- **Download JPG**: Export as JPG with background
- **Clear Canvas**: Start fresh with empty canvas

### Drawing History

- **Undo**: Revert last action
- **Redo**: Restore undone action
- **History Panel**: View and restore previous sessions
- **Auto-save**: Automatic saving of drawing progress

### Technologies Used

- HTML5 Canvas API
- CSS3 (with animations and effects)
- Vanilla JavaScript
- Local Storage API
- File API
- Canvas 2D Context
