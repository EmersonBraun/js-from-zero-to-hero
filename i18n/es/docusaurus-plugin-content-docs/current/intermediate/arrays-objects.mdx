# Arrays y Objetos

Los arrays y objetos son la columna vertebral de la gestión de datos en JavaScript. Dominarlos — junto con la sintaxis moderna como la desestructuración y el spread — mejorará dramáticamente cómo escribes y razonas sobre el código.

## Teoría

### Arrays

Un array es una lista ordenada de valores. Los arrays de JavaScript son dinámicos y pueden contener tipos mixtos.

```js
const fruits = ["apple", "banana", "cherry"];
console.log(fruits[0]); // "apple"
console.log(fruits.length); // 3
```

#### Métodos Comunes de Array

| Método | Descripción |
|--------|-------------|
| `push(val)` | Agregar al final |
| `pop()` | Eliminar del final |
| `shift()` | Eliminar del inicio |
| `unshift(val)` | Agregar al inicio |
| `slice(start, end)` | Devolver una porción (no mutante) |
| `splice(start, deleteCount, ...items)` | Insertar/eliminar en el lugar (mutante) |
| `indexOf(val)` | Encontrar índice del valor (-1 si no se encuentra) |
| `includes(val)` | Verificar si el valor existe |
| `find(fn)` | Devolver el primer elemento que coincida |
| `filter(fn)` | Devolver todos los elementos que coincidan |
| `map(fn)` | Transformar cada elemento |
| `reduce(fn, init)` | Acumular a un único valor |

Referencia MDN: [Array](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Array)

### Objetos

Un objeto almacena pares clave-valor. Las claves son strings (o Symbols); los valores pueden ser cualquier cosa.

```js
const person = { name: "Alice", age: 30 };
console.log(person.name);       // notación de punto
console.log(person["age"]);     // notación de corchetes

const key = "name";
console.log(person[key]);       // acceso dinámico a clave
```

#### Métodos de Utilidad de Objetos

- `Object.keys(obj)` — array de claves
- `Object.values(obj)` — array de valores
- `Object.entries(obj)` — array de pares `[clave, valor]`
- `Object.assign(target, source)` — mezcla superficial
- `Object.freeze(obj)` — prevenir modificaciones

Referencia MDN: [Object](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Object)

### Desestructuración

Extrae valores de arrays u objetos en variables.

```js
// Desestructuración de array
const [first, second, ...rest] = [1, 2, 3, 4, 5];

// Desestructuración de objeto
const { name, age, city = "Unknown" } = person;

// Anidado
const { address: { street } } = { address: { street: "Main St" } };
```

Referencia MDN: [Asignación por desestructuración](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Operators/Destructuring_assignment)

### Operadores Spread y Rest

```js
// Spread: expandir un iterable
const combined = [...arr1, ...arr2];
const clone = { ...obj };

// Rest: recopilar elementos restantes
function sum(...numbers) {
  return numbers.reduce((a, b) => a + b, 0);
}
```

Referencia MDN: [Sintaxis spread](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Operators/Spread_syntax)

### Copia Superficial vs Profunda

```js
// Copia superficial — los objetos anidados aún son compartidos
const shallow = { ...original };

// Copia profunda — clon completamente independiente
const deep = JSON.parse(JSON.stringify(original));
// O usando structuredClone (moderno):
const deep2 = structuredClone(original);
```

### Map y Set

```js
// Map — como un objeto, pero cualquier tipo de clave; preserva el orden de inserción
const map = new Map();
map.set("key", 42);
map.get("key"); // 42
map.has("key"); // true

// Set — colección de valores únicos
const set = new Set([1, 2, 2, 3]);
set.size; // 3
set.has(2); // true
```

Referencias MDN: [Map](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Map) | [Set](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Set)

### Guía

La lógica principal mapea cada elección con lo que vence:

```js
const rules = {
  rock: "scissors",
  paper: "rock",
  scissors: "paper",
};

function getResult(player, computer) {
  if (player === computer) return "draw";
  return rules[player] === computer ? "win" : "lose";
}
```

El marcador se almacena en un `Map` para que cualquier clave de string (nombre del jugador) pueda usarse:

```js
const scoreboard = new Map();

function updateScore(player, result) {
  const current = scoreboard.get(player) ?? { wins: 0, losses: 0, draws: 0 };
  current[result === "win" ? "wins" : result === "lose" ? "losses" : "draws"]++;
  scoreboard.set(player, current);
}
```

## Resumen

- Los arrays tienen un rico conjunto de métodos integrados; prefiere los **no mutantes** (`map`, `filter`, `slice`) cuando no quieras efectos secundarios.
- Los objetos almacenan datos estructurados; `Object.entries` + `map` te permite transformarlos como arrays.
- La **desestructuración** y el **spread** reducen el código repetitivo y hacen que la intención sea más clara.
- Usa `structuredClone` (o `JSON.parse(JSON.stringify(...))`) para copias profundas de datos anidados.
- `Map` y `Set` son mejores opciones que objetos simples cuando necesitas almacenamiento ordenado de clave-valor o colecciones de valores únicos.
