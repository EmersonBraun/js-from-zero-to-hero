# DOM Básico

O **DOM** (Document Object Model) é como JavaScript interage com o HTML. Quando um navegador carrega uma página, ele cria uma estrutura em árvore de todos os elementos — essa árvore é o DOM. JavaScript pode ler, modificar, adicionar e remover qualquer parte dele.

## Selecionando Elementos

### `getElementById`

Seleciona um elemento pelo seu atributo `id`:

```javascript
const title = document.getElementById("title");
console.log(title.textContent);  // O texto dentro do elemento
```

### `querySelector`

Seleciona o **primeiro** elemento que corresponde a um seletor CSS:

```javascript
const paragraph = document.querySelector("p");          // Primeiro <p>
const box = document.querySelector(".box");             // Primeiro .box
const btn = document.querySelector("#submit-btn");       // Elemento com id
const nested = document.querySelector(".card > h2");     // Seletor aninhado
```

### `querySelectorAll`

Seleciona **todos** os elementos que correspondem a um seletor CSS (retorna um NodeList):

```javascript
const allButtons = document.querySelectorAll("button");
allButtons.forEach(btn => console.log(btn.textContent));
```

> **Referência MDN:** [querySelector](https://developer.mozilla.org/en-US/docs/Web/API/Document/querySelector)

## Modificando Elementos

### Conteúdo de Texto

```javascript
const heading = document.getElementById("title");
heading.textContent = "New Title";  // Mudar o texto
```

### Estilos CSS

```javascript
const box = document.querySelector(".box");
box.style.backgroundColor = "blue";
box.style.color = "white";
box.style.padding = "20px";
```

### Classes CSS

```javascript
const element = document.querySelector(".card");
element.classList.add("active");     // Adicionar uma classe
element.classList.remove("hidden");  // Remover uma classe
element.classList.toggle("open");    // Alternar uma classe
element.classList.contains("active"); // Verificar se a classe existe → true/false
```

### Atributos

```javascript
const link = document.querySelector("a");
link.setAttribute("href", "https://example.com");
link.getAttribute("href");  // "https://example.com"
link.removeAttribute("target");
```

> **Referência MDN:** [Element](https://developer.mozilla.org/en-US/docs/Web/API/Element)

## Event Listeners

Eventos são coisas que acontecem no navegador: cliques, teclas pressionadas, movimentos do mouse, envios de formulários. Você usa `addEventListener` para reagir a eles:

```javascript
const button = document.querySelector("#myBtn");

button.addEventListener("click", function() {
  console.log("Button clicked!");
});
```

### Eventos Comuns

| Evento | Disparado Quando |
|---|---|
| `click` | Elemento é clicado |
| `dblclick` | Elemento é clicado duas vezes |
| `mouseenter` | Mouse entra no elemento |
| `mouseleave` | Mouse sai do elemento |
| `keydown` | Uma tecla é pressionada |
| `keyup` | Uma tecla é solta |
| `input` | Valor do input muda |
| `submit` | Formulário é enviado |
| `load` | Página termina de carregar |

### O Objeto de Evento

Event listeners recebem um **objeto de evento** com informações sobre o que aconteceu:

```javascript
document.addEventListener("keydown", function(event) {
  console.log(event.key);     // A tecla que foi pressionada ("a", "Enter", etc.)
  console.log(event.code);    // Código físico da tecla ("KeyA", "Enter")
  console.log(event.keyCode); // Código numérico da tecla (obsoleto mas comum)
});

button.addEventListener("click", function(event) {
  console.log(event.target);  // O elemento que foi clicado
});
```

> **Referência MDN:** [addEventListener](https://developer.mozilla.org/en-US/docs/Web/API/EventTarget/addEventListener)

## Criando e Removendo Elementos

### Criando Elementos

```javascript
const newParagraph = document.createElement("p");
newParagraph.textContent = "I was created by JavaScript!";
newParagraph.classList.add("highlight");

document.body.appendChild(newParagraph);  // Adicionar ao final do body
```

### Removendo Elementos

```javascript
const element = document.querySelector("#old-element");
element.remove();
```

## Projeto: Códigos de Teclas

O projeto **Event Keycodes** é um inspetor de eventos de teclado que mostra informações sobre teclas em tempo real quando você pressiona qualquer tecla. Demonstra event listeners, o objeto de evento e manipulação do DOM.

### Conceitos-Chave

```javascript
document.addEventListener('keydown', function(e) {
  e.preventDefault();

  // Acessar propriedades do evento
  const keyData = {
    key: e.key,        // "a", "Enter", "Shift"
    code: e.code,      // "KeyA", "Enter", "ShiftLeft"
    keyCode: e.keyCode // 65, 13, 16 (numérico, obsoleto)
  };

  // Atualizar o DOM com as informações da tecla
  document.getElementById('keyValue').textContent = keyData.key;
  document.getElementById('keyCode').textContent = keyData.code;
  document.getElementById('keyCodeNumber').textContent = keyData.keyCode;
});
```

## Projeto: Progress Steps

O projeto **Progress Steps** demonstra manipulação do DOM com um formulário de múltiplas etapas. Usa `classList`, manipulação de estilos e event listeners para criar um wizard interativo.

### Conceitos-Chave

```javascript
const circles = document.querySelectorAll('.circle');
let currentActive = 1;

// Atualizar estado visual dos círculos de etapas
function updateCircles() {
  circles.forEach((circle, index) => {
    if (index < currentActive) {
      circle.classList.add('active');
    } else {
      circle.classList.remove('active');
    }
  });
}

// Atualizar largura da barra de progresso
function updateProgress() {
  const progressPercent = ((currentActive - 1) / (circles.length - 1)) * 100;
  document.getElementById('progress').style.width = progressPercent + '%';
}
```
