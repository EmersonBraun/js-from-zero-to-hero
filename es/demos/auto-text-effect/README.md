# Auto Text Effect

> [pt-br version](README-PTBR.md)

A dynamic typing animation application with multiple effects, customizable settings, and real-time statistics.

![Auto Text Effect](gifs/class.gif)

## CLASS

### Features

- **Multiple Effects**: Typewriter, Matrix, Glitch, Rainbow, Bounce, and Fade effects
- **Customizable Speed**: Adjustable typing speed from 50ms to 500ms
- **Cursor Styles**: Various cursor styles including vertical line, underscore, block, and more
- **Text Presets**: Pre-built text samples for quick testing
- **Real-time Statistics**: Track characters typed, words, time, and WPM
- **Auto Repeat**: Continuous typing with customizable pause duration
- **Color Customization**: Change text color and font size
- **History Tracking**: Save and manage typing sessions

### How to Use

1. **Enter Text**: Type or paste text in the input area
2. **Choose Effect**: Select from 6 different typing effects
3. **Adjust Settings**: Modify speed, cursor style, and colors
4. **Start Typing**: Click "Start Typing" to begin the animation
5. **Control Playback**: Pause, reset, or clear as needed
6. **Save Settings**: Save your preferences for future use

### Effect Types

- **Typewriter**: Classic typewriter effect with blinking cursor
- **Matrix**: Green terminal-style effect with glow
- **Glitch**: Digital glitch effect with random movements
- **Rainbow**: Animated rainbow color gradient
- **Bounce**: Bouncing character animation
- **Fade**: Smooth fade-in effect for each character

### Cursor Styles

- **Vertical Line (|)**: Traditional typewriter cursor
- **Underscore (_)**: Classic underscore cursor
- **Block (█)**: Solid block cursor
- **Half Block (▋)**: Semi-transparent block
- **Circle (●)**: Circular cursor
- **None**: No cursor display

### Controls

- **Typing Speed**: 50ms (fast) to 500ms (slow)
- **Auto Repeat**: Enable/disable continuous typing
- **Pause Duration**: 500ms to 5000ms between repeats
- **Text Color**: Custom color picker
- **Font Size**: 12px to 72px adjustable

### Text Presets

- **Greeting**: Welcome message
- **Pangram**: "The quick brown fox..." (contains all letters)
- **Lorem Ipsum**: Classic placeholder text
- **Emoji Text**: Fun emoji-filled message
- **Inspirational**: Motivational quote
- **Programming**: Coding-related text

### Statistics Tracking

- **Characters Typed**: Total character count
- **Words Typed**: Word count calculation
- **Typing Time**: Duration of typing session
- **WPM**: Words per minute calculation

### File Operations

- **Save Settings**: Store preferences in local storage
- **Load Settings**: Restore saved preferences
- **Export Text**: Download typed text as file
- **History Management**: View and restore previous sessions

### Technologies Used

- HTML5
- CSS3 (with animations and effects)
- Vanilla JavaScript
- Local Storage API
- Canvas API (for effects)
- Web Animations API
