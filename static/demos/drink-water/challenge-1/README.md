# Drink Water - Challenge 1

> [pt-br version](README-PTBR.md)

A water intake tracker with visual cup interface, daily goals, and progress tracking.

## CLASS

Basic water tracking with:
- Visual cup interface with water level
- Daily water consumption tracking
- Goal progress monitoring
- Glass counting system
- Local storage persistence
- Notification system

## CHALLENGE 01

Implement a complete water intake tracking system:

### Requirements:
- [x] **Visual Cup Interface**: Animated water cup with fill level
- [x] **Daily Statistics**: Track glasses consumed, total water, and goal progress
- [x] **Interactive Glasses**: Click to add/remove glasses from daily count
- [x] **Water Animations**: Smooth water level transitions and splash effects
- [x] **Goal Tracking**: Visual progress towards daily water goal
- [x] **Local Storage**: Persist daily data across browser sessions
- [x] **Notification System**: User feedback for all actions
- [x] **Keyboard Shortcuts**: Quick actions with keyboard controls
- [x] **History View**: View today's drinking history
- [x] **Reset Functionality**: Reset daily progress when needed

### Features:
- **Animated Water Cup**: Visual representation of current water level
- **Daily Goal Tracking**: Progress towards 2000ml daily goal (configurable)
- **Glass Management**: Interactive glasses showing daily intake
- **Smart Drinking**: Drink from cup or add glasses directly
- **Visual Feedback**: Color-coded progress and animations
- **Data Persistence**: Save progress automatically
- **Responsive Design**: Works on all screen sizes

### Controls:
- **Mouse**: Click drink/refill buttons, click glasses to toggle
- **Keyboard**: 
  - Space: Drink water
  - R: Refill cup
  - Escape: Close notifications
- **Touch**: All controls work on mobile devices

### Daily Goal:
- **Default Goal**: 2000ml (8 glasses of 250ml each)
- **Progress Tracking**: Visual percentage and color indicators
- **Flexible System**: Add or remove glasses as needed
