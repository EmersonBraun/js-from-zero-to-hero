# Arrays & Objects

Arrays and objects are the backbone of JavaScript data management. Mastering them — along with modern syntax like destructuring and spread — will dramatically improve how you write and reason about code.

## Theory

### Arrays

An array is an ordered list of values. JavaScript arrays are dynamic and can hold mixed types.

```js
const fruits = ["apple", "banana", "cherry"];
console.log(fruits[0]); // "apple"
console.log(fruits.length); // 3
```

#### Common Array Methods

| Method | Description |
|--------|-------------|
| `push(val)` | Add to end |
| `pop()` | Remove from end |
| `shift()` | Remove from start |
| `unshift(val)` | Add to start |
| `slice(start, end)` | Return a portion (non-mutating) |
| `splice(start, deleteCount, ...items)` | Insert/remove in place (mutating) |
| `indexOf(val)` | Find index of value (-1 if not found) |
| `includes(val)` | Check if value exists |
| `find(fn)` | Return first matching element |
| `filter(fn)` | Return all matching elements |
| `map(fn)` | Transform every element |
| `reduce(fn, init)` | Accumulate to a single value |

MDN Reference: [Array](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Array)

### Objects

An object stores key-value pairs. Keys are strings (or Symbols); values can be anything.

```js
const person = { name: "Alice", age: 30 };
console.log(person.name);       // dot notation
console.log(person["age"]);     // bracket notation

const key = "name";
console.log(person[key]);       // dynamic key access
```

#### Object Utility Methods

- `Object.keys(obj)` — array of keys
- `Object.values(obj)` — array of values
- `Object.entries(obj)` — array of `[key, value]` pairs
- `Object.assign(target, source)` — shallow merge
- `Object.freeze(obj)` — prevent modifications

MDN Reference: [Object](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Object)

### Destructuring

Extract values from arrays or objects into variables.

```js
// Array destructuring
const [first, second, ...rest] = [1, 2, 3, 4, 5];

// Object destructuring
const { name, age, city = "Unknown" } = person;

// Nested
const { address: { street } } = { address: { street: "Main St" } };
```

MDN Reference: [Destructuring assignment](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Operators/Destructuring_assignment)

### Spread and Rest Operators

```js
// Spread: expand an iterable
const combined = [...arr1, ...arr2];
const clone = { ...obj };

// Rest: collect remaining elements
function sum(...numbers) {
  return numbers.reduce((a, b) => a + b, 0);
}
```

MDN Reference: [Spread syntax](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Operators/Spread_syntax)

### Shallow vs Deep Copy

```js
// Shallow copy — nested objects are still shared
const shallow = { ...original };

// Deep copy — fully independent clone
const deep = JSON.parse(JSON.stringify(original));
// Or using structuredClone (modern):
const deep2 = structuredClone(original);
```

### Map and Set

```js
// Map — like an object, but any key type; preserves insertion order
const map = new Map();
map.set("key", 42);
map.get("key"); // 42
map.has("key"); // true

// Set — collection of unique values
const set = new Set([1, 2, 2, 3]);
set.size; // 3
set.has(2); // true
```

MDN References: [Map](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Map) | [Set](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Set)

### Walkthrough

The core logic maps each choice to what it beats:

```js
const rules = {
  rock: "scissors",
  paper: "rock",
  scissors: "paper",
};

function getResult(player, computer) {
  if (player === computer) return "draw";
  return rules[player] === computer ? "win" : "lose";
}
```

The scoreboard is stored in a `Map` so any string key (player name) can be used:

```js
const scoreboard = new Map();

function updateScore(player, result) {
  const current = scoreboard.get(player) ?? { wins: 0, losses: 0, draws: 0 };
  current[result === "win" ? "wins" : result === "lose" ? "losses" : "draws"]++;
  scoreboard.set(player, current);
}
```

## Summary

- Arrays have a rich set of built-in methods; prefer **non-mutating** ones (`map`, `filter`, `slice`) when you don't want side effects.
- Objects store structured data; `Object.entries` + `map` lets you transform them like arrays.
- **Destructuring** and **spread** reduce boilerplate and make intent clearer.
- Use `structuredClone` (or `JSON.parse(JSON.stringify(...))`) for deep copies of nested data.
- `Map` and `Set` are better choices than plain objects when you need ordered key-value storage or unique value collections.
