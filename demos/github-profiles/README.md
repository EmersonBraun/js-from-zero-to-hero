# Github Profiles

> [pt-br version](README-PTBR.md)

A comprehensive GitHub profile viewer with search, statistics, favorites, and comparison features.

![Github Profiles](gifs/class.gif)

## CLASS

### Features

- **Profile Search**: Search any GitHub user by username
- **Profile Display**: Complete profile information with avatar, bio, and stats
- **Repository List**: View user's repositories with sorting options
- **Multiple Themes**: Dark, Light, GitHub, and Neon themes
- **Display Modes**: Card, Compact, and Detailed view options
- **Favorites System**: Save and manage favorite profiles
- **Recent Searches**: Quick access to previously searched profiles
- **Statistics Panel**: Detailed profile statistics and metrics
- **Responsive Design**: Works perfectly on all devices

### How to Use

1. **Search Profiles**: Enter a GitHub username and click search
2. **View Information**: See profile details, repositories, and statistics
3. **Customize Display**: Choose themes and display modes
4. **Manage Favorites**: Add profiles to favorites for quick access
5. **Compare Profiles**: Compare multiple profiles side by side
6. **Export Data**: Download profile information in various formats

### Profile Information Displayed

- **Avatar**: User profile picture with hover effects
- **Name & Username**: Full name and GitHub username
- **Bio**: User's biography and description
- **Statistics**: Followers, following, public repos, and public gists
- **Links**: Profile, blog, and location information
- **Repositories**: List of public repositories with details

### Repository Features

- **Sorting Options**: Sort by stars, forks, updated date, or name
- **Repository Limit**: Adjust number of repositories displayed (5-50)
- **Repository Details**: Name, description, language, stars, forks, and update date
- **Interactive Cards**: Hover effects and clickable repository cards

### Controls

- **Theme Selection**: Choose from 4 different visual themes
- **Display Mode**: Switch between card, compact, and detailed views
- **Repository Sorting**: Sort repositories by different criteria
- **Repository Limit**: Control number of repositories shown

### Search Features

- **Auto-suggestions**: Search suggestions as you type
- **Recent Searches**: Quick access to previous searches
- **Error Handling**: Clear error messages for invalid usernames
- **Loading States**: Visual feedback during API calls

### Favorites System

- **Add to Favorites**: Save profiles for quick access
- **Favorites Grid**: Visual grid of saved profiles
- **Quick Access**: Click favorites to load profiles instantly
- **Local Storage**: Favorites persist across browser sessions

### Statistics Tracking

- **Total Repositories**: Count of all public repositories
- **Total Stars**: Sum of stars across all repositories
- **Total Forks**: Sum of forks across all repositories
- **Account Age**: Days since account creation

### Technologies Used

- HTML5
- CSS3 (with animations and effects)
- Vanilla JavaScript
- GitHub REST API
- Local Storage API
- Fetch API
