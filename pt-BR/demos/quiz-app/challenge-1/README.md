## Demo

The application allows users to:
1. Start a quiz with 10 random questions
2. Answer multiple-choice questions within a 60-second timer
3. See immediate feedback for correct/incorrect answers
4. View detailed results including:
   - Final score and percentage
   - Time used
   - Number of correct/wrong answers
   - Performance-based message
5. Restart the quiz to try again

## Features

### Core Functionality:
- **Question Display**: Clear presentation of questions and options
- **Answer Selection**: Click to select answers with visual feedback
- **Timer**: 60-second countdown for each quiz session
- **Scoring**: Real-time score tracking
- **Results**: Comprehensive results page with statistics

### User Experience:
- **Question Shuffling**: Questions appear in random order
- **Visual Feedback**: Immediate indication of correct/incorrect answers
- **Progress Tracking**: Current question number and total questions
- **Responsive Design**: Works on desktop and mobile devices
- **Smooth Animations**: Transitions between questions and states

### Quiz Management:
- **Start Quiz**: Begin a new quiz session
- **Next Question**: Proceed to the next question after answering
- **Restart**: Start a new quiz with fresh questions
- **Timer Management**: Automatic quiz completion when time runs out

## Sample Questions

The quiz includes questions from various topics:
- Geography (capitals, countries)
- Science (planets, chemistry)
- History (important dates)
- Art (famous artists)
- Mathematics (basic geometry)
- Biology (animals, nature)

## Scoring System

- **Excellent (80-100%)**: "Excellent! 🎉"
- **Good (60-79%)**: "Good Job! 👍"
- **Average (40-59%)**: "Not Bad! 😊"
- **Below Average (0-39%)**: "Keep Learning! 📚"
