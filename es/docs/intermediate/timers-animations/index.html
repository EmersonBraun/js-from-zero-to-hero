Temporizadores y Animaciones

JavaScript puede programar código para ejecutarse en el futuro, repetirse en un intervalo y sincronizarse con el ciclo de renderizado del navegador. Estas capacidades son la base de las cuentas regresivas, los juegos y las animaciones fluidas.

Teoría​

setTimeout​

setTimeout programa una función para ejecutarse una vez después de un retraso (en milisegundos).

const id = setTimeout(() => {
  console.log("Esto se ejecuta después de 2 segundos");
}, 2000);

// Cancelar antes de que se ejecute:
clearTimeout(id);

El callback se coloca en la cola de tareas después del retraso y se ejecuta cuando la pila de llamadas está vacía — así que los retrasos son tiempos mínimos, no garantizados.

Referencia MDN: setTimeout

setInterval​

setInterval llama a una función repetidamente en un intervalo fijo.

let count = 0;
const id = setInterval(() => {
  count++;
  console.log(`Tick ${count}`);
  if (count === 5) clearInterval(id);
}, 1000);

Siempre guarda el ID para poder detener el intervalo con clearInterval cuando hayas terminado — olvidar limpiarlo es una fuente común de fugas de memoria.

Referencia MDN: setInterval

clearTimeout y clearInterval​

Tanto clearTimeout como clearInterval aceptan el ID numérico devuelto por sus respectivas funciones de programación.

const timerId = setTimeout(fn, 5000);
clearTimeout(timerId); // fn nunca se ejecuta

const intervalId = setInterval(fn, 500);
clearInterval(intervalId); // detiene las llamadas repetidas

requestAnimationFrame​

requestAnimationFrame (rAF) programa un callback para ejecutarse antes del siguiente repintado, aproximadamente 60 veces por segundo (cada ~16.7 ms). Es la herramienta preferida para animaciones porque:

  • Se pausa cuando la pestaña está oculta (ahorra CPU/batería).
  • Se sincroniza con la tasa de refresco de la pantalla.
  • Evita el tartamudeo visual que puede causar setInterval.
function animate(timestamp) {
  // timestamp es un DOMHighResTimeStamp
  draw(timestamp);
  requestAnimationFrame(animate); // programar el siguiente frame
}
requestAnimationFrame(animate); // iniciar el bucle

Para detener un bucle rAF, llama a cancelAnimationFrame(id) con el ID devuelto.

Referencia MDN: requestAnimationFrame

Animaciones CSS Disparadas por JavaScript​

Puedes iniciar animaciones CSS alternando clases con JavaScript:

/* style.css */
.ball {
  transition: transform 0.5s ease;
}
.ball.jump {
  transform: translateY(-150px);
}
const ball = document.querySelector(".ball");
ball.classList.add("jump");

setTimeout(() => ball.classList.remove("jump"), 500);

Para secuencias más complejas, la Web Animations API te permite controlar animaciones completamente desde JS:

element.animate(
  [{ transform: "translateY(0)" }, { transform: "translateY(-150px)" }],
  { duration: 400, easing: "ease-out", fill: "forwards" }
);

Referencia MDN: Web Animations API

Bucles de Juego​

Un bucle de juego actualiza el estado y redibuja la pantalla lo más rápido posible. Usar requestAnimationFrame proporciona un bucle fluido y eficiente en batería:

let lastTime = 0;

function gameLoop(timestamp) {
  const delta = timestamp - lastTime; // tiempo desde el último frame (ms)
  lastTime = timestamp;

  update(delta); // mover objetos, verificar colisiones
  render();      // dibujar todo

  requestAnimationFrame(gameLoop);
}

requestAnimationFrame(gameLoop);

Usar delta (tiempo transcurrido) en lugar de un paso fijo hace que el juego sea independiente de la tasa de frames — corre a la misma velocidad en una pantalla de 60 Hz y una de 120 Hz.

Proyecto 1: Temporizador de Cuenta Regresiva​

Un temporizador visual de cuenta regresiva que muestra minutos y segundos, con controles de inicio, pausa y reinicio.

Demo en Vivo​

Guía​

El estado del temporizador es un objeto simple actualizado por setInterval:

let intervalId = null;
let remaining = 0; // segundos

function start() {
  if (intervalId) return; // ya está corriendo
  intervalId = setInterval(() => {
    if (remaining <= 0) {
      clearInterval(intervalId);
      intervalId = null;
      onFinish();
      return;
    }
    remaining--;
    render();
  }, 1000);
}

function pause() {
  clearInterval(intervalId);
  intervalId = null;
}

function reset(seconds) {
  pause();
  remaining = seconds;
  render();
}

function render() {
  const m = String(Math.floor(remaining / 60)).padStart(2, "0");
  const s = String(remaining % 60).padStart(2, "0");
  display.textContent = `${m}:${s}`;
}

Puntos clave:

  • Guarda el ID del intervalo para poder limpiarlo.
  • Rastrea remaining separado de la pantalla.
  • padStart(2, "0") asegura formato de dos dígitos.

Proyecto 2: Mario Jump​

Un juego de plataformas de desplazamiento lateral en el que Mario debe saltar sobre obstáculos. Construido con requestAnimationFrame y alternancia de clases CSS.

Demo en Vivo​

Guía​

const mario = document.querySelector(".mario");
const obstacle = document.querySelector(".obstacle");

let gameOver = false;
let animationId;

function jump() {
  if (mario.classList.contains("jump")) return;
  mario.classList.add("jump");
  setTimeout(() => mario.classList.remove("jump"), 500);
}

function checkCollision() {
  const marioRect = mario.getBoundingClientRect();
  const obstacleRect = obstacle.getBoundingClientRect();
  return (
    marioRect.right > obstacleRect.left &&
    marioRect.left < obstacleRect.right &&
    marioRect.bottom > obstacleRect.top &&
    marioRect.top < obstacleRect.bottom
  );
}

function gameLoop() {
  if (checkCollision()) {
    gameOver = true;
    obstacle.style.animation = "none";
    return;
  }
  animationId = requestAnimationFrame(gameLoop);
}

document.addEventListener("keydown", (e) => {
  if (e.code === "Space" && !gameOver) jump();
});

requestAnimationFrame(gameLoop);

El movimiento horizontal del obstáculo está manejado por una animación de keyframe CSS, manteniendo el bucle JS enfocado puramente en la detección de colisiones.

Desafío 1 – Doble Salto​

Permite que Mario salte una segunda vez mientras está en el aire (doble salto). Rastrea el conteo de saltos con una variable y reinícialo cuando Mario aterrice.

Desafío 2 – Contador de Puntuación​

Agrega una puntuación en vivo que aumenta cada segundo que el jugador sobrevive. Muestra una puntuación máxima en localStorage para que persista entre sesiones.

Resumen​

  • setTimeout ejecuta código una vez después de un retraso; siempre guarda y limpia el ID cuando hayas terminado.
  • setInterval repite código en un horario fijo; siempre limpialo para prevenir fugas de memoria.
  • requestAnimationFrame es la herramienta correcta para animaciones y bucles de juego — se sincroniza con la pantalla, se pausa cuando la pestaña está oculta y evita el tartamudeo.
  • La alternancia de clases CSS es una forma limpia de disparar transiciones CSS y animaciones de keyframe desde JavaScript.
  • El tiempo delta hace que los bucles de juego sean independientes de la tasa de frames: multiplica las velocidades por el tiempo transcurrido en lugar de un paso fijo.
  • El patrón debounce (construido sobre setTimeout) evita que una función que se dispara rápidamente se ejecute hasta que el usuario haga una pausa.
