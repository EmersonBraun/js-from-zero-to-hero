Functions

Functions are reusable blocks of code that perform a specific task. They are one of the most important concepts in JavaScript — they help you organize code, avoid repetition, and build complex programs from smaller pieces.

Function Declaration​

The classic way to define a function:

function greet(name) {
  return "Hello, " + name + "!";
}

console.log(greet("Alice"));  // "Hello, Alice!"

Parts of a function:

  • function keyword
  • Name (greet)
  • Parameters (name) — inputs the function accepts
  • Body ({ ... }) — the code that runs
  • return — the output value (optional)

MDN Reference: Functions

Function Expression​

A function stored in a variable:

const greet = function(name) {
  return "Hello, " + name + "!";
};

The difference: function declarations are hoisted (can be called before they are defined), function expressions are not.

Arrow Functions​

A shorter syntax introduced in ES6:

const greet = (name) => {
  return "Hello, " + name + "!";
};

// Even shorter for single expressions:
const greet = (name) => "Hello, " + name + "!";

// Single parameter — parentheses optional:
const double = n => n * 2;

MDN Reference: Arrow functions

Parameters and Arguments​

  • Parameters are the names listed in the function definition
  • Arguments are the actual values passed when calling the function
function add(a, b) {   // a, b are parameters
  return a + b;
}

add(3, 5);  // 3, 5 are arguments

Default Parameters​

Provide fallback values when arguments are not passed:

function greet(name = "World") {
  return `Hello, ${name}!`;
}

greet();        // "Hello, World!"
greet("Alice"); // "Hello, Alice!"

Rest Parameters​

Collect multiple arguments into an array:

function sum(...numbers) {
  let total = 0;
  for (const num of numbers) {
    total += num;
  }
  return total;
}

sum(1, 2, 3);     // 6
sum(10, 20, 30, 40); // 100

Return Values​

Functions can return a value using return. If no return statement is used, the function returns undefined:

function add(a, b) {
  return a + b;  // Returns a value
}

function logMessage(msg) {
  console.log(msg);  // No return — returns undefined
}

A function stops executing when it hits a return:

function checkAge(age) {
  if (age < 0) return "Invalid age";  // Early return
  if (age >= 18) return "Adult";
  return "Minor";
}

Scope​

Scope determines where a variable is accessible:

let globalVar = "I'm global";

function myFunction() {
  let localVar = "I'm local";
  console.log(globalVar);  // OK — can access global
  console.log(localVar);   // OK — can access local
}

myFunction();
// console.log(localVar);  // ERROR — localVar is not defined here

Functions create their own scope. Variables declared inside a function are not accessible outside it.

Project: BMI Calculator​

Let's apply functions to a real project! The BMI Calculator takes height and weight as inputs and calculates the Body Mass Index.

How It Works​

The BMI formula is: BMI = weight (kg) / height (m)²

The core function demonstrates parameters, return values, and early returns:

function calculate() {
  const height = document.getElementById('height').value;
  const weight = document.getElementById('weight').value;
  if (!height || !weight) return;  // Early return if inputs are empty
  const bmi = weight / height ** 2;
  document.getElementById('bmi').textContent = `${(bmi * 10000).toFixed(2)} BMI`;
}

Key concepts:

  • Function with no parameters — reads values from the DOM
  • Early return pattern — if (!height || !weight) return
  • Exponentiation operator ** and .toFixed(2) for formatting

Challenges​

Challenge 1: BMI Categories​

Extend the calculator to show the BMI category (Severe Thinness, Normal, Overweight, etc.) using a function with multiple if statements:

function getBMIType(value) {
  if (value < 16) return 'Severe Thinness';
  if (value <= 17) return 'Moderate Thinness';
  if (value <= 18.5) return 'Mild Thinness';
  if (value <= 25) return 'Normal';
  if (value <= 30) return 'Overweight';
  if (value <= 35) return 'Obese Class I';
  if (value <= 40) return 'Obese Class II';
  return 'Obese Class III';
}

Challenge 2: Ideal Weight​

Add a function that calculates the ideal weight based on a BMI of 22.5, and shows the difference:

function calculateBMIIdeal(height, weight) {
  const idealWeight = (height ** 2 * 22.5 / 10000).toFixed(2);
  const diff = (idealWeight - weight).toFixed(2);
  return `Ideal weight: ${idealWeight} kg (${diff > 0 ? '+' : ''}${diff}kg)`;
}
