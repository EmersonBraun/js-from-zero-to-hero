# Introduction to JavaScript

Welcome to your first step into the world of JavaScript! This module will teach you what JavaScript is, how it runs in the browser, and how to write your very first lines of code.

## What is JavaScript?

**JavaScript** (often abbreviated as **JS**) is a lightweight, interpreted programming language that is one of the three core technologies of the World Wide Web, alongside HTML and CSS.

- **HTML** defines the structure of a web page (headings, paragraphs, buttons)
- **CSS** defines the presentation and styling (colors, fonts, layout)
- **JavaScript** defines the behavior (what happens when you click a button, how data is validated, animations)

JavaScript was created in 1995 by Brendan Eich in just 10 days while he was working at Netscape. Despite its name, JavaScript has no relation to the Java programming language — the name was a marketing decision.

Today, JavaScript is the most widely used programming language in the world. It runs in every web browser, on servers (via Node.js), in mobile apps, desktop apps, and even IoT devices.

> **MDN Reference:** [What is JavaScript?](https://developer.mozilla.org/en-US/docs/Learn/JavaScript/First_steps/What_is_JavaScript)

## How JavaScript Runs in the Browser

Every modern web browser (Chrome, Firefox, Safari, Edge) has a built-in **JavaScript engine** that can execute JavaScript code:

| Browser | Engine |
|---|---|
| Chrome | V8 |
| Firefox | SpiderMonkey |
| Safari | JavaScriptCore |
| Edge | V8 |

When a browser loads a web page, it:
1. Parses the **HTML** to build the DOM (Document Object Model)
2. Applies **CSS** styles
3. Executes any **JavaScript** code it finds

## The Browser Console

The **browser console** is a developer tool built into every browser where you can type and execute JavaScript code immediately. It is your best friend for learning and debugging.

### How to open it:
- **Chrome/Edge:** Press `F12` or `Ctrl+Shift+J` (Windows/Linux) or `Cmd+Option+J` (Mac)
- **Firefox:** Press `F12` or `Ctrl+Shift+K` (Windows/Linux) or `Cmd+Option+K` (Mac)
- **Safari:** Enable Developer menu in Preferences, then press `Cmd+Option+C`

Try opening your browser console right now and typing:

```javascript
2 + 2
```

You should see `4` as the result. The console **evaluates** the expression and shows the result.

## `console.log()` — Your First Tool

`console.log()` is a function that prints (logs) a message to the browser console. It is the most basic and most used debugging tool in JavaScript.

```javascript
console.log("Hello, World!");
```

This will print `Hello, World!` in the console.

You can log multiple values separated by commas:

```javascript
console.log("My name is", "Emerson");
console.log("2 + 2 =", 2 + 2);
```

You can also log numbers, booleans, and expressions:

```javascript
console.log(42);
console.log(true);
console.log(10 > 5);
```

> **MDN Reference:** [console.log()](https://developer.mozilla.org/en-US/docs/Web/API/console/log_static)

## Adding JavaScript to an HTML Page

There are two main ways to add JavaScript to a web page:

### 1. Inline Script (inside the HTML file)

Use the `<script>` tag directly in your HTML:

```html
<!DOCTYPE html>
<html>
<head>
  <title>My First JS Page</title>
</head>
<body>
  <h1>Hello!</h1>

  <script>
    console.log("This script runs when the page loads!");
    document.querySelector("h1").textContent = "Hello from JavaScript!";
  </script>
</body>
</html>
```

**Important:** Place the `<script>` tag at the **bottom of the `<body>`** so that the HTML elements are loaded before the script tries to access them.

### 2. External Script (separate `.js` file)

Create a separate file (e.g., `index.js`) and link it:

```html
<!-- index.html -->
<body>
  <h1>Hello!</h1>
  <script src="index.js"></script>
</body>
```

```javascript
// index.js
console.log("This comes from an external file!");
```

**This is the preferred approach** for real projects because it keeps your code organized and reusable.

> **MDN Reference:** [What went wrong? Troubleshooting JavaScript](https://developer.mozilla.org/en-US/docs/Learn/JavaScript/First_steps/What_went_wrong)

## Comments

Comments are notes in your code that JavaScript ignores. They help you (and others) understand what the code does.

```javascript
// This is a single-line comment

/*
  This is a
  multi-line comment
*/

console.log("This runs"); // You can also comment at the end of a line
```

## Your First Program

Let's put it all together. Here is a simple program that greets the user:

```javascript
// My first JavaScript program
let name = "World";
console.log("Hello, " + name + "!");
console.log("Welcome to JavaScript!");
```

This program:
1. Creates a **variable** called `name` with the value `"World"`
2. **Concatenates** (joins) strings together using `+`
3. Prints two messages to the console

Don't worry if you don't fully understand variables and string concatenation yet — we will cover them in detail in the next module!

## Summary

In this module you learned:

- **JavaScript** is the programming language of the web, running in every browser
- The **browser console** lets you execute JS code directly
- **`console.log()`** prints messages to the console
- The **`<script>`** tag adds JavaScript to an HTML page
- **Comments** help document your code (`//` for single-line, `/* */` for multi-line)
- You can use **operators** like `+`, `*`, `%`, `>` to work with values
- **Strings** have useful properties and methods like `.length` and `.toUpperCase()`
