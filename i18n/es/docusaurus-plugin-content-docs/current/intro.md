# JS de Cero a Héroe

Bienvenido a **JS de Cero a Héroe** — un curso completo de JavaScript que te lleva desde principiante absoluto hasta desarrollador avanzado a través de proyectos prácticos y ejercicios interactivos.

## Estructura del Curso

Este curso está organizado en tres niveles:

### Principiante

Empieza aquí si nunca has escrito una línea de JavaScript. Aprenderás los fundamentos: variables, tipos, operadores, condicionales, bucles, funciones y manipulación del DOM.

### Intermedio

Construye sobre tus bases con arrays, objetos, funciones de orden superior, temporizadores, Canvas API, Local Storage y APIs del navegador. Cada módulo incluye proyectos del mundo real que puedes construir y demostrar.

### Avanzado

Domina los conceptos más profundos: closures, la palabra clave `this`, prototipos, JavaScript asíncrono, módulos ES, metaprogramación y buenas prácticas de seguridad.

## Cómo Usar Este Curso

Cada módulo sigue una estructura consistente:

1. **Teoría** — conceptos clave explicados con ejemplos y referencias a la documentación de MDN
2. **Ejercicios** — ejercicios de programación interactivos que puedes ejecutar directamente en tu navegador
3. **Proyectos** — proyectos del mundo real con guías paso a paso y demos en vivo
4. **Desafíos** — variaciones progresivamente más difíciles para poner a prueba tu comprensión

¡Elige un módulo en la barra lateral y comienza a aprender!
