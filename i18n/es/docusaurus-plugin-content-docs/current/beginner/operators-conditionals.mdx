# Operadores y Condicionales

En este módulo aprenderás cómo realizar cálculos, comparar valores y tomar decisiones en tu código. Estos son los bloques de construcción que hacen que los programas sean dinámicos e interactivos.

## Operadores Aritméticos

JavaScript soporta todas las operaciones matemáticas básicas:

| Operador | Nombre | Ejemplo | Resultado |
|---|---|---|---|
| `+` | Suma | `5 + 3` | `8` |
| `-` | Resta | `10 - 4` | `6` |
| `*` | Multiplicación | `3 * 7` | `21` |
| `/` | División | `20 / 4` | `5` |
| `%` | Módulo (resto) | `10 % 3` | `1` |
| `**` | Exponenciación | `2 ** 3` | `8` |

El **operador módulo** (`%`) devuelve el resto de una división. Es muy útil para verificar si un número es par o impar:

```javascript
10 % 2  // 0 → par (sin resto)
7 % 2   // 1 → impar (resto de 1)
```

> **Referencia MDN:** [Operadores aritméticos](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Operators#arithmetic_operators)

## Operadores de Comparación

Los operadores de comparación comparan dos valores y devuelven un **booleano** (`true` o `false`):

| Operador | Significado | Ejemplo | Resultado |
|---|---|---|---|
| `===` | Igualdad estricta | `5 === 5` | `true` |
| `!==` | Desigualdad estricta | `5 !== 3` | `true` |
| `>` | Mayor que | `10 > 5` | `true` |
| `<` | Menor que | `3 < 7` | `true` |
| `>=` | Mayor o igual que | `5 >= 5` | `true` |
| `<=` | Menor o igual que | `3 <= 2` | `false` |

### `===` vs `==`

JavaScript tiene dos operadores de igualdad:

- **`===` (igualdad estricta)** — compara tanto el valor COMO el tipo. **Siempre usa este.**
- **`==` (igualdad débil)** — compara valores con coerción de tipos (puede producir resultados inesperados)

```javascript
5 === 5      // true (mismo valor, mismo tipo)
5 === "5"    // false (tipos diferentes: number vs string)
5 == "5"     // true (débil: ¡convierte string a número!)
```

**Regla general:** Siempre usa `===` y `!==` para evitar bugs causados por la coerción de tipos.

> **Referencia MDN:** [Operadores de comparación](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Operators/Comparison_Operators)

## Operadores Lógicos

Los operadores lógicos combinan expresiones booleanas:

| Operador | Nombre | Descripción |
|---|---|---|
| `&&` | AND | `true` si AMBOS lados son true |
| `\|\|` | OR | `true` si AL MENOS UN lado es true |
| `!` | NOT | Invierte el valor booleano |

```javascript
true && true    // true
true && false   // false
true || false   // true
false || false  // false
!true           // false
!false          // true
```

Ejemplo práctico:

```javascript
let age = 25;
let hasLicense = true;

// Puede manejar: debe tener 18+ Y tener licencia
let canDrive = age >= 18 && hasLicense;  // true
```

> **Referencia MDN:** [Operadores lógicos](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Operators/Logical_AND)

## Sentencias `if / else`

La sentencia `if` ejecuta código solo cuando una condición es `true`:

```javascript
let temperature = 35;

if (temperature > 30) {
  console.log("¡Hace calor afuera!");
}
```

Agrega un bloque `else` para cuando la condición es `false`:

```javascript
let temperature = 15;

if (temperature > 30) {
  console.log("¡Hace calor afuera!");
} else {
  console.log("No hace tanto calor.");
}
```

Usa `else if` para múltiples condiciones:

```javascript
let temperature = 15;

if (temperature > 30) {
  console.log("¡Hace calor!");
} else if (temperature > 20) {
  console.log("Está templado.");
} else if (temperature > 10) {
  console.log("Está fresco.");
} else {
  console.log("¡Hace frío!");
}
```

> **Referencia MDN:** [if...else](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Statements/if...else)

## Sentencia `switch`

Cuando necesitas comparar un valor contra muchas opciones, `switch` es más limpio que múltiples `if/else if`:

```javascript
let day = "Monday";

switch (day) {
  case "Monday":
    console.log("Inicio de semana");
    break;
  case "Friday":
    console.log("¡Casi fin de semana!");
    break;
  case "Saturday":
  case "Sunday":
    console.log("¡Fin de semana!");
    break;
  default:
    console.log("Día normal");
}
```

**Importante:** ¡No olvides la sentencia `break`! Sin ella, la ejecución "cae" al siguiente caso.

> **Referencia MDN:** [switch](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Statements/switch)

## Operador Ternario

El operador ternario es una forma abreviada para sentencias `if/else` simples:

```javascript
// Sintaxis: condición ? valorSiVerdadero : valorSiFalso

let age = 20;
let status = age >= 18 ? "adult" : "minor";
// status es "adult"
```

Esto es equivalente a:

```javascript
let status;
if (age >= 18) {
  status = "adult";
} else {
  status = "minor";
}
```

El operador ternario es excelente para condiciones cortas y simples. Para lógica compleja, usa `if/else`.

> **Referencia MDN:** [Operador condicional (ternario)](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Operators/Conditional_operator)

## Proyecto: Switch Light

¡Ahora apliquemos lo que aprendiste a un proyecto real! **Switch Light** es una bombilla interactiva que responde a eventos del mouse usando condicionales.

### Cómo Funciona

El proyecto tiene una imagen de bombilla que cambia según la interacción del usuario:

- **Pasar el mouse** sobre la bombilla → la luz se ENCIENDE
- **Alejar el mouse** → la luz se APAGA
- **Hacer clic** en la bombilla → la luz se ROMPE (y queda rota)

La lógica principal usa **condicionales** y **indicadores booleanos** para controlar el estado:

```javascript
let broken = false;

function changeLight(element, type) {
  // Si ya está rota, no hacer nada (retorno anticipado con condicional)
  if (broken === true) return;

  element.srcElement.src = `images/light-${type}.png`;

  if (type === 'broken') {
    broken = true;  // Una vez rota, se queda rota
  }
}
```

Conceptos clave demostrados:
- **Variables booleanas** (`broken`) para rastrear estado
- **Sentencias `if`** para lógica condicional y retornos anticipados
- **Template literals** para strings dinámicos
- **Event listeners** (`mouseenter`, `mouseleave`, `click`) para la interacción del usuario

### Guía Paso a Paso

**1. Estructura HTML**

El HTML es simple — una imagen y un botón:

```html
<div class="container">
  <div class="box">
    <img id="light" src="images/light-off.png" alt="light">
  </div>
  <div class="box">
    <button id="btn" class="button" onclick="toogleType()">NORMAL</button>
  </div>
</div>
<script src="index.js"></script>
```

**2. Variables de Estado**

Tres variables rastrean el estado actual de la luz:

```javascript
let broken = false;  // ¿Está rota la luz?
let on = true;       // ¿Está encendida actualmente?
let type = 'NORMAL'; // Modo actual: NORMAL o SWITCH
```

**3. Event Listeners**

La imagen de la luz escucha tres eventos:

```javascript
const light = document.getElementById('light');

light.addEventListener('mouseenter', (element) => changeLight(element, 'on'));
light.addEventListener('mouseleave', (element) => changeLight(element, 'off'));
light.addEventListener('click', (element) => {
  if (type === 'NORMAL') {
    changeLight(element, 'broken');
  } else {
    toogleLight(element);
  }
});
```

Observa cómo el handler de `click` usa un **`if/else`** para decidir el comportamiento según el modo actual.

**4. El Operador Ternario en Acción**

El botón de cambio de modo usa un **operador ternario**:

```javascript
function toogleType() {
  type = type === 'NORMAL' ? 'SWITCH' : 'NORMAL';
  document.getElementById('btn').textContent = type;
  broken = false;
}
```

**5. Retorno Anticipado Condicional**

La función `changeLight` usa un patrón de retorno anticipado con condicionales:

```javascript
function changeLight(element, tipo) {
  if (broken === true || type === 'SWITCH') return;
  element.srcElement.src = `images/light-${tipo}.png`;
  if (tipo === 'broken') {
    broken = true;
  }
}
```

El operador `||` (OR) combina dos condiciones: si la luz está rota O el modo es SWITCH, no hacer nada.

## Resumen

En este módulo aprendiste:

- **Operadores aritméticos** (`+`, `-`, `*`, `/`, `%`, `**`) para cálculos

- **Operadores lógicos** (`&&`, `||`, `!`) para combinar condiciones
- Sentencias **`if/else`** para ejecución condicional
