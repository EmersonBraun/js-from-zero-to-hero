## Demo

The application allows users to:
1. Draw freely on a digital canvas using mouse or touch
2. Choose from various colors using the color picker
3. Adjust brush size from 1 to 50 pixels
4. Switch between brush and eraser tools
5. Undo and redo drawing actions
6. Clear the canvas and start over
7. Save drawings as PNG images
8. Track drawing statistics (strokes, time)
9. Use keyboard shortcuts for quick access
10. Auto-save progress to prevent data loss

## Keyboard Shortcuts

- **B**: Switch to brush tool
- **E**: Switch to eraser tool
- **Ctrl/Cmd + Z**: Undo
- **Ctrl/Cmd + Shift + Z**: Redo
- **Ctrl/Cmd + Y**: Redo (alternative)
- **Ctrl/Cmd + S**: Save drawing
- **Ctrl/Cmd + C**: Clear canvas
- **Escape**: Stop drawing
