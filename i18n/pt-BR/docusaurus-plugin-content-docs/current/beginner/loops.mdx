# Loops

Loops permitem que você repita um bloco de código várias vezes. Eles são essenciais para iterar sobre dados, automatizar tarefas repetitivas e construir aplicações dinâmicas.

## Loop `for`

O loop mais comum. Você controla o **início**, a **condição** e o **passo**:

```javascript
for (let i = 0; i < 5; i++) {
  console.log(i);  // 0, 1, 2, 3, 4
}
```

As três partes:
1. **Inicialização:** `let i = 0` — executado uma vez antes do loop começar
2. **Condição:** `i < 5` — verificado antes de cada iteração; o loop para quando for false
3. **Atualização:** `i++` — executado após cada iteração

### Padrões comuns

```javascript
// Contar de trás para frente
for (let i = 10; i > 0; i--) {
  console.log(i);  // 10, 9, 8, ..., 1
}

// Pular de 2 em 2
for (let i = 0; i <= 10; i += 2) {
  console.log(i);  // 0, 2, 4, 6, 8, 10
}
```

> **Referência MDN:** [for](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Statements/for)

## Loop `while`

Repete enquanto uma condição for `true`. Use quando você não sabe quantas iterações precisará:

```javascript
let count = 0;
while (count < 5) {
  console.log(count);  // 0, 1, 2, 3, 4
  count++;
}
```

**Aviso:** Se a condição nunca se tornar false, você terá um **loop infinito** que congela seu programa!

## Loop `do...while`

Como `while`, mas garante pelo menos **uma execução**:

```javascript
let num = 10;
do {
  console.log(num);  // 10 (executa uma vez mesmo que a condição seja false)
  num++;
} while (num < 5);
```

> **Referência MDN:** [while](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Statements/while), [do...while](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Statements/do...while)

## Loop `for...of`

Itera sobre **valores** de objetos iteráveis (arrays, strings):

```javascript
const fruits = ["apple", "banana", "cherry"];
for (const fruit of fruits) {
  console.log(fruit);  // "apple", "banana", "cherry"
}

// Funciona com strings também
for (const char of "Hello") {
  console.log(char);  // "H", "e", "l", "l", "o"
}
```

## Loop `for...in`

Itera sobre **chaves** (nomes de propriedades) de um objeto:

```javascript
const person = { name: "Alice", age: 25, city: "NYC" };
for (const key in person) {
  console.log(`${key}: ${person[key]}`);
}
// "name: Alice", "age: 25", "city: NYC"
```

**Dica:** Use `for...of` para arrays, `for...in` para objetos.

> **Referência MDN:** [for...of](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Statements/for...of), [for...in](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Statements/for...in)

## `break` e `continue`

- **`break`** — sai do loop imediatamente
- **`continue`** — pula para a próxima iteração

```javascript
// break: parar quando encontrar 3
for (let i = 0; i < 10; i++) {
  if (i === 3) break;
  console.log(i);  // 0, 1, 2
}

// continue: pular números pares
for (let i = 0; i < 6; i++) {
  if (i % 2 === 0) continue;
  console.log(i);  // 1, 3, 5
}
```

## Resumo

Neste módulo você aprendeu:

- **Loop `for`** — quando você sabe o número de iterações
- **Loop `while`** — quando precisa iterar até que uma condição seja atendida
- **`do...while`** — garante pelo menos uma execução
- **`for...of`** — itera sobre valores (arrays, strings)
- **`for...in`** — itera sobre chaves (objetos)
- **`break`** sai do loop, **`continue`** pula para a próxima iteração
- Como resolver problemas comuns com loops: somas, inversões, buscas
