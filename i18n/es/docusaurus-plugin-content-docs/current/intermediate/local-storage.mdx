# Local Storage y Persistencia de Datos

Los navegadores modernos proveen APIs de almacenamiento integradas que permiten que tus aplicaciones JavaScript recuerden datos entre recargas de página y sesiones del navegador — sin necesitar un servidor o base de datos. En este módulo dominarás `localStorage`, `sessionStorage` y los patrones de serialización JSON necesarios para almacenar datos complejos.

**Referencias MDN:**
- [Window.localStorage](https://developer.mozilla.org/en-US/docs/Web/API/Window/localStorage)
- [Window.sessionStorage](https://developer.mozilla.org/en-US/docs/Web/API/Window/sessionStorage)

## Teoría

### La API localStorage

`localStorage` es un almacén clave-valor vinculado al origen actual (protocolo + nombre de host + puerto). Los datos persisten indefinidamente hasta que se borran explícitamente.

```js
// Almacenar un valor
localStorage.setItem('username', 'Alice');

// Recuperar un valor (devuelve null si la clave no existe)
const name = localStorage.getItem('username'); // 'Alice'

// Eliminar una clave específica
localStorage.removeItem('username');

// Borrar TODAS las claves de este origen
localStorage.clear();

// Verificar cuántas claves están almacenadas
console.log(localStorage.length);

// Iterar sobre todas las claves
for (let i = 0; i < localStorage.length; i++) {
  const key = localStorage.key(i);
  const value = localStorage.getItem(key);
  console.log(key, value);
}
```

> **Importante:** `localStorage` solo almacena cadenas de texto. Para almacenar objetos o arrays, debes serializarlos.

---

### JSON.stringify y JSON.parse

Como `localStorage` solo acepta cadenas, `JSON.stringify` convierte objetos/arrays a cadenas JSON, y `JSON.parse` los convierte de vuelta:

```js
// Almacenar un objeto
const user = { name: 'Alice', age: 30, hobbies: ['coding', 'reading'] };
localStorage.setItem('user', JSON.stringify(user));

// Recuperar y analizar
const stored = localStorage.getItem('user');
const parsed = JSON.parse(stored);
console.log(parsed.name); // 'Alice'

// Análisis seguro (maneja null y JSON malformado)
function safeGet(key, defaultValue = null) {
  try {
    const item = localStorage.getItem(key);
    return item !== null ? JSON.parse(item) : defaultValue;
  } catch (e) {
    return defaultValue;
  }
}
```

### Patrones CRUD

Un patrón estándar para gestionar una colección en `localStorage`:

```js
const STORAGE_KEY = 'my-todos';

// Crear — agregar un nuevo elemento
function createItem(text) {
  const items = readAll();
  const newItem = { id: Date.now(), text, done: false, createdAt: new Date().toISOString() };
  items.push(newItem);
  localStorage.setItem(STORAGE_KEY, JSON.stringify(items));
  return newItem;
}

// Leer — obtener todos los elementos
function readAll() {
  const raw = localStorage.getItem(STORAGE_KEY);
  return raw ? JSON.parse(raw) : [];
}

// Actualizar — cambiar estado completado
function updateItem(id, changes) {
  const items = readAll();
  const updated = items.map(item => item.id === id ? { ...item, ...changes } : item);
  localStorage.setItem(STORAGE_KEY, JSON.stringify(updated));
}

// Eliminar — remover por id
function deleteItem(id) {
  const items = readAll().filter(item => item.id !== id);
  localStorage.setItem(STORAGE_KEY, JSON.stringify(items));
}
```

### Estrategias de Persistencia de Datos

Al diseñar aplicaciones respaldadas por localStorage, considera:

- **Versionado:** Almacena una clave `_version` junto con tus datos. Si la versión almacenada difiere de la versión de la app, migra o restablece los datos.
- **Cuota:** `localStorage` está típicamente limitado a ~5MB por origen. Almacena solo lo necesario.
- **Expiración:** `localStorage` no tiene TTL integrado. Si necesitas expiración, almacena una marca de tiempo y verifícala al leer.

```js
function setWithExpiry(key, value, ttlMs) {
  const item = { value, expiry: Date.now() + ttlMs };
  localStorage.setItem(key, JSON.stringify(item));
}

function getWithExpiry(key) {
  const raw = localStorage.getItem(key);
  if (!raw) return null;
  const item = JSON.parse(raw);
  if (Date.now() > item.expiry) {
    localStorage.removeItem(key);
    return null;
  }
  return item.value;
}
```

---

### sessionStorage vs localStorage

| Característica | `localStorage` | `sessionStorage` |
|---|---|---|
| Persistencia | Hasta que se borre explícitamente | Hasta que se cierre la pestaña/ventana |
| Alcance | Todas las pestañas del mismo origen | Solo una pestaña |
| Capacidad | ~5MB | ~5MB |
| API | Idéntica | Idéntica |

Usa `sessionStorage` para estado temporal como borradores de formularios o pasos de un asistente donde no quieres que los datos persistan entre sesiones.

Una aplicación de lista de tareas completa que recuerda tus tareas entre recargas de página usando `localStorage`.

**Conceptos clave:** Operaciones CRUD, serialización JSON, delegación de eventos, renderizado dinámico del DOM desde el estado almacenado.

#### Cómo Funciona

Al cargar la página, las tareas se leen de `localStorage` y se renderizan en el DOM. Cada mutación (agregar, alternar, eliminar) actualiza tanto el DOM como `localStorage` inmediatamente.

```js
const STORAGE_KEY = 'js-hero-todos';

function loadTodos() {
  return JSON.parse(localStorage.getItem(STORAGE_KEY) || '[]');
}

function saveTodos(todos) {
  localStorage.setItem(STORAGE_KEY, JSON.stringify(todos));
}

function renderTodo(todo, listEl) {
  const li = document.createElement('li');
  li.dataset.id = todo.id;
  if (todo.done) li.classList.add('done');

  const span = document.createElement('span');
  span.textContent = todo.text;

  const toggleBtn = document.createElement('button');
  toggleBtn.className = 'toggle';
  toggleBtn.textContent = 'Done';

  const deleteBtn = document.createElement('button');
  deleteBtn.className = 'delete';
  deleteBtn.textContent = 'Remove';

  li.append(span, toggleBtn, deleteBtn);
  listEl.appendChild(li);
}

function renderTodos(todos, listEl) {
  listEl.replaceChildren(); // limpiar elementos existentes de forma segura
  todos.forEach(todo => renderTodo(todo, listEl));
}
```

Cada día obtiene su propia clave de `localStorage` basada en la fecha actual (ej.: `water-2024-03-15`). Las claves antiguas se limpian automáticamente al cargar.

```js
function getTodayKey() {
  return `water-${new Date().toISOString().split('T')[0]}`;
}

function getIntake() {
  return parseInt(localStorage.getItem(getTodayKey()) || '0', 10);
}

function addCup(ml) {
  const current = getIntake();
  localStorage.setItem(getTodayKey(), String(current + ml));
  updateUI();
}
```

## Resumen

En este módulo aprendiste:

- Las APIs `localStorage` y `sessionStorage`: `setItem`, `getItem`, `removeItem`, `clear`.
- Por qué se requiere la serialización JSON y cómo usar `JSON.stringify` y `JSON.parse` de forma segura.
- Un patrón **CRUD completo** para gestionar colecciones en almacenamiento del lado del cliente.
- Estrategias para manejar la cuota de almacenamiento, expiración de datos con TTL y migraciones de esquema.
- Las diferencias clave entre `localStorage` (persistente, entre pestañas) y `sessionStorage` (por pestaña, efímero).

La persistencia de datos es la puerta de entrada a aplicaciones reales. La Lista de Tareas, el Juego de Memoria y el Rastreador de Agua demuestran cómo la misma API simple puede potenciar una amplia variedad de proyectos prácticos.
