# Theme Clock

> [pt-br version](README-PTBR.md)

A beautiful analog and digital clock with multiple themes, customizable settings, and alarm functionality.

![Theme Clock](gifs/class.gif)

## CLASS

### Features

- **Analog Clock**: Beautiful hand-drawn clock face with smooth animations
- **Digital Display**: Clean digital time and date display
- **Multiple Themes**: 6 different visual themes (Dark, Light, Sunset, Ocean, Forest, Neon)
- **Time Formats**: 12-hour and 24-hour time display options
- **Clock Types**: Analog, digital, or both display modes
- **Real-time Updates**: Accurate time synchronization
- **Additional Info**: Day of year, week number, timezone, and Unix timestamp
- **Responsive Design**: Works perfectly on all devices

### How to Use

1. **Change Theme**: Select from 6 beautiful themes
2. **Switch Clock Type**: Choose between analog, digital, or both displays
3. **Time Format**: Toggle between 12-hour and 24-hour formats
4. **Freeze Time**: Pause the clock for testing or demonstration
5. **Sync Time**: Synchronize with accurate time servers
6. **Set Alarms**: Create custom alarms with repeat options

### Controls

- **Theme Selector**: Choose visual theme
- **Clock Type**: Switch between display modes
- **Time Format**: Toggle 12/24 hour format
- **Freeze Button**: Pause clock updates
- **Sync Button**: Synchronize with accurate time
- **Alarm Button**: Set custom alarms

### Themes Available

- **Dark**: Classic dark theme with subtle gradients
- **Light**: Clean light theme with soft shadows
- **Sunset**: Warm sunset colors with pink gradients
- **Ocean**: Cool blue ocean-inspired theme
- **Forest**: Natural green forest theme
- **Neon**: Cyberpunk neon theme with glowing effects

### Clock Information

- **Current Time**: Real-time clock display
- **Current Date**: Full date with day name
- **Day of Year**: Current day number (1-366)
- **Week of Year**: Current week number (1-53)
- **Timezone**: Current timezone information
- **Unix Timestamp**: Current Unix timestamp

### Technologies Used

- HTML5
- CSS3 (with animations and gradients)
- Vanilla JavaScript
- Date API
- Local Storage API
- Google Fonts (Roboto)
