# Callbacks y Funciones de Orden Superior

Las funciones son **ciudadanos de primera clase** en JavaScript — pueden almacenarse en variables, pasarse como argumentos y retornarse desde otras funciones. Este módulo explora esa idea a través de callbacks y funciones de orden superior.

## Teoría

### Funciones de Primera Clase

JavaScript trata las funciones como cualquier otro valor. Puedes:

```js
// Asignar a una variable
const greet = function(name) { return `Hello, ${name}!`; };

// Almacenar en un array
const operations = [Math.sqrt, Math.abs, Math.ceil];

// Pasar como argumento
setTimeout(() => console.log("delayed"), 1000);
```

Referencia MDN: [First-class Function](https://developer.mozilla.org/en-US/docs/Glossary/First-class_Function)

### Callbacks

Un **callback** es una función pasada a otra función para ser llamada más tarde — ya sea de forma síncrona o asíncrona.

```js
function doTwice(fn) {
  fn();
  fn();
}

doTwice(() => console.log("hello")); // "hello" impreso dos veces
```

Patrones comunes donde aparecen los callbacks:

- Métodos de array (`forEach`, `map`, `filter`, `sort`)
- Event listeners (`addEventListener`)
- Operaciones asíncronas (`setTimeout`, `fetch`)

### Funciones de Orden Superior (HOF)

Una **función de orden superior** ya sea:
1. Acepta una función como argumento, o
2. Retorna una función.

```js
// Acepta una función
function applyToAll(arr, fn) {
  return arr.map(fn);
}

// Retorna una función
function multiplier(factor) {
  return (n) => n * factor;
}
const double = multiplier(2);
double(5); // 10
```

Referencia MDN: [Funciones](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide/Functions)

### map, filter y reduce en Profundidad

Estos tres métodos de array son la base del procesamiento declarativo de arrays.

#### map

Transforma cada elemento; devuelve un nuevo array de la misma longitud.

```js
const prices = [10, 20, 30];
const withTax = prices.map(p => p * 1.2); // [12, 24, 36]
```

#### filter

Mantiene solo los elementos donde el callback devuelve `true`.

```js
const ages = [12, 20, 17, 25];
const adults = ages.filter(age => age >= 18); // [20, 25]
```

#### reduce

Acumula todos los elementos en un único valor. El callback recibe `(acumulador, valorActual)`.

```js
const numbers = [1, 2, 3, 4];
const sum = numbers.reduce((acc, n) => acc + n, 0); // 10

// Construir un objeto desde un array
const inventory = [
  { name: "apple", qty: 5 },
  { name: "banana", qty: 3 },
];
const totals = inventory.reduce((acc, item) => {
  acc[item.name] = item.qty;
  return acc;
}, {});
// { apple: 5, banana: 3 }
```

Referencias MDN: [map](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Array/map) | [filter](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Array/filter) | [reduce](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Array/reduce)

### Estilo Declarativo vs Imperativo

**Imperativo** — describe *cómo* hacer algo paso a paso:

```js
const result = [];
for (let i = 0; i < numbers.length; i++) {
  if (numbers[i] % 2 === 0) {
    result.push(numbers[i] * 2);
  }
}
```

**Declarativo** — describe *qué* quieres:

```js
const result = numbers.filter(n => n % 2 === 0).map(n => n * 2);
```

El estilo declarativo es más corto, más fácil de probar y más cercano a cómo piensas sobre el problema.

### Composición de Funciones

Combinar funciones pequeñas en funciones más grandes:

```js
const compose = (...fns) => (x) => fns.reduceRight((v, f) => f(v), x);

const add1 = x => x + 1;
const double = x => x * 2;
const square = x => x * x;

const transform = compose(square, double, add1);
transform(3); // square(double(add1(3))) = square(double(4)) = square(8) = 64
```

Este proyecto convierte enteros a números romanos usando una tabla de búsqueda y `reduce`.

### Guía

```js
const romanNumerals = [
  [1000, "M"], [900, "CM"], [500, "D"], [400, "CD"],
  [100, "C"],  [90, "XC"],  [50, "L"],  [40, "XL"],
  [10, "X"],   [9, "IX"],   [5, "V"],   [4, "IV"],
  [1, "I"],
];

function toRoman(num) {
  return romanNumerals.reduce((result, [value, symbol]) => {
    while (num >= value) {
      result += symbol;
      num -= value;
    }
    return result;
  }, "");
}
```

El callback de `reduce` actúa aquí como un iterador sobre la tabla de búsqueda — un patrón clásico de orden superior.

### Guía

```js
function binaryToDecimal(binaryStr) {
  return binaryStr
    .split("")
    .reverse()
    .reduce((acc, bit, index) => acc + Number(bit) * Math.pow(2, index), 0);
}
```

Observa cómo `reduce` reemplaza el bucle `for` manual — el acumulador construye el valor decimal bit a bit.

## Resumen

- Las funciones son valores de primera clase — almacénalas, pásalas y retórnalas libremente.
- Un **callback** es simplemente una función que le das a otra función para que la invoque en el momento correcto.
- Una **función de orden superior** es cualquier función que toma o retorna una función.
- `map`, `filter` y `reduce` forman el núcleo del procesamiento declarativo de arrays — prefierelos sobre los bucles `for` cuando transformes datos.
- La **composición de funciones** te permite construir pipelines poderosos a partir de piezas pequeñas y reutilizables.
- El estilo declarativo hace que tu intención sea más clara y tu código más fácil de probar.
