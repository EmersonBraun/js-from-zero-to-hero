# APIs do Navegador

Além do DOM, navegadores modernos expõem uma rica coleção de APIs JavaScript que desbloqueiam capacidades poderosas: interfaces de arrastar e soltar, geração e controle de áudio, tratamento aprofundado de eventos de teclado, acesso à área de transferência e muito mais. Neste módulo você vai trabalhar praticamente com as mais úteis dessas APIs.

**Referências MDN:**
- [HTML Drag and Drop API](https://developer.mozilla.org/en-US/docs/Web/API/HTML_Drag_and_Drop_API)
- [Web Audio API](https://developer.mozilla.org/en-US/docs/Web/API/Web_Audio_API)
- [KeyboardEvent](https://developer.mozilla.org/en-US/docs/Web/API/KeyboardEvent)
- [Clipboard API](https://developer.mozilla.org/en-US/docs/Web/API/Clipboard_API)
- [Vibration API](https://developer.mozilla.org/en-US/docs/Web/API/Vibration_API)

## Teoria

### API HTML5 de Arrastar e Soltar

Qualquer elemento pode ser tornado arrastável adicionando o atributo `draggable="true"` e escutando eventos de arrasto:

```js
// O elemento sendo arrastado dispara estes eventos:
// dragstart  → arrasto começa
// drag       → arrasto está em andamento
// dragend    → arrasto terminou (sucesso ou falha)

// O alvo de soltar dispara estes eventos:
// dragenter  → arrastável entra no alvo
// dragover   → arrastável está sobre o alvo (deve chamar preventDefault para permitir soltar)
// dragleave  → arrastável sai do alvo
// drop       → arrastável é solto no alvo

draggable.addEventListener('dragstart', (e) => {
  e.dataTransfer.setData('text/plain', draggable.id);
  e.dataTransfer.effectAllowed = 'move';
});

dropZone.addEventListener('dragover', (e) => {
  e.preventDefault(); // Obrigatório para permitir soltar
  e.dataTransfer.dropEffect = 'move';
});

dropZone.addEventListener('drop', (e) => {
  e.preventDefault();
  const id = e.dataTransfer.getData('text/plain');
  const el = document.getElementById(id);
  dropZone.appendChild(el);
});
```

O objeto `dataTransfer` é a ponte entre dragstart e drop — ele carrega qualquer dado que você queira passar entre eles.

### Fundamentos da Web Audio API

A Web Audio API permite gerar, processar e reproduzir áudio inteiramente em JavaScript usando um grafo de áudio de nós conectados:

```js
const audioCtx = new AudioContext();

// Criar um nó oscilador (gera um tom)
const oscillator = audioCtx.createOscillator();
oscillator.type = 'sine'; // 'sine' | 'square' | 'sawtooth' | 'triangle'
oscillator.frequency.setValueAtTime(440, audioCtx.currentTime); // nota A4

// Criar um nó de ganho (controla o volume)
const gainNode = audioCtx.createGain();
gainNode.gain.setValueAtTime(0.5, audioCtx.currentTime);

// Conectar: oscilador -> ganho -> alto-falantes
oscillator.connect(gainNode);
gainNode.connect(audioCtx.destination);

// Iniciar e parar
oscillator.start();
oscillator.stop(audioCtx.currentTime + 0.5); // parar após 0,5 segundos
```

Para um sound board, você tipicamente carrega arquivos de áudio com `fetch` e os decodifica:

```js
async function loadSound(url) {
  const response = await fetch(url);
  const arrayBuffer = await response.arrayBuffer();
  return audioCtx.decodeAudioData(arrayBuffer);
}

function playBuffer(buffer) {
  const source = audioCtx.createBufferSource();
  source.buffer = buffer;
  source.connect(audioCtx.destination);
  source.start();
}
```

### Eventos de Teclado em Profundidade

Eventos de teclado disparam nesta ordem: `keydown` → `keypress` (obsoleto) → `keyup`.

```js
document.addEventListener('keydown', (e) => {
  console.log(e.key);      // Nome da tecla legível: 'a', 'Enter', 'ArrowLeft'
  console.log(e.code);     // Tecla física: 'KeyA', 'Enter', 'ArrowLeft'
  console.log(e.keyCode);  // Código numérico legado (obsoleto, evite)

  // Teclas modificadoras
  console.log(e.ctrlKey, e.shiftKey, e.altKey, e.metaKey);

  // Detectar combinações
  if (e.ctrlKey && e.key === 'z') {
    e.preventDefault(); // Impedir o desfazer padrão do navegador
    handleUndo();
  }

  // Impedir comportamento padrão do navegador
  if (e.key === ' ') e.preventDefault(); // Impedir rolagem da página
});
```

A diferença entre `e.key` e `e.code`:
- `e.key` = o que a tecla produz (dependente do layout): `'a'` no QWERTY, `'q'` no AZERTY
- `e.code` = o local físico da tecla: sempre `'KeyA'` independente do layout

### Clipboard API

A API moderna `navigator.clipboard` é baseada em Promises e requer permissão do usuário:

```js
// Copiar texto para a área de transferência
async function copyText(text) {
  try {
    await navigator.clipboard.writeText(text);
    console.log('Copiado!');
  } catch (err) {
    console.error('Cópia falhou:', err);
  }
}

// Ler texto da área de transferência
async function pasteText() {
  try {
    const text = await navigator.clipboard.readText();
    console.log('Colado:', text);
    return text;
  } catch (err) {
    console.error('Colagem falhou:', err);
  }
}

// Copiar conteúdo rico (HTML, imagens)
async function copyHtml(html, plainText) {
  const item = new ClipboardItem({
    'text/html': new Blob([html], { type: 'text/html' }),
    'text/plain': new Blob([plainText], { type: 'text/plain' })
  });
  await navigator.clipboard.write([item]);
}
```

> A Clipboard API requer um contexto seguro (HTTPS ou localhost) e permissão do usuário.

### Visão Geral de Outras APIs do Navegador

| API | Propósito | Método Principal |
|---|---|---|
| `Geolocation` | Obter localização do usuário | `navigator.geolocation.getCurrentPosition()` |
| `Vibration` | Vibrar o dispositivo | `navigator.vibrate(200)` |
| `Notification` | Notificações do sistema | `new Notification('Title', { body: '...' })` |
| `IntersectionObserver` | Detectar visibilidade de elemento | `new IntersectionObserver(callback, options)` |
| `ResizeObserver` | Detectar redimensionamento de elemento | `new ResizeObserver(callback)` |
| `History API` | Manipular histórico do navegador | `history.pushState(state, '', '/path')` |
| `BroadcastChannel` | Comunicar entre abas | `new BroadcastChannel('channel-name')` |

}

function createHangmanGame(word) {
  const target = word.toLowerCase();
  const guessed = new Set();
  const maxWrong = 6;

  function guess(letter) {
    letter = letter.toLowerCase();
    if (guessed.has(letter)) return 'already-guessed';
    guessed.add(letter);
    return target.includes(letter) ? 'correct' : 'wrong';
  }

  function getMasked() {
    return target.split('').map(ch => guessed.has(ch) ? ch : '_').join('');
  }

  function getWrongCount() {
    return [...guessed].filter(l => !target.includes(l)).length;
  }

  function isWon() {
    return target.split('').every(ch => guessed.has(ch));
  }

  function isLost() {
    return getWrongCount() >= maxWrong;
  }

  function getStatus() {
    if (isWon()) return 'won';
    if (isLost()) return 'lost';
    return 'playing';
  }

  return { guess, getMasked, getWrongCount, isWon, isLost, getStatus };
}
`}

Uma lista interativa onde os itens podem ser reordenados arrastando, com feedback visual durante a operação de arrasto.

**Conceitos-chave:** Eventos `dragstart`, `dragover`, `drop`, `dragleave`, `dragend`, `dataTransfer`, classes CSS de feedback visual.

  style={{border: '1px solid var(--ifm-color-emphasis-300)', borderRadius: '8px'}}
  title="Drag and Drop Demo"

#### Como Funciona

Cada item da lista recebe `draggable="true"`. O evento `dragover` deve chamar `e.preventDefault()` para sinalizar que o soltar é permitido. A reordenação real acontece no handler `drop`.

```js
let dragSrc = null;

items.forEach(item => {
  item.setAttribute('draggable', 'true');

  item.addEventListener('dragstart', (e) => {
    dragSrc = item;
    e.dataTransfer.effectAllowed = 'move';
    item.classList.add('dragging');
  });

  item.addEventListener('dragend', () => {
    dragSrc = null;
    item.classList.remove('dragging');
    document.querySelectorAll('.drag-over').forEach(el => el.classList.remove('drag-over'));
  });

  item.addEventListener('dragover', (e) => {
    e.preventDefault();
    item.classList.add('drag-over');
  });

  item.addEventListener('dragleave', () => item.classList.remove('drag-over'));

  item.addEventListener('drop', (e) => {
    e.preventDefault();
    if (dragSrc && dragSrc !== item) {
      const list = item.parentNode;
      const allItems = [...list.children];
      const srcIdx = allItems.indexOf(dragSrc);
      const tgtIdx = allItems.indexOf(item);
      if (srcIdx < tgtIdx) {
        list.insertBefore(dragSrc, item.nextSibling);
      } else {
        list.insertBefore(dragSrc, item);
      }
    }
  });
});
```

#### Desafio 1

Adicione **alças de arrasto** — ícones pequenos que são a única região arrastável de cada item. O texto do item deve permanecer selecionável. Implemente isso fazendo apenas o elemento de alça o gatilho de arrasto, enquanto mantém o `<li>` completo como alvo de soltar.

const sounds = {

  const src = ctx.createBufferSource();
  src.buffer = buffer;
  src.connect(ctx.destination);
  src.start();

document.addEventListener('keydown', (e) => {

#### Como Funciona

O relógio usa CSS `transform: rotate()` aplicado aos elementos de ponteiro de hora, minuto e segundo. A rotação é calculada a partir da hora atual e atualizada a cada segundo com `setInterval`.

```js
function updateClock() {
  const now = new Date();
  const seconds = now.getSeconds();
  const minutes = now.getMinutes();
  const hours = now.getHours() % 12;

  const secondDeg = seconds * 6;          // 360 / 60
  const minuteDeg = minutes * 6 + seconds * 0.1;
  const hourDeg = hours * 30 + minutes * 0.5;

  secondHand.style.transform = `rotate(${secondDeg}deg)`;
  minuteHand.style.transform = `rotate(${minuteDeg}deg)`;
  hourHand.style.transform   = `rotate(${hourDeg}deg)`;
}

setInterval(updateClock, 1000);
updateClock(); // Executar imediatamente na carga
```

Neste módulo você aprendeu:

- A **API de Arrastar e Soltar**: tornando elementos arrastáveis, transferindo dados via `dataTransfer` e tratando todos os eventos do ciclo de vida do arrasto para construir listas reordenáveis totalmente interativas.
- Fundamentos da **Web Audio API**: o contexto de áudio, osciladores, nós de ganho, carregamento de buffers de áudio e reprodução de sons — a base de instrumentos e sound boards no navegador.
- **Eventos de teclado em profundidade**: a distinção entre `e.key` e `e.code`, detectando combinações de teclas modificadoras, impedindo comportamentos padrão do navegador e construindo um gerenciador de atalhos reutilizável.
- A **Clipboard API**: lendo e escrevendo texto e conteúdo rico na área de transferência do sistema de forma baseada em Promises e consciente de permissões.
- Uma visão geral de outras APIs poderosas do navegador: Geolocation, Vibration, Notifications, IntersectionObserver, ResizeObserver e mais.

Juntas, essas APIs expandem dramaticamente o que você pode construir com JavaScript no navegador — de jogos e ferramentas criativas a aplicações de produtividade que parecem verdadeiramente nativas.
