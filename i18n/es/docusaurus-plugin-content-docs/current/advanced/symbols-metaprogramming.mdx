# Symbols y Metaprogramación

La metaprogramación es la práctica de escribir código que opera sobre otro código — inspeccionándolo, modificando su comportamiento o interceptando sus operaciones en tiempo de ejecución. JavaScript proporciona tres pilares para esto: **Symbols** (claves únicas que evitan colisiones), **Proxy** (interceptar operaciones fundamentales de objetos) y **Reflect** (una API limpia para esas mismas operaciones).

---

## 1. ¿Qué Son los Symbols y Por Qué Existen?

Antes de los Symbols, todas las claves de objeto eran cadenas de texto. Esto creaba problemas cuando múltiples bibliotecas intentaban agregar propiedades al mismo objeto — los nombres podían colisionar silenciosamente.

`Symbol()` crea un **valor primitivo garantizado como único**. Dos symbols nunca son iguales, incluso si se crean con la misma descripción.

```js
const a = Symbol('id');
const b = Symbol('id');
console.log(a === b); // false — siempre únicos
console.log(typeof a); // "symbol"
console.log(a.toString()); // "Symbol(id)"
console.log(a.description); // "id"
```

Los symbols no son enumerables en bucles `for...in`, no aparecen en `Object.keys()` y son excluidos de `JSON.stringify()`. Esto los hace ideales para adjuntar metadatos o puntos de extensión sin contaminar las APIs públicas.

Referencia MDN: [Symbol](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Symbol)

---

## 2. Crear Symbols: `Symbol()` vs `Symbol.for()`

`Symbol()` siempre crea un nuevo symbol único.

`Symbol.for(key)` usa un **registro global de symbols** — retorna el mismo symbol para la misma cadena clave, entre realms (iframes, workers).

```js
const s1 = Symbol.for('app.user');
const s2 = Symbol.for('app.user');
console.log(s1 === s2); // true

// Búsqueda inversa
console.log(Symbol.keyFor(s1)); // "app.user"

// Los symbols locales no tienen clave de registro
const local = Symbol('local');
console.log(Symbol.keyFor(local)); // undefined
```

Usa `Symbol.for()` cuando necesites symbols compartidos entre realms o módulos. Usa `Symbol()` para puntos de extensión privados/internos.

## 3. Symbols como Claves de Objeto

```js
const ID = Symbol('id');
const ROLE = Symbol('role');

const user = {
  name: 'Alice',
  [ID]: 42,
  [ROLE]: 'admin',
};

console.log(user[ID]); // 42
console.log(Object.keys(user)); // ["name"] — symbols excluidos
console.log(Object.getOwnPropertySymbols(user)); // [Symbol(id), Symbol(role)]

// JSON.stringify ignora los symbols
console.log(JSON.stringify(user)); // {"name":"Alice"}
```

Las bibliotecas usan este patrón para adjuntar estado interno no enumerable a objetos de usuario sin arriesgar colisiones de claves.

## 4. Symbols Conocidos

JavaScript usa symbols integrados (almacenados en `Symbol.*`) para conectarse a comportamientos fundamentales del lenguaje. Estos se llaman **symbols conocidos**.

### `Symbol.iterator`

Define el iterador por defecto de un objeto. Usado por `for...of`, spread y desestructuración.

```js
class Counter {
  constructor(max) { this.max = max; }

  [Symbol.iterator]() {
    let n = 0, max = this.max;
    return {
      next() {
        return n < max
          ? { value: n++, done: false }
          : { value: undefined, done: true };
      }
    };
  }
}

console.log([...new Counter(4)]); // [0, 1, 2, 3]
```

### `Symbol.toPrimitive`

Controla cómo un objeto se coerciona a un primitivo (número, cadena o por defecto).

```js
class Temperature {
  constructor(celsius) { this.celsius = celsius; }

  [Symbol.toPrimitive](hint) {
    if (hint === 'number') return this.celsius;
    if (hint === 'string') return `${this.celsius}°C`;
    return this.celsius; // default
  }
}

const temp = new Temperature(22);
console.log(+temp);           // 22  (hint numérico)
console.log(`Temp: ${temp}`); // "Temp: 22°C"  (hint de cadena)
console.log(temp + 0);        // 22  (hint por defecto)
```

Referencia MDN: [Symbol.toPrimitive](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Symbol/toPrimitive)

### `Symbol.hasInstance`

Controla el comportamiento de `instanceof`.

```js
class EvenNumber {
  static [Symbol.hasInstance](value) {
    return typeof value === 'number' && value % 2 === 0;
  }
}

console.log(4 instanceof EvenNumber); // true
console.log(3 instanceof EvenNumber); // false
```

### `Symbol.toStringTag`

Personaliza la salida de `Object.prototype.toString()`.

```js
class Database {
  get [Symbol.toStringTag]() { return 'Database'; }
}

const db = new Database();
console.log(Object.prototype.toString.call(db)); // "[object Database]"
```

### `Symbol.species`

Especifica el constructor usado cuando se crean objetos derivados por métodos como `map`, `filter`, `slice`. Raramente necesario fuera del código de framework/biblioteca.

Referencia MDN: [Well-known symbols](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Symbol#well-known_symbols)

## 5. El Objeto Proxy

`Proxy` envuelve un objeto objetivo e intercepta operaciones fundamentales a través de **trampas del handler**. Cada operación que puedes realizar en un objeto tiene una trampa correspondiente.

```js
const proxy = new Proxy(target, handler);
```

El handler es un objeto cuyos métodos (trampas) interceptan operaciones en el objetivo.

Referencia MDN: [Proxy](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Proxy)

### Trampa `get`

```js
const handler = {
  get(target, prop, receiver) {
    console.log(`Getting: ${String(prop)}`);
    return Reflect.get(target, prop, receiver);
  }
};

const obj = new Proxy({ x: 1 }, handler);
obj.x; // registra "Getting: x", retorna 1
```

### Trampa `set`

```js
const validator = {
  set(target, prop, value, receiver) {
    if (prop === 'age' && (typeof value !== 'number' || value < 0)) {
      throw new TypeError('Age must be a non-negative number');
    }
    return Reflect.set(target, prop, value, receiver);
  }
};

const person = new Proxy({}, validator);
person.age = 25;  // OK
person.age = -1;  // TypeError
```

### Trampa `has`

Intercepta el operador `in`.

```js
const rangeProxy = new Proxy({}, {
  has(target, prop) {
    const num = Number(prop);
    return num >= 1 && num <= 100;
  }
});

console.log(50 in rangeProxy);  // true
console.log(101 in rangeProxy); // false
```

### Trampa `deleteProperty`

```js
const frozen = new Proxy({ a: 1, b: 2 }, {
  deleteProperty(target, prop) {
    console.warn(`Deletion of "${prop}" was blocked`);
    return false; // previene la eliminación
  }
});
```

### Trampa `apply`

Intercepta llamadas a funciones.

```js
function greet(name) { return `Hello, ${name}!`; }

const tracedGreet = new Proxy(greet, {
  apply(target, thisArg, args) {
    console.log(`Called with args: ${JSON.stringify(args)}`);
    return Reflect.apply(target, thisArg, args);
  }
});

tracedGreet('Alice'); // registra los argumentos, retorna "Hello, Alice!"
```

## 6. La API Reflect

`Reflect` proporciona métodos estáticos que reflejan cada trampa de Proxy. Sirve dos propósitos:

1. **Reenviar operaciones desde trampas de Proxy** — siempre usa `Reflect` en lugar de operar directamente en el objetivo para preservar el comportamiento correcto de `this` con herencia.
2. **Alternativas funcionales a operadores** — `Reflect.has(obj, key)` vs `key in obj`.

```js
// En lugar de:
target[prop] = value;
// Usar en trampas:
Reflect.set(target, prop, value, receiver);

// En lugar de:
delete target[prop];
Reflect.deleteProperty(target, prop);

// En lugar de:
new Ctor(...args);
Reflect.construct(Ctor, args);
```

Referencia MDN: [Reflect](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Reflect)

## 7. Patrones Prácticos de Metaprogramación

### Proxy de Validación

```js
function createValidated(schema) {
  return new Proxy({}, {
    set(target, prop, value) {
      if (schema[prop] && !schema[prop](value)) {
        throw new TypeError(`Validation failed for "${prop}"`);
      }
      return Reflect.set(target, prop, value);
    }
  });
}

const user = createValidated({
  name: v => typeof v === 'string' && v.length > 0,
  age: v => Number.isInteger(v) && v >= 0 && v <= 150,
});
```

### Proxy de Registro / Traza

```js
function createLogged(target, label = 'Object') {
  return new Proxy(target, {
    get(t, prop, receiver) {
      const value = Reflect.get(t, prop, receiver);
      if (typeof value === 'function') {
        return function(...args) {
          console.log(`[${label}] ${String(prop)}(${args.map(JSON.stringify).join(', ')})`);
          return value.apply(this, args);
        };
      }
      return value;
    }
  });
}
```

### Datos Reactivos (estilo Vue)

```js
function reactive(data, onChange) {
  return new Proxy(data, {
    set(target, prop, value, receiver) {
      const old = target[prop];
      const result = Reflect.set(target, prop, value, receiver);
      if (old !== value) onChange(prop, old, value);
      return result;
    }
  });
}

const state = reactive({ count: 0 }, (key, from, to) => {
  console.log(`${key}: ${from} → ${to}`);
});

state.count = 1; // registra "count: 0 → 1"
```

## Resumen

- Los **Symbols** son primitivos únicos y no enumerables usados como claves de objeto libres de colisiones o para adjuntar metadatos no públicos.
- `Symbol()` crea un symbol local siempre único; `Symbol.for(key)` registra y recupera symbols de un registro global.
- Los **symbols conocidos** son los ganchos de extensión para comportamientos integrados del lenguaje: `Symbol.iterator` (iteración), `Symbol.toPrimitive` (coerción), `Symbol.hasInstance` (`instanceof`), `Symbol.toStringTag` (etiqueta de tipo), `Symbol.species` (constructor derivado).
- **Proxy** envuelve cualquier objeto e intercepta operaciones a través de trampas (`get`, `set`, `has`, `deleteProperty`, `apply` y más).
- Siempre reenvía a **Reflect** dentro de las trampas de Proxy para preservar el comportamiento correcto de la cadena de prototipos.
- **Reflect** proporciona una API funcional que refleja cada trampa de Proxy y cada operador de objeto.
- Los patrones prácticos de metaprogramación incluyen **proxies de validación** (aplicar invariantes en la asignación), **proxies de registro** (rastrear todas las operaciones) y **datos reactivos** (disparar efectos secundarios en mutaciones, como se ve en Vue y MobX).
- Estos primitivos son la base de los frameworks modernos de JavaScript — entenderlos revela la maquinaria detrás de las propiedades computadas, el binding bidireccional y el estado observable.
