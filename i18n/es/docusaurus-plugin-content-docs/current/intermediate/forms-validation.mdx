# Formularios y Validación

Los formularios son la forma en que los usuarios envían datos a tu aplicación. JavaScript te permite leer valores, responder a la entrada del usuario en tiempo real, validar datos antes del envío y dar retroalimentación clara — todo sin recargar la página.

## Teoría

### Elementos de Formulario

Los principales elementos de formulario y cómo acceder a ellos en JavaScript:

| Elemento | Cómo obtener el valor |
|---------|-----------------|
| `<input type="text">` | `element.value` |
| `<input type="number">` | `Number(element.value)` |
| `<input type="checkbox">` | `element.checked` |
| `<input type="radio">` | `element.checked` en cada opción |
| `<select>` | `element.value` |
| `<textarea>` | `element.value` |

```js
const nameInput = document.querySelector("#name");
const ageInput  = document.querySelector("#age");
const colorSelect = document.querySelector("#color");

console.log(nameInput.value);   // texto actual
console.log(Number(ageInput.value));
console.log(colorSelect.value);
```

Referencia MDN: [HTMLInputElement](https://developer.mozilla.org/en-US/docs/Web/API/HTMLInputElement) | [HTMLSelectElement](https://developer.mozilla.org/en-US/docs/Web/API/HTMLSelectElement)

### Obtener y Establecer Valores de Formulario

Lee valores con `.value`, establécelos de la misma manera:

```js
// Leer
const text = input.value.trim(); // .trim() elimina espacios alrededor

// Escribir (actualizar la interfaz)
input.value = "texto por defecto";
checkbox.checked = true;
select.value = "option2"; // selecciona el <option> correspondiente
```

Para leer todos los campos a la vez, usa `FormData`:

```js
const form = document.querySelector("form");
const data = new FormData(form);

data.get("username"); // valor de input[name="username"]
Object.fromEntries(data); // convierte todos los campos a un objeto plano
```

Referencia MDN: [FormData](https://developer.mozilla.org/en-US/docs/Web/API/FormData)

### Eventos de Formulario

| Evento | Cuándo se dispara |
|-------|--------------|
| `input` | Cada tecla presionada / cambio de valor |
| `change` | Cuando un elemento pierde el foco después de que su valor cambió |
| `focus` | Cuando un elemento obtiene el foco |
| `blur` | Cuando un elemento pierde el foco |
| `submit` | Cuando se envía el formulario |
| `reset` | Cuando se restablece el formulario |

```js
input.addEventListener("input", (e) => {
  console.log(e.target.value); // valor en vivo con cada tecla
});

form.addEventListener("submit", (e) => {
  e.preventDefault(); // evita que la página se recargue
  validate(new FormData(form));
});
```

Referencia MDN: [HTMLElement: input event](https://developer.mozilla.org/en-US/docs/Web/API/HTMLElement/input_event) | [HTMLFormElement: submit event](https://developer.mozilla.org/en-US/docs/Web/API/HTMLFormElement/submit_event)

### Patrones Básicos de Validación

**Validación manual** — verifica los valores tú mismo y muestra mensajes de error:

```js
function validate(fields) {
  const errors = {};

  if (!fields.name || fields.name.trim().length < 2) {
    errors.name = "Name must be at least 2 characters.";
  }

  if (isNaN(fields.age) || fields.age < 0 || fields.age > 120) {
    errors.age = "Age must be a number between 0 and 120.";
  }

  return errors; // objeto vacío significa válido
}
```

**Constraint Validation API** — el navegador valida usando atributos HTML:

```html
<input type="email" required minlength="5" />
```

```js
input.checkValidity();   // true / false
input.validationMessage; // mensaje de error incorporado
form.checkValidity();    // true si todos los campos son válidos
```

### Fundamentos de Expresiones Regulares

Una **expresión regular** (regex) es un patrón para hacer coincidencias en cadenas de texto.

```js
// Probar si una cadena coincide con el patrón
/^\d{4}$/.test("2024");  // true — exactamente 4 dígitos
/^\d{4}$/.test("24");    // false

// Patrones comunes
const emailPattern = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;
const phonePattern = /^\+?[\d\s\-()]{7,15}$/;
const upperPattern = /[A-Z]/;
const numberPattern = /[0-9]/;
const specialPattern = /[!@#$%^&*]/;
```

Referencia MDN: [Regular Expressions](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide/Regular_expressions)

### Mostrar Retroalimentación de Validación

Un patrón común es agregar/eliminar clases CSS en el elemento contenedor:

```js
function showError(input, message) {
  const field = input.parentElement;
  field.classList.add("error");
  field.classList.remove("success");
  field.querySelector(".error-msg").textContent = message;
}

function showSuccess(input) {
  const field = input.parentElement;
  field.classList.remove("error");
  field.classList.add("success");
  field.querySelector(".error-msg").textContent = "";
}
```

### Cómo Funciona

El generador lee los estados de los checkboxes y un range input para componer el conjunto de caracteres:

```js
const CHARS = {
  lowercase: "abcdefghijklmnopqrstuvwxyz",
  uppercase: "ABCDEFGHIJKLMNOPQRSTUVWXYZ",
  numbers:   "0123456789",
  symbols:   "!@#$%^&*()_+-=[]{}|;:,.<>?",
};

function generatePassword(options) {
  const { length, useLower, useUpper, useNumbers, useSymbols } = options;

  let charset = "";
  if (useLower)   charset += CHARS.lowercase;
  if (useUpper)   charset += CHARS.uppercase;
  if (useNumbers) charset += CHARS.numbers;
  if (useSymbols) charset += CHARS.symbols;

  if (!charset) return ""; // ninguna opción seleccionada

  return Array.from({ length }, () =>
    charset[Math.floor(Math.random() * charset.length)]
  ).join("");
}
```

El formulario escucha eventos `input` en el slider de longitud para actualizar la pantalla en tiempo real:

```js
lengthSlider.addEventListener("input", () => {
  lengthDisplay.textContent = lengthSlider.value;
});

generateBtn.addEventListener("click", () => {
  const options = {
    length:     Number(lengthSlider.value),
    useLower:   lowercaseCheckbox.checked,
    useUpper:   uppercaseCheckbox.checked,
    useNumbers: numbersCheckbox.checked,
    useSymbols: symbolsCheckbox.checked,
  };
  output.value = generatePassword(options);
});
```

### Cómo Funciona

Las preguntas se almacenan como un array de objetos:

```js
const questions = [
  {
    question: "What does typeof null return?",
    choices: ["null", "undefined", "object", "string"],
    answer: "object",
  },
  {
    question: "Which method adds an element to the end of an array?",
    choices: ["push", "pop", "shift", "unshift"],
    answer: "push",
  },
];
```

El estado se rastrea en un objeto simple:

```js
let state = {
  currentIndex: 0,
  score: 0,
  answers: [],
};
```

El handler de `submit` lee el radio button seleccionado, lo compara con la respuesta y avanza a la siguiente pregunta:

```js
form.addEventListener("submit", (e) => {
  e.preventDefault();
  const selected = form.querySelector("input[name='choice']:checked");
  if (!selected) return; // nada seleccionado

  const answer = selected.value;
  const correct = questions[state.currentIndex].answer;
  const isCorrect = answer === correct;

  state.answers.push({ answer, isCorrect });
  if (isCorrect) state.score++;
  state.currentIndex++;

  if (state.currentIndex < questions.length) {
    renderQuestion();
  } else {
    renderResults();
  }
});
```

## Resumen

- Accede a los valores del formulario con `.value` (texto, número, select, textarea) y `.checked` (checkbox, radio).
- Usa `e.preventDefault()` en el evento `submit` para manejar formularios sin recargar la página.
- El evento `input` se dispara con cada tecla presionada — ideal para retroalimentación en tiempo real. El evento `change` se dispara cuando el foco abandona el elemento.
- `FormData` convierte un formulario completo a una colección clave-valor en una sola línea.
- La validación manual devuelve un objeto de errores; muestra mensajes al usuario y nunca asumas que la entrada es segura.
- Las expresiones regulares son poderosas para hacer coincidencias de patrones (emails, contraseñas, teléfonos) — pruébalas en [regex101.com](https://regex101.com).
- Siempre sanitiza la entrada del usuario antes de mostrarla en la página para prevenir XSS.
