# JS From Zero to Hero

Welcome to **JS From Zero to Hero** — a comprehensive JavaScript course that takes you from absolute beginner to advanced developer through hands-on projects and interactive exercises.

## Course Structure

This course is organized into three levels:

### Beginner

Start here if you have never written a line of JavaScript. You will learn the fundamentals: variables, types, operators, conditionals, loops, functions, and DOM manipulation.

### Intermediate

Build on your foundations with arrays, objects, higher-order functions, timers, Canvas API, Local Storage, and browser APIs. Each module includes real-world projects you can build and demo.

### Advanced

Master the deeper concepts: closures, the `this` keyword, prototypes, asynchronous JavaScript, ES modules, metaprogramming, and security best practices.

## How to Use This Course

Each module follows a consistent structure:

1. **Theory** — core concepts explained with examples and references to MDN documentation
2. **Exercises** — interactive coding exercises you can run directly in your browser
3. **Projects** — real-world projects with step-by-step walkthroughs and live demos
4. **Challenges** — progressively harder variations to test your understanding

Pick a module from the sidebar and start learning!
