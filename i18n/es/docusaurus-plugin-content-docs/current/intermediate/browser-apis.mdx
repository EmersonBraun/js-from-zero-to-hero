# APIs del Navegador

Más allá del DOM, los navegadores modernos exponen una rica colección de APIs de JavaScript que desbloquean capacidades poderosas: interfaces de arrastrar y soltar, generación y control de audio, manejo profundo de eventos de teclado, acceso al portapapeles y mucho más. En este módulo trabajarás de forma práctica con las más útiles de estas APIs.

**Referencias MDN:**
- [HTML Drag and Drop API](https://developer.mozilla.org/en-US/docs/Web/API/HTML_Drag_and_Drop_API)
- [Web Audio API](https://developer.mozilla.org/en-US/docs/Web/API/Web_Audio_API)
- [KeyboardEvent](https://developer.mozilla.org/en-US/docs/Web/API/KeyboardEvent)
- [Clipboard API](https://developer.mozilla.org/en-US/docs/Web/API/Clipboard_API)
- [Vibration API](https://developer.mozilla.org/en-US/docs/Web/API/Vibration_API)

## Teoría

### API HTML5 de Arrastrar y Soltar

Cualquier elemento puede hacerse arrastrable agregando el atributo `draggable="true"` y escuchando los eventos de arrastre:

```js
// El elemento que se arrastra dispara estos eventos:
// dragstart  → el arrastre comienza
// drag       → el arrastre está en progreso
// dragend    → el arrastre terminó (éxito o fallo)

// El destino del soltado dispara estos eventos:
// dragenter  → el arrastrable entra al destino
// dragover   → el arrastrable está sobre el destino (debe llamar preventDefault para permitir soltar)
// dragleave  → el arrastrable sale del destino
// drop       → el arrastrable se suelta en el destino

draggable.addEventListener('dragstart', (e) => {
  e.dataTransfer.setData('text/plain', draggable.id);
  e.dataTransfer.effectAllowed = 'move';
});

dropZone.addEventListener('dragover', (e) => {
  e.preventDefault(); // Requerido para permitir soltar
  e.dataTransfer.dropEffect = 'move';
});

dropZone.addEventListener('drop', (e) => {
  e.preventDefault();
  const id = e.dataTransfer.getData('text/plain');
  const el = document.getElementById(id);
  dropZone.appendChild(el);
});
```

El objeto `dataTransfer` es el puente entre dragstart y drop — transporta cualquier dato que quieras pasar entre ellos.

### Fundamentos de la Web Audio API

La Web Audio API te permite generar, procesar y reproducir audio completamente en JavaScript usando un grafo de audio de nodos conectados:

```js
const audioCtx = new AudioContext();

// Crear un nodo oscilador (genera un tono)
const oscillator = audioCtx.createOscillator();
oscillator.type = 'sine'; // 'sine' | 'square' | 'sawtooth' | 'triangle'
oscillator.frequency.setValueAtTime(440, audioCtx.currentTime); // nota A4

// Crear un nodo de ganancia (controla el volumen)
const gainNode = audioCtx.createGain();
gainNode.gain.setValueAtTime(0.5, audioCtx.currentTime);

// Conectar: oscilador -> ganancia -> altavoces
oscillator.connect(gainNode);
gainNode.connect(audioCtx.destination);

// Iniciar y detener
oscillator.start();
oscillator.stop(audioCtx.currentTime + 0.5); // detener después de 0.5 segundos
```

Para un tablero de sonidos, típicamente se cargan archivos de audio con `fetch` y se decodifican:

```js
async function loadSound(url) {
  const response = await fetch(url);
  const arrayBuffer = await response.arrayBuffer();
  return audioCtx.decodeAudioData(arrayBuffer);
}

function playBuffer(buffer) {
  const source = audioCtx.createBufferSource();
  source.buffer = buffer;
  source.connect(audioCtx.destination);
  source.start();
}
```

### Eventos de Teclado en Profundidad

Los eventos de teclado se disparan en este orden: `keydown` → `keypress` (obsoleto) → `keyup`.

```js
document.addEventListener('keydown', (e) => {
  console.log(e.key);      // Nombre legible de la tecla: 'a', 'Enter', 'ArrowLeft'
  console.log(e.code);     // Tecla física: 'KeyA', 'Enter', 'ArrowLeft'
  console.log(e.keyCode);  // Código numérico heredado (obsoleto, evitar)

  // Teclas modificadoras
  console.log(e.ctrlKey, e.shiftKey, e.altKey, e.metaKey);

  // Detectar combinaciones
  if (e.ctrlKey && e.key === 'z') {
    e.preventDefault(); // Prevenir deshacer del navegador
    handleUndo();
  }

  // Prevenir comportamiento predeterminado del navegador
  if (e.key === ' ') e.preventDefault(); // Prevenir scroll de página
});
```

La diferencia entre `e.key` y `e.code`:
- `e.key` = lo que produce la tecla (dependiente del diseño): `'a'` en QWERTY, `'q'` en AZERTY
- `e.code` = la ubicación física de la tecla: siempre `'KeyA'` sin importar el diseño

### Clipboard API

La API moderna `navigator.clipboard` es basada en promesas y requiere permiso del usuario:

```js
// Copiar texto al portapapeles
async function copyText(text) {
  try {
    await navigator.clipboard.writeText(text);
    console.log('Copied!');
  } catch (err) {
    console.error('Copy failed:', err);
  }
}

// Leer texto del portapapeles
async function pasteText() {
  try {
    const text = await navigator.clipboard.readText();
    console.log('Pasted:', text);
    return text;
  } catch (err) {
    console.error('Paste failed:', err);
  }
}

// Copiar contenido enriquecido (HTML, imágenes)
async function copyHtml(html, plainText) {
  const item = new ClipboardItem({
    'text/html': new Blob([html], { type: 'text/html' }),
    'text/plain': new Blob([plainText], { type: 'text/plain' })
  });
  await navigator.clipboard.write([item]);
}
```

> La Clipboard API requiere un contexto seguro (HTTPS o localhost) y permiso del usuario.

### Resumen de Otras APIs del Navegador

| API | Propósito | Método Principal |
|---|---|---|
| `Geolocation` | Obtener ubicación del usuario | `navigator.geolocation.getCurrentPosition()` |
| `Vibration` | Vibrar el dispositivo | `navigator.vibrate(200)` |
| `Notification` | Notificaciones del sistema | `new Notification('Title', { body: '...' })` |
| `IntersectionObserver` | Detectar visibilidad de elementos | `new IntersectionObserver(callback, options)` |
| `ResizeObserver` | Detectar cambio de tamaño de elementos | `new ResizeObserver(callback)` |
| `History API` | Manipular el historial del navegador | `history.pushState(state, '', '/path')` |
| `BroadcastChannel` | Comunicarse entre pestañas | `new BroadcastChannel('channel-name')` |

// Equal temperament: each semitone = 2^(1/12) ratio

function noteToFrequency(semitones) {

  return notes.map((semitones, i) => ({

}

function createHangmanGame(word) {
  const target = word.toLowerCase();
  const guessed = new Set();
  const maxWrong = 6;

  function guess(letter) {
    letter = letter.toLowerCase();
    if (guessed.has(letter)) return 'already-guessed';
    guessed.add(letter);
    return target.includes(letter) ? 'correct' : 'wrong';
  }

  function getMasked() {
    return target.split('').map(ch => guessed.has(ch) ? ch : '_').join('');
  }

  function getWrongCount() {
    return [...guessed].filter(l => !target.includes(l)).length;
  }

  function isWon() {
    return target.split('').every(ch => guessed.has(ch));
  }

  function isLost() {
    return getWrongCount() >= maxWrong;
  }

  function getStatus() {
    if (isWon()) return 'won';
    if (isLost()) return 'lost';
    return 'playing';
  }

  return { guess, getMasked, getWrongCount, isWon, isLost, getStatus };
}
`}

Una lista interactiva donde los elementos pueden reordenarse arrastrándolos, con retroalimentación visual durante la operación de arrastre.

**Conceptos clave:** Eventos `dragstart`, `dragover`, `drop`, `dragleave`, `dragend`, `dataTransfer`, clases CSS para retroalimentación visual.

  title="Drag and Drop Demo"

#### Cómo Funciona

Cada elemento de la lista obtiene `draggable="true"`. El evento `dragover` debe llamar `e.preventDefault()` para indicar que se permite soltar. El reordenamiento real ocurre en el handler de `drop`.

```js
let dragSrc = null;

items.forEach(item => {
  item.setAttribute('draggable', 'true');

  item.addEventListener('dragstart', (e) => {
    dragSrc = item;
    e.dataTransfer.effectAllowed = 'move';
    item.classList.add('dragging');
  });

  item.addEventListener('dragend', () => {
    dragSrc = null;
    item.classList.remove('dragging');
    document.querySelectorAll('.drag-over').forEach(el => el.classList.remove('drag-over'));
  });

  item.addEventListener('dragover', (e) => {
    e.preventDefault();
    item.classList.add('drag-over');
  });

  item.addEventListener('dragleave', () => item.classList.remove('drag-over'));

  item.addEventListener('drop', (e) => {
    e.preventDefault();
    if (dragSrc && dragSrc !== item) {
      const list = item.parentNode;
      const allItems = [...list.children];
      const srcIdx = allItems.indexOf(dragSrc);
      const tgtIdx = allItems.indexOf(item);
      if (srcIdx < tgtIdx) {
        list.insertBefore(dragSrc, item.nextSibling);
      } else {
        list.insertBefore(dragSrc, item);
      }
    }
  });
});
```

#### Desafío 1

Agrega **manijas de arrastre** — pequeños íconos que son la única región arrastrable de cada elemento. El texto del elemento debe permanecer seleccionable. Implementa esto haciendo que solo el elemento de la manija active el arrastre, mientras que el `<li>` completo sigue siendo el destino del soltado.

#### Cómo Funciona

El reloj usa CSS `transform: rotate()` aplicado a los elementos de manecilla de horas, minutos y segundos. La rotación se calcula a partir de la hora actual y se actualiza cada segundo con `setInterval`.

```js
function updateClock() {
  const now = new Date();
  const seconds = now.getSeconds();
  const minutes = now.getMinutes();
  const hours = now.getHours() % 12;

  const secondDeg = seconds * 6;          // 360 / 60
  const minuteDeg = minutes * 6 + seconds * 0.1;
  const hourDeg = hours * 30 + minutes * 0.5;

  secondHand.style.transform = `rotate(${secondDeg}deg)`;
  minuteHand.style.transform = `rotate(${minuteDeg}deg)`;
  hourHand.style.transform   = `rotate(${hourDeg}deg)`;
}

setInterval(updateClock, 1000);
updateClock(); // Ejecutar inmediatamente al cargar
```

En este módulo aprendiste:

- La **API de Arrastrar y Soltar**: hacer elementos arrastrables, transferir datos a través de `dataTransfer`, y manejar todos los eventos del ciclo de vida del arrastre para construir listas reordenables totalmente interactivas.
- Fundamentos de la **Web Audio API**: el contexto de audio, osciladores, nodos de ganancia, cargar buffers de audio y reproducir sonidos — la base de instrumentos y tableros de sonido en el navegador.
- **Eventos de teclado en profundidad**: la distinción entre `e.key` y `e.code`, detectar combinaciones de teclas modificadoras, prevenir comportamientos predeterminados del navegador y construir un gestor de atajos reutilizable.
- La **Clipboard API**: leer y escribir texto y contenido enriquecido en el portapapeles del sistema de forma basada en promesas y consciente de permisos.
- Un panorama de otras APIs poderosas del navegador: Geolocation, Vibration, Notifications, IntersectionObserver, ResizeObserver y más.

Juntas, estas APIs amplían dramáticamente lo que puedes construir con JavaScript en el navegador — desde juegos y herramientas creativas hasta aplicaciones de productividad que se sienten verdaderamente nativas.
