## Prerequisites

* A modern web browser (Chrome, Firefox, Edge, Safari)
* A code editor (VS Code recommended)
* [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) VS Code extension (optional, for auto-reload)
* Node.js >= 18 (optional, for linting and tests)

## Getting Started

1. Clone the repository:
```bash
git clone https://github.com/EmersonBraun/js-dev-course.git
cd js-dev-course
```

2. (Optional) Install dev dependencies for linting and tests:
```bash
npm install
```

3. Open any project folder and launch `index.html` with Live Server or directly in your browser.

## Available Scripts

```bash
npm run lint          # Run ESLint on all JS files
npm run lint:fix      # Auto-fix lint issues
npm test              # Run unit tests with Vitest
```
