# Background Slider

> [pt-br version](README-PTBR.md)

A beautiful background image slider with smooth transitions, customizable controls, and fullscreen support.

![Background Slider](gifs/class.gif)

## CLASS

### Features

- **Smooth Transitions**: Multiple transition effects (fade, slide, zoom)
- **Auto Play**: Automatic slide advancement with customizable speed
- **Navigation Controls**: Previous/Next buttons and dot navigation
- **Fullscreen Mode**: Immersive fullscreen viewing experience
- **Touch Support**: Swipe gestures for mobile devices
- **Keyboard Navigation**: Arrow keys and spacebar controls
- **Customizable Settings**: Adjust transition speed and auto-play
- **Responsive Design**: Works perfectly on all devices

### How to Use

1. **Navigate Slides**: Use arrow buttons or swipe gestures
2. **Adjust Speed**: Control transition speed with the slider
3. **Toggle Auto Play**: Enable/disable automatic slide advancement
4. **Change Effects**: Switch between fade, slide, and zoom transitions
5. **Fullscreen View**: Click fullscreen button for immersive experience
6. **Shuffle Mode**: Randomize slide order for variety

### Controls

- **Arrow Buttons**: Navigate between slides
- **Dot Navigation**: Jump to specific slides
- **Play/Pause**: Control auto-play functionality
- **Fullscreen**: Toggle fullscreen mode
- **Shuffle**: Randomize slide order

### Keyboard Shortcuts

- `Left Arrow`: Previous slide
- `Right Arrow`: Next slide
- `Spacebar`: Play/Pause auto-play
- `Ctrl+F`: Toggle fullscreen
- `Ctrl+S`: Shuffle slides

### Transition Effects

- **Fade**: Smooth opacity transition
- **Slide**: Horizontal sliding motion
- **Zoom**: Scale-based transitions

### Technologies Used

- HTML5
- CSS3 (with animations and transitions)
- Vanilla JavaScript
- Local Storage API
- Fullscreen API
- Google Fonts (Roboto)
