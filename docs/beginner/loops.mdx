# Loops

Loops allow you to repeat a block of code multiple times. They are essential for iterating over data, automating repetitive tasks, and building dynamic applications.

## `for` Loop

The most common loop. You control the **start**, **condition**, and **step**:

```javascript
for (let i = 0; i < 5; i++) {
  console.log(i);  // 0, 1, 2, 3, 4
}
```

The three parts:
1. **Initialization:** `let i = 0` — runs once before the loop starts
2. **Condition:** `i < 5` — checked before each iteration; loop stops when false
3. **Update:** `i++` — runs after each iteration

### Common patterns

```javascript
// Count backwards
for (let i = 10; i > 0; i--) {
  console.log(i);  // 10, 9, 8, ..., 1
}

// Step by 2
for (let i = 0; i <= 10; i += 2) {
  console.log(i);  // 0, 2, 4, 6, 8, 10
}
```

> **MDN Reference:** [for](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Statements/for)

## `while` Loop

Repeats as long as a condition is `true`. Use when you don't know how many iterations you need:

```javascript
let count = 0;
while (count < 5) {
  console.log(count);  // 0, 1, 2, 3, 4
  count++;
}
```

**Warning:** If the condition never becomes false, you get an **infinite loop** that freezes your program!

## `do...while` Loop

Like `while`, but guarantees at least **one execution**:

```javascript
let num = 10;
do {
  console.log(num);  // 10 (runs once even though condition is false)
  num++;
} while (num < 5);
```

> **MDN Reference:** [while](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Statements/while), [do...while](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Statements/do...while)

## `for...of` Loop

Iterates over **values** of iterable objects (arrays, strings):

```javascript
const fruits = ["apple", "banana", "cherry"];
for (const fruit of fruits) {
  console.log(fruit);  // "apple", "banana", "cherry"
}

// Works with strings too
for (const char of "Hello") {
  console.log(char);  // "H", "e", "l", "l", "o"
}
```

## `for...in` Loop

Iterates over **keys** (property names) of an object:

```javascript
const person = { name: "Alice", age: 25, city: "NYC" };
for (const key in person) {
  console.log(`${key}: ${person[key]}`);
}
// "name: Alice", "age: 25", "city: NYC"
```

**Tip:** Use `for...of` for arrays, `for...in` for objects.

> **MDN Reference:** [for...of](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Statements/for...of), [for...in](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Statements/for...in)

## `break` and `continue`

- **`break`** — exits the loop immediately
- **`continue`** — skips to the next iteration

```javascript
// break: stop when we find 3
for (let i = 0; i < 10; i++) {
  if (i === 3) break;
  console.log(i);  // 0, 1, 2
}

// continue: skip even numbers
for (let i = 0; i < 6; i++) {
  if (i % 2 === 0) continue;
  console.log(i);  // 1, 3, 5
}
```

## Summary

In this module you learned:

- **`for`** loop — when you know the number of iterations
- **`while`** loop — when you need to loop until a condition is met
- **`do...while`** — guarantees at least one execution
- **`for...of`** — iterates over values (arrays, strings)
- **`for...in`** — iterates over keys (objects)
- **`break`** exits the loop, **`continue`** skips to the next iteration
