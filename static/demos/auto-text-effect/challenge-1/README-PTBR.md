# Auto Text Effect

> [versão em inglês](README.md)

Um aplicativo de animação de digitação interativo que simula entrada de texto em tempo real com velocidade ajustável, múltiplas opções de texto e rastreamento abrangente de estatísticas.

## CLASS

Animação básica de digitação de texto com controles simples.

### Funcionalidades:
- Animação de digitação de texto
- Controles básicos de play/pause
- Ajuste simples de velocidade
- Exibição de texto com cursor
- Estatísticas básicas

### Tecnologias:
- HTML5
- CSS3 (com gradientes e animações)
- JavaScript (ES6+)
- Animações e transições CSS

## Demo

O aplicativo permite aos usuários:
1. Selecionar de opções de texto predefinidas ou inserir texto personalizado
2. Ajustar a velocidade de digitação usando o slider (1-50 WPM)
3. Controlar a animação com botões play, pause e reset
4. Visualizar estatísticas em tempo real incluindo:
   - Caracteres digitados
   - Palavras digitadas
   - Tempo decorrido
5. Usar atalhos de teclado para controle rápido

## Funcionalidades

### Funcionalidade Principal:
- **Animação de Texto**: Efeito suave de digitação caractere por caractere
- **Controle de Velocidade**: Velocidade de digitação ajustável de 1 a 50 WPM
- **Seleção de Texto**: Escolher entre múltiplos textos predefinidos
- **Texto Personalizado**: Inserir e animar seu próprio texto
- **Rastreamento de Estatísticas**: Contagem em tempo real de caracteres, palavras e tempo

### Experiência do Usuário:
- **Cursor Visual**: Cursor piscante animado durante a digitação
- **Controles Suaves**: Botões responsivos com efeitos hover
- **Slider de Velocidade**: Ajuste intuitivo de velocidade com feedback visual
- **Opções de Texto**: Seleção fácil de múltiplas amostras de texto
- **Design Responsivo**: Funciona em desktop e dispositivos móveis

### Opções de Controle:
- **Botão Play**: Iniciar a animação de digitação
- **Botão Pause**: Pausar a animação a qualquer momento
- **Botão Reset**: Limpar texto e resetar para o início
- **Slider de Velocidade**: Ajustar velocidade de digitação em tempo real
- **Seletor de Texto**: Escolher entre diferentes opções de texto
- **Entrada Personalizada**: Inserir e animar texto personalizado

## Atalhos de Teclado

- **Ctrl/Cmd + Espaço**: Play/Pause animação
- **Ctrl/Cmd + R**: Reset animação

## Controle de Velocidade

O slider de velocidade permite ajuste de 1 a 50 WPM (Palavras Por Minuto):
- **Lento (1-10 WPM)**: Fácil de seguir, bom para demonstrações
- **Médio (11-25 WPM)**: Ritmo natural de leitura
- **Rápido (26-50 WPM)**: Efeito de digitação rápida, bom para impacto
