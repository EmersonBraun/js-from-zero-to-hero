# Browser APIs

Beyond the DOM, modern browsers expose a rich collection of JavaScript APIs that unlock powerful capabilities: drag-and-drop interfaces, audio generation and control, deep keyboard event handling, clipboard access, and much more. In this module you will work hands-on with the most practical of these APIs.

## Theory

### HTML5 Drag and Drop API

Any element can be made draggable by adding the `draggable="true"` attribute and listening to drag events:

```js
// The element being dragged fires these events:
// dragstart  → drag begins
// drag       → drag is in progress
// dragend    → drag has ended (success or failure)

// The drop target fires these events:
// dragenter  → draggable enters the target
// dragover   → draggable is over the target (must call preventDefault to allow drop)
// dragleave  → draggable leaves the target
// drop       → draggable is dropped on the target

draggable.addEventListener('dragstart', (e) => {
  e.dataTransfer.setData('text/plain', draggable.id);
  e.dataTransfer.effectAllowed = 'move';
});

dropZone.addEventListener('dragover', (e) => {
  e.preventDefault(); // Required to allow dropping
  e.dataTransfer.dropEffect = 'move';
});

dropZone.addEventListener('drop', (e) => {
  e.preventDefault();
  const id = e.dataTransfer.getData('text/plain');
  const el = document.getElementById(id);
  dropZone.appendChild(el);
});
```

The `dataTransfer` object is the bridge between dragstart and drop — it carries any data you want to pass between them.

### Web Audio API Basics

The Web Audio API lets you generate, process, and play audio entirely in JavaScript using an audio graph of connected nodes:

```js
const audioCtx = new AudioContext();

// Create an oscillator node (generates a tone)
const oscillator = audioCtx.createOscillator();
oscillator.type = 'sine'; // 'sine' | 'square' | 'sawtooth' | 'triangle'
oscillator.frequency.setValueAtTime(440, audioCtx.currentTime); // A4 note

// Create a gain node (controls volume)
const gainNode = audioCtx.createGain();
gainNode.gain.setValueAtTime(0.5, audioCtx.currentTime);

// Connect: oscillator -> gain -> speakers
oscillator.connect(gainNode);
gainNode.connect(audioCtx.destination);

// Start and stop
oscillator.start();
oscillator.stop(audioCtx.currentTime + 0.5); // stop after 0.5 seconds
```

For a sound board, you typically load audio files with `fetch` and decode them:

```js
async function loadSound(url) {
  const response = await fetch(url);
  const arrayBuffer = await response.arrayBuffer();
  return audioCtx.decodeAudioData(arrayBuffer);
}

function playBuffer(buffer) {
  const source = audioCtx.createBufferSource();
  source.buffer = buffer;
  source.connect(audioCtx.destination);
  source.start();
}
```

### Keyboard Events in Depth

Keyboard events fire in this order: `keydown` → `keypress` (deprecated) → `keyup`.

```js
document.addEventListener('keydown', (e) => {
  console.log(e.key);      // Human-readable key name: 'a', 'Enter', 'ArrowLeft'
  console.log(e.code);     // Physical key: 'KeyA', 'Enter', 'ArrowLeft'
  console.log(e.keyCode);  // Legacy numeric code (deprecated, avoid)

  // Modifier keys
  console.log(e.ctrlKey, e.shiftKey, e.altKey, e.metaKey);

  // Detect combinations
  if (e.ctrlKey && e.key === 'z') {
    e.preventDefault(); // Prevent browser default undo
    handleUndo();
  }

  // Prevent default browser behavior
  if (e.key === ' ') e.preventDefault(); // Prevent page scroll
});
```

The difference between `e.key` and `e.code`:
- `e.key` = what the key produces (layout-dependent): `'a'` on QWERTY, `'q'` on AZERTY
- `e.code` = the physical key location: always `'KeyA'` regardless of layout

### Clipboard API

The modern `navigator.clipboard` API is promise-based and requires user permission:

```js
// Copy text to clipboard
async function copyText(text) {
  try {
    await navigator.clipboard.writeText(text);
    console.log('Copied!');
  } catch (err) {
    console.error('Copy failed:', err);
  }
}

// Read text from clipboard
async function pasteText() {
  try {
    const text = await navigator.clipboard.readText();
    console.log('Pasted:', text);
    return text;
  } catch (err) {
    console.error('Paste failed:', err);
  }
}

// Copy rich content (HTML, images)
async function copyHtml(html, plainText) {
  const item = new ClipboardItem({
    'text/html': new Blob([html], { type: 'text/html' }),
    'text/plain': new Blob([plainText], { type: 'text/plain' })
  });
  await navigator.clipboard.write([item]);
}
```

> The Clipboard API requires a secure context (HTTPS or localhost) and user permission.

function createDragList(items) {
  let list = [...items];

function createShortcutManager() {
  const shortcuts = new Map();

  function register(combo, handler) {
    // combo format: 'ctrl+z', 'shift+enter', 'escape'
    shortcuts.set(combo.toLowerCase(), handler);

// Equal temperament: each semitone = 2^(1/12) ratio
const A4_FREQ = 440; // Hz
const SEMITONE_RATIO = Math.pow(2, 1 / 12);

function noteToFrequency(semitones) {
  // semitones from A4 (0 = A4, 12 = A5, -12 = A3)
  return A4_FREQ * Math.pow(SEMITONE_RATIO, semitones);
}

function frequencyToNote(freq) {
  // Returns semitone offset from A4
  return Math.round(12 * Math.log2(freq / A4_FREQ));
}

const NOTE_NAMES = ['A', 'A#', 'B', 'C', 'C#', 'D', 'D#', 'E', 'F', 'F#', 'G', 'G#'];

function semitoneToName(semitones) {

  return NOTE_NAMES[index];
}

function createToneSchedule(notes, bpm) {
  const beatDuration = 60 / bpm;
  return notes.map((semitones, i) => ({
    time: i * beatDuration,
    frequency: noteToFrequency(semitones),
    duration: beatDuration * 0.9
  }));
}

function createHangmanGame(word) {
  const target = word.toLowerCase();
  const guessed = new Set();
  const maxWrong = 6;

  function guess(letter) {
    letter = letter.toLowerCase();
    if (guessed.has(letter)) return 'already-guessed';
    guessed.add(letter);
    return target.includes(letter) ? 'correct' : 'wrong';
  }

  function getMasked() {
    return target.split('').map(ch => guessed.has(ch) ? ch : '_').join('');
  }

  function getWrongCount() {
    return [...guessed].filter(l => !target.includes(l)).length;
  }

  function isWon() {
    return target.split('').every(ch => guessed.has(ch));
  }

  function isLost() {
    return getWrongCount() >= maxWrong;
  }

  function getStatus() {
    if (isWon()) return 'won';
    if (isLost()) return 'lost';
    return 'playing';
  }

  return { guess, getMasked, getWrongCount, isWon, isLost, getStatus };
}
`}

### Project 1: Drag and Drop List

An interactive list where items can be reordered by dragging, with visual feedback during the drag operation.

**Key concepts:** `dragstart`, `dragover`, `drop`, `dragleave`, `dragend` events, `dataTransfer`, CSS visual feedback classes.

<iframe
  src="/js-from-zero-to-hero/demos/drag-drop/index.html"
  width="100%"
  height="500"
  style={{border: '1px solid var(--ifm-color-emphasis-300)', borderRadius: '8px'}}
  title="Drag and Drop Demo"
/>

#### How it works

Each list item gets `draggable="true"`. The `dragover` event must call `e.preventDefault()` to signal that a drop is allowed. The actual reorder happens in the `drop` handler.

```js
let dragSrc = null;

items.forEach(item => {
  item.setAttribute('draggable', 'true');

  item.addEventListener('dragstart', (e) => {
    dragSrc = item;
    e.dataTransfer.effectAllowed = 'move';
    item.classList.add('dragging');
  });

  item.addEventListener('dragend', () => {
    dragSrc = null;
    item.classList.remove('dragging');
    document.querySelectorAll('.drag-over').forEach(el => el.classList.remove('drag-over'));
  });

  item.addEventListener('dragover', (e) => {
    e.preventDefault();
    item.classList.add('drag-over');
  });

  item.addEventListener('dragleave', () => item.classList.remove('drag-over'));

  item.addEventListener('drop', (e) => {
    e.preventDefault();
    if (dragSrc && dragSrc !== item) {
      const list = item.parentNode;
      const allItems = [...list.children];
      const srcIdx = allItems.indexOf(dragSrc);
      const tgtIdx = allItems.indexOf(item);
      if (srcIdx < tgtIdx) {
        list.insertBefore(dragSrc, item.nextSibling);
      } else {
        list.insertBefore(dragSrc, item);
      }
    }
  });
});
```

const sounds = {

async function loadAll(ctx) {

### Bonus Project: Theme Clock

An analog clock that updates in real time, with a dark/light theme toggle stored in `localStorage`.

#### How it works

The clock uses CSS `transform: rotate()` applied to hour, minute, and second hand elements. The rotation is calculated from the current time and updated every second with `setInterval`.

```js
function updateClock() {
  const now = new Date();
  const seconds = now.getSeconds();
  const minutes = now.getMinutes();
  const hours = now.getHours() % 12;

  const secondDeg = seconds * 6;          // 360 / 60
  const minuteDeg = minutes * 6 + seconds * 0.1;
  const hourDeg = hours * 30 + minutes * 0.5;

  secondHand.style.transform = `rotate(${secondDeg}deg)`;
  minuteHand.style.transform = `rotate(${minuteDeg}deg)`;
  hourHand.style.transform   = `rotate(${hourDeg}deg)`;
}

setInterval(updateClock, 1000);
updateClock(); // Run immediately on load
```

## Summary

In this module you learned:

- The **Drag and Drop API**: making elements draggable, transferring data via `dataTransfer`, and handling all drag lifecycle events to build fully interactive reorderable lists.
- **Web Audio API** fundamentals: the audio context, oscillators, gain nodes, loading audio buffers, and playing sounds — the foundation of browser-based instruments and sound boards.
- **Keyboard events in depth**: the distinction between `e.key` and `e.code`, detecting modifier key combinations, preventing default browser behaviors, and building a reusable shortcut manager.
- The **Clipboard API**: reading and writing text and rich content to the system clipboard in a promise-based, permission-aware way.
- A survey of other powerful browser APIs: Geolocation, Vibration, Notifications, IntersectionObserver, ResizeObserver, and more.

Together, these APIs dramatically expand what you can build with JavaScript in the browser — from games and creative tools to productivity applications that feel truly native.
