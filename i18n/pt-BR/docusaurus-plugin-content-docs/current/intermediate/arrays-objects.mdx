# Arrays & Objetos

Arrays e objetos são a espinha dorsal do gerenciamento de dados em JavaScript. Dominá-los — junto com sintaxe moderna como desestruturação e spread — vai melhorar drasticamente como você escreve e raciocina sobre código.

## Teoria

### Arrays

Um array é uma lista ordenada de valores. Arrays em JavaScript são dinâmicos e podem conter tipos misturados.

```js
const fruits = ["apple", "banana", "cherry"];
console.log(fruits[0]); // "apple"
console.log(fruits.length); // 3
```

#### Métodos Comuns de Array

| Método | Descrição |
|--------|-------------|
| `push(val)` | Adiciona ao final |
| `pop()` | Remove do final |
| `shift()` | Remove do início |
| `unshift(val)` | Adiciona ao início |
| `slice(start, end)` | Retorna uma porção (não mutante) |
| `splice(start, deleteCount, ...items)` | Insere/remove no lugar (mutante) |
| `indexOf(val)` | Encontra o índice do valor (-1 se não encontrado) |
| `includes(val)` | Verifica se o valor existe |
| `find(fn)` | Retorna o primeiro elemento correspondente |
| `filter(fn)` | Retorna todos os elementos correspondentes |
| `map(fn)` | Transforma cada elemento |
| `reduce(fn, init)` | Acumula para um único valor |

Referência MDN: [Array](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Array)

### Objetos

Um objeto armazena pares chave-valor. Chaves são strings (ou Symbols); valores podem ser qualquer coisa.

```js
const person = { name: "Alice", age: 30 };
console.log(person.name);       // notação de ponto
console.log(person["age"]);     // notação de colchetes

const key = "name";
console.log(person[key]);       // acesso dinâmico por chave
```

#### Métodos Utilitários de Objeto

- `Object.keys(obj)` — array de chaves
- `Object.values(obj)` — array de valores
- `Object.entries(obj)` — array de pares `[chave, valor]`
- `Object.assign(target, source)` — mesclagem rasa
- `Object.freeze(obj)` — previne modificações

Referência MDN: [Object](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Object)

### Desestruturação

Extrai valores de arrays ou objetos em variáveis.

```js
// Desestruturação de array
const [first, second, ...rest] = [1, 2, 3, 4, 5];

// Desestruturação de objeto
const { name, age, city = "Unknown" } = person;

// Aninhada
const { address: { street } } = { address: { street: "Main St" } };
```

Referência MDN: [Destructuring assignment](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Operators/Destructuring_assignment)

### Operadores Spread e Rest

```js
// Spread: expande um iterável
const combined = [...arr1, ...arr2];
const clone = { ...obj };

// Rest: coleta elementos restantes
function sum(...numbers) {
  return numbers.reduce((a, b) => a + b, 0);
}
```

Referência MDN: [Spread syntax](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Operators/Spread_syntax)

### Cópia Rasa vs Cópia Profunda

```js
// Cópia rasa — objetos aninhados ainda são compartilhados
const shallow = { ...original };

// Cópia profunda — clone totalmente independente
const deep = JSON.parse(JSON.stringify(original));
// Ou usando structuredClone (moderno):
const deep2 = structuredClone(original);
```

### Map e Set

```js
// Map — como um objeto, mas qualquer tipo de chave; preserva a ordem de inserção
const map = new Map();
map.set("key", 42);
map.get("key"); // 42
map.has("key"); // true

// Set — coleção de valores únicos
const set = new Set([1, 2, 2, 3]);
set.size; // 3
set.has(2); // true
```

Referências MDN: [Map](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Map) | [Set](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Set)

### Como Funciona

A lógica principal mapeia cada escolha para o que ela derrota:

```js
const rules = {
  rock: "scissors",
  paper: "rock",
  scissors: "paper",
};

function getResult(player, computer) {
  if (player === computer) return "draw";
  return rules[player] === computer ? "win" : "lose";
}
```

O placar é armazenado em um `Map` para que qualquer string (nome do jogador) possa ser usada como chave:

```js
const scoreboard = new Map();

function updateScore(player, result) {
  const current = scoreboard.get(player) ?? { wins: 0, losses: 0, draws: 0 };
  current[result === "win" ? "wins" : result === "lose" ? "losses" : "draws"]++;
  scoreboard.set(player, current);
}
```

## Resumo

- Arrays têm um rico conjunto de métodos embutidos; prefira os **não mutantes** (`map`, `filter`, `slice`) quando não quiser efeitos colaterais.
- Objetos armazenam dados estruturados; `Object.entries` + `map` permite transformá-los como arrays.
- **Desestruturação** e **spread** reduzem código repetitivo e tornam a intenção mais clara.
- Use `structuredClone` (ou `JSON.parse(JSON.stringify(...))`) para cópias profundas de dados aninhados.
- `Map` e `Set` são melhores escolhas que objetos simples quando você precisa de armazenamento chave-valor ordenado ou coleções de valores únicos.
