# Callbacks & Higher-Order Functions

Functions are **first-class citizens** in JavaScript — they can be stored in variables, passed as arguments, and returned from other functions. This module explores that idea through callbacks and higher-order functions.

## Theory

### First-Class Functions

JavaScript treats functions like any other value. You can:

```js
// Assign to a variable
const greet = function(name) { return `Hello, ${name}!`; };

// Store in an array
const operations = [Math.sqrt, Math.abs, Math.ceil];

// Pass as an argument
setTimeout(() => console.log("delayed"), 1000);
```

MDN Reference: [First-class Function](https://developer.mozilla.org/en-US/docs/Glossary/First-class_Function)

### Callbacks

A **callback** is a function passed to another function to be called later — either synchronously or asynchronously.

```js
function doTwice(fn) {
  fn();
  fn();
}

doTwice(() => console.log("hello")); // "hello" printed twice
```

Common patterns where callbacks appear:

- Array methods (`forEach`, `map`, `filter`, `sort`)
- Event listeners (`addEventListener`)
- Async operations (`setTimeout`, `fetch`)

### Higher-Order Functions (HOF)

A **higher-order function** either:
1. Accepts a function as an argument, or
2. Returns a function.

```js
// Accepts a function
function applyToAll(arr, fn) {
  return arr.map(fn);
}

// Returns a function
function multiplier(factor) {
  return (n) => n * factor;
}
const double = multiplier(2);
double(5); // 10
```

MDN Reference: [Functions](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide/Functions)

### map, filter, and reduce in Depth

These three array methods are the foundation of declarative array processing.

#### map

Transforms every element; returns a new array of the same length.

```js
const prices = [10, 20, 30];
const withTax = prices.map(p => p * 1.2); // [12, 24, 36]
```

#### filter

Keeps only elements where the callback returns `true`.

```js
const ages = [12, 20, 17, 25];
const adults = ages.filter(age => age >= 18); // [20, 25]
```

#### reduce

Accumulates all elements into a single value. The callback receives `(accumulator, currentValue)`.

```js
const numbers = [1, 2, 3, 4];
const sum = numbers.reduce((acc, n) => acc + n, 0); // 10

// Build an object from an array
const inventory = [
  { name: "apple", qty: 5 },
  { name: "banana", qty: 3 },
];
const totals = inventory.reduce((acc, item) => {
  acc[item.name] = item.qty;
  return acc;
}, {});
// { apple: 5, banana: 3 }
```

MDN References: [map](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Array/map) | [filter](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Array/filter) | [reduce](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Array/reduce)

### Declarative vs Imperative Style

**Imperative** — describe *how* to do something step by step:

```js
const result = [];
for (let i = 0; i < numbers.length; i++) {
  if (numbers[i] % 2 === 0) {
    result.push(numbers[i] * 2);
  }
}
```

**Declarative** — describe *what* you want:

```js
const result = numbers.filter(n => n % 2 === 0).map(n => n * 2);
```

Declarative style is shorter, easier to test, and closer to how you think about the problem.

### Function Composition

Combining small functions into larger ones:

```js
const compose = (...fns) => (x) => fns.reduceRight((v, f) => f(v), x);

const add1 = x => x + 1;
const double = x => x * 2;
const square = x => x * x;

const transform = compose(square, double, add1);
transform(3); // square(double(add1(3))) = square(double(4)) = square(8) = 64
```

### Walkthrough

```js
const romanNumerals = [
  [1000, "M"], [900, "CM"], [500, "D"], [400, "CD"],
  [100, "C"],  [90, "XC"],  [50, "L"],  [40, "XL"],
  [10, "X"],   [9, "IX"],   [5, "V"],   [4, "IV"],
  [1, "I"],
];

function toRoman(num) {
  return romanNumerals.reduce((result, [value, symbol]) => {
    while (num >= value) {
      result += symbol;
      num -= value;
    }
    return result;
  }, "");
}
```

The `reduce` callback here acts as an iterator over the lookup table — a classic higher-order pattern.

### Walkthrough

```js
function binaryToDecimal(binaryStr) {
  return binaryStr
    .split("")
    .reverse()
    .reduce((acc, bit, index) => acc + Number(bit) * Math.pow(2, index), 0);
}
```

Notice how `reduce` replaces the manual `for` loop — the accumulator builds the decimal value bit by bit.

## Summary

- Functions are first-class values — store, pass, and return them freely.
- A **callback** is simply a function you hand to another function to invoke at the right time.
- A **higher-order function** is any function that takes or returns a function.
- `map`, `filter`, and `reduce` form the core of declarative array processing — prefer them over `for` loops when transforming data.
- **Function composition** lets you build powerful pipelines from small, reusable pieces.
- Declarative style makes your intent clearer and your code easier to test.
