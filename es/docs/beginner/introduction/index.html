Introducción a JavaScript

¡Bienvenido a tu primer paso en el mundo de JavaScript! Este módulo te enseñará qué es JavaScript, cómo se ejecuta en el navegador y cómo escribir tus primeras líneas de código.

¿Qué es JavaScript?​

JavaScript (frecuentemente abreviado como JS) es un lenguaje de programación ligero e interpretado que es una de las tres tecnologías centrales de la World Wide Web, junto con HTML y CSS.

  • HTML define la estructura de una página web (encabezados, párrafos, botones)
  • CSS define la presentación y el estilo (colores, fuentes, diseño)
  • JavaScript define el comportamiento (qué sucede cuando haces clic en un botón, cómo se validan los datos, las animaciones)

JavaScript fue creado en 1995 por Brendan Eich en tan solo 10 días mientras trabajaba en Netscape. A pesar de su nombre, JavaScript no tiene relación con el lenguaje de programación Java — el nombre fue una decisión de marketing.

Hoy en día, JavaScript es el lenguaje de programación más usado en el mundo. Se ejecuta en todos los navegadores web, en servidores (a través de Node.js), en aplicaciones móviles, aplicaciones de escritorio e incluso en dispositivos IoT.

Cómo se Ejecuta JavaScript en el Navegador​

Cada navegador web moderno (Chrome, Firefox, Safari, Edge) tiene un motor JavaScript incorporado que puede ejecutar código JavaScript:

NavegadorMotor
ChromeV8
FirefoxSpiderMonkey
SafariJavaScriptCore
EdgeV8

Cuando un navegador carga una página web:

  1. Analiza el HTML para construir el DOM (Document Object Model)
  2. Aplica los estilos de CSS
  3. Ejecuta cualquier código JavaScript que encuentre

La Consola del Navegador​

La consola del navegador es una herramienta de desarrollador incorporada en todos los navegadores donde puedes escribir y ejecutar código JavaScript de inmediato. Es tu mejor aliada para aprender y depurar.

Cómo abrirla:​

  • Chrome/Edge: Presiona F12 o Ctrl+Shift+J (Windows/Linux) o Cmd+Option+J (Mac)
  • Firefox: Presiona F12 o Ctrl+Shift+K (Windows/Linux) o Cmd+Option+K (Mac)
  • Safari: Activa el menú Desarrollador en Preferencias, luego presiona Cmd+Option+C

Prueba abrir la consola de tu navegador ahora mismo y escribe:

2 + 2

Deberías ver 4 como resultado. La consola evalúa la expresión y muestra el resultado.

console.log() — Tu Primera Herramienta​

console.log() es una función que imprime (registra) un mensaje en la consola del navegador. Es la herramienta de depuración más básica y más usada en JavaScript.

console.log("Hello, World!");

Esto imprimirá Hello, World! en la consola.

Puedes registrar múltiples valores separados por comas:

console.log("My name is", "Emerson");
console.log("2 + 2 =", 2 + 2);

También puedes registrar números, booleanos y expresiones:

console.log(42);
console.log(true);
console.log(10 > 5);

Agregar JavaScript a una Página HTML​

Hay dos formas principales de agregar JavaScript a una página web:

1. Script Inline (dentro del archivo HTML)​

Usa la etiqueta <script> directamente en tu HTML:

<!DOCTYPE html>
<html>
<head>
  <title>Mi Primera Página JS</title>
</head>
<body>
  <h1>¡Hola!</h1>

  <script>
    console.log("¡Este script se ejecuta cuando la página carga!");
    document.querySelector("h1").textContent = "¡Hola desde JavaScript!";
  </script>
</body>
</html>

Importante: Coloca la etiqueta <script> al final del <body> para que los elementos HTML se carguen antes de que el script intente acceder a ellos.

2. Script Externo (archivo .js separado)​

Crea un archivo separado (p. ej., index.js) y enlázalo:

<!-- index.html -->
<body>
  <h1>¡Hola!</h1>
  <script src="index.js"></script>
</body>
// index.js
console.log("¡Esto viene de un archivo externo!");

Este es el enfoque preferido para proyectos reales porque mantiene tu código organizado y reutilizable.

Comentarios​

Los comentarios son notas en tu código que JavaScript ignora. Te ayudan a ti (y a otros) a entender qué hace el código.

// Este es un comentario de una sola línea

/*
  Este es un
  comentario de múltiples líneas
*/

console.log("Esto se ejecuta"); // También puedes comentar al final de una línea

Tu Primer Programa​

Pongamos todo junto. Aquí hay un programa simple que saluda al usuario:

// Mi primer programa JavaScript
let name = "World";
console.log("Hello, " + name + "!");
console.log("Welcome to JavaScript!");

Este programa:

  1. Crea una variable llamada name con el valor "World"
  2. Concatena (une) strings usando +
  3. Imprime dos mensajes en la consola

¡No te preocupes si no entiendes completamente las variables y la concatenación de strings todavía — las cubriremos en detalle en el próximo módulo!

Resumen​

En este módulo aprendiste:

  • JavaScript es el lenguaje de programación de la web, que se ejecuta en todos los navegadores
  • La consola del navegador te permite ejecutar código JS directamente
  • console.log() imprime mensajes en la consola
  • La etiqueta <script> agrega JavaScript a una página HTML
  • Los comentarios ayudan a documentar tu código (// para una sola línea, /* */ para múltiples líneas)
  • Puedes usar operadores como +, *, %, > para trabajar con valores
  • Los strings tienen propiedades y métodos útiles como .length y .toUpperCase()

En el próximo módulo, profundizaremos en Variables y Tipos — los bloques de construcción de cualquier programa JavaScript.
