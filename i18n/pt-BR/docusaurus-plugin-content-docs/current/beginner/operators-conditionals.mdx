# Operadores & Condicionais

Neste módulo você aprenderá como realizar cálculos, comparar valores e tomar decisões no seu código. Esses são os blocos fundamentais que tornam os programas dinâmicos e interativos.

## Operadores Aritméticos

JavaScript suporta todas as operações matemáticas básicas:

| Operador | Nome | Exemplo | Resultado |
|---|---|---|---|
| `+` | Adição | `5 + 3` | `8` |
| `-` | Subtração | `10 - 4` | `6` |
| `*` | Multiplicação | `3 * 7` | `21` |
| `/` | Divisão | `20 / 4` | `5` |
| `%` | Módulo (resto) | `10 % 3` | `1` |
| `**` | Exponenciação | `2 ** 3` | `8` |

O **operador módulo** (`%`) retorna o resto de uma divisão. É muito útil para verificar se um número é par ou ímpar:

```javascript
10 % 2  // 0 → par (sem resto)
7 % 2   // 1 → ímpar (resto 1)
```

> **Referência MDN:** [Operadores aritméticos](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Operators#arithmetic_operators)

## Operadores de Comparação

Operadores de comparação comparam dois valores e retornam um **boolean** (`true` ou `false`):

| Operador | Significado | Exemplo | Resultado |
|---|---|---|---|
| `===` | Igualdade estrita | `5 === 5` | `true` |
| `!==` | Desigualdade estrita | `5 !== 3` | `true` |
| `>` | Maior que | `10 > 5` | `true` |
| `<` | Menor que | `3 < 7` | `true` |
| `>=` | Maior ou igual | `5 >= 5` | `true` |
| `<=` | Menor ou igual | `3 <= 2` | `false` |

### `===` vs `==`

JavaScript tem dois operadores de igualdade:

- **`===` (igualdade estrita)** — compara valor E tipo. **Sempre use este.**
- **`==` (igualdade solta)** — compara valores com coerção de tipos (pode produzir resultados inesperados)

```javascript
5 === 5      // true (mesmo valor, mesmo tipo)
5 === "5"    // false (tipos diferentes: number vs string)
5 == "5"     // true (solto: converte string para número!)
```

**Regra geral:** Sempre use `===` e `!==` para evitar bugs causados por coerção de tipos.

> **Referência MDN:** [Operadores de comparação](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Operators/Comparison_Operators)

## Operadores Lógicos

Operadores lógicos combinam expressões booleanas:

| Operador | Nome | Descrição |
|---|---|---|
| `&&` | E (AND) | `true` se AMBOS os lados forem true |
| `\|\|` | OU (OR) | `true` se PELO MENOS UM lado for true |
| `!` | NÃO (NOT) | Inverte o valor booleano |

```javascript
true && true    // true
true && false   // false
true || false   // true
false || false  // false
!true           // false
!false          // true
```

Exemplo prático:

```javascript
let age = 25;
let hasLicense = true;

// Pode dirigir: deve ter 18+ E ter habilitação
let canDrive = age >= 18 && hasLicense;  // true
```

> **Referência MDN:** [Operadores lógicos](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Operators/Logical_AND)

## Declarações `if / else`

A declaração `if` executa código apenas quando uma condição é `true`:

```javascript
let temperature = 35;

if (temperature > 30) {
  console.log("It's hot outside!");
}
```

Adicione um bloco `else` para quando a condição for `false`:

```javascript
let temperature = 15;

if (temperature > 30) {
  console.log("It's hot outside!");
} else {
  console.log("It's not that hot.");
}
```

Use `else if` para múltiplas condições:

```javascript
let temperature = 15;

if (temperature > 30) {
  console.log("It's hot!");
} else if (temperature > 20) {
  console.log("It's warm.");
} else if (temperature > 10) {
  console.log("It's cool.");
} else {
  console.log("It's cold!");
}
```

> **Referência MDN:** [if...else](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Statements/if...else)

## Declaração `switch`

Quando você precisa comparar um valor com muitas opções, `switch` é mais limpo que vários `if/else if`:

```javascript
let day = "Monday";

switch (day) {
  case "Monday":
    console.log("Start of the week");
    break;
  case "Friday":
    console.log("Almost weekend!");
    break;
  case "Saturday":
  case "Sunday":
    console.log("Weekend!");
    break;
  default:
    console.log("Regular day");
}
```

**Importante:** Não esqueça a declaração `break`! Sem ela, a execução "cai" para o próximo caso.

> **Referência MDN:** [switch](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Statements/switch)

## Operador Ternário

O operador ternário é uma forma abreviada de declarações simples `if/else`:

```javascript
// Sintaxe: condição ? valorSeVerdadeiro : valorSeFalso

let age = 20;
let status = age >= 18 ? "adult" : "minor";
// status é "adult"
```

Isso é equivalente a:

```javascript
let status;
if (age >= 18) {
  status = "adult";
} else {
  status = "minor";
}
```

O operador ternário é ótimo para condições curtas e simples. Para lógica complexa, use `if/else`.

> **Referência MDN:** [Operador condicional (ternário)](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Operators/Conditional_operator)

## Projeto: Lâmpada Interativa

Agora vamos aplicar o que você aprendeu em um projeto real! **Switch Light** é uma lâmpada interativa que responde a eventos do mouse usando condicionais.

### Como Funciona

O projeto tem uma imagem de lâmpada que muda com base na interação do usuário:

- **Passar o mouse** sobre a lâmpada → luz ACENDE
- **Mover o mouse para longe** → luz APAGA
- **Clicar** na lâmpada → luz QUEBRA (e fica quebrada)

A lógica principal usa **condicionais** e **flags booleanos** para controlar o estado:

```javascript
let broken = false;

function changeLight(element, type) {
  // Se já quebrado, não fazer nada (retorno antecipado com condicional)
  if (broken === true) return;

  element.srcElement.src = `images/light-${type}.png`;

  if (type === 'broken') {
    broken = true;  // Uma vez quebrado, fica quebrado
  }
}
```

Conceitos-chave demonstrados:
- **Variáveis booleanas** (`broken`) para rastrear estado
- **Declarações `if`** para lógica condicional e retornos antecipados
- **Template literals** para strings dinâmicas
- **Event listeners** (`mouseenter`, `mouseleave`, `click`) para interação do usuário

### Passo a Passo

**1. Estrutura HTML**

O HTML é simples — uma imagem e um botão:

```html
<div class="container">
  <div class="box">
    <img id="light" src="images/light-off.png" alt="light">
  </div>
  <div class="box">
    <button id="btn" class="button" onclick="toogleType()">NORMAL</button>
  </div>
</div>
<script src="index.js"></script>
```

**2. Variáveis de Estado**

Três variáveis rastreiam o estado atual da lâmpada:

```javascript
let broken = false;  // A lâmpada está quebrada?
let on = true;       // A lâmpada está acesa?
let type = 'NORMAL'; // Modo atual: NORMAL ou SWITCH
```

**3. Event Listeners**

A imagem da lâmpada escuta três eventos:

```javascript
const light = document.getElementById('light');

light.addEventListener('mouseenter', (element) => changeLight(element, 'on'));
light.addEventListener('mouseleave', (element) => changeLight(element, 'off'));
light.addEventListener('click', (element) => {
  if (type === 'NORMAL') {
    changeLight(element, 'broken');
  } else {
    toogleLight(element);
  }
});
```

Note como o handler de `click` usa um **`if/else`** para decidir o comportamento com base no modo atual.

**4. O Operador Ternário em Ação**

O botão de troca de modo usa um **operador ternário**:

```javascript
function toogleType() {
  type = type === 'NORMAL' ? 'SWITCH' : 'NORMAL';
  document.getElementById('btn').textContent = type;
  broken = false;
}
```

**5. Retorno Antecipado Condicional**

A função `changeLight` usa o padrão de retorno antecipado com condicionais:

```javascript
function changeLight(element, tipo) {
  if (broken === true || type === 'SWITCH') return;
  element.srcElement.src = `images/light-${tipo}.png`;
  if (tipo === 'broken') {
    broken = true;
  }
}
```

O operador `||` (OU) combina duas condições: se a lâmpada está quebrada OU o modo é SWITCH, não fazer nada.
