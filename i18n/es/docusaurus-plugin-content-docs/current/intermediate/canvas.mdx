# Canvas API

El elemento Canvas de HTML5 proporciona una potente superficie de dibujo 2D que puedes controlar completamente con JavaScript. Desde formas simples hasta animaciones complejas e incluso manipulación de píxeles, la Canvas API es una piedra angular de los gráficos en el navegador.

**Referencias MDN:**
- [HTMLCanvasElement](https://developer.mozilla.org/en-US/docs/Web/API/HTMLCanvasElement)
- [CanvasRenderingContext2D](https://developer.mozilla.org/en-US/docs/Web/API/CanvasRenderingContext2D)
- [requestAnimationFrame](https://developer.mozilla.org/en-US/docs/Web/API/window/requestAnimationFrame)

---

## Teoría

### Comenzando con Canvas

El elemento `<canvas>` es simplemente una superficie de dibujo en blanco. Obtienes acceso a su contexto de dibujo a través de `getContext('2d')`:

```js
const canvas = document.getElementById('myCanvas');
const ctx = canvas.getContext('2d');
```

El sistema de coordenadas comienza en la esquina superior izquierda `(0, 0)`, con `x` aumentando hacia la derecha e `y` aumentando hacia abajo.

---

### Dibujar Rectángulos

Los rectángulos son la forma más simple en el canvas:

```js
// Rectángulo relleno
ctx.fillStyle = 'blue';
ctx.fillRect(x, y, width, height);

// Rectángulo con borde
ctx.strokeStyle = 'red';
ctx.lineWidth = 2;
ctx.strokeRect(x, y, width, height);

// Limpiar un área rectangular
ctx.clearRect(x, y, width, height);
```

---

### Trazados, Líneas y Arcos

La mayoría de las formas complejas se construyen usando trazados:

```js
ctx.beginPath();
ctx.moveTo(50, 50);       // Moverse al punto de inicio sin dibujar
ctx.lineTo(200, 50);      // Dibujar una línea hasta este punto
ctx.lineTo(200, 150);
ctx.closePath();           // Cerrar el trazado de vuelta al inicio
ctx.stroke();              // Renderizar el contorno del trazado

// Círculos y arcos
ctx.beginPath();
ctx.arc(x, y, radius, startAngle, endAngle, anticlockwise);
// Círculo completo: startAngle = 0, endAngle = Math.PI * 2
ctx.fill();
```

---

### Estilos de Relleno y Borde

Puedes usar colores, gradientes y patrones como estilos de relleno o borde:

```js
// Color sólido
ctx.fillStyle = '#ff6347';

// Gradiente lineal
const gradient = ctx.createLinearGradient(0, 0, 200, 0);
gradient.addColorStop(0, 'red');
gradient.addColorStop(1, 'blue');
ctx.fillStyle = gradient;

// Gradiente radial
const radial = ctx.createRadialGradient(75, 50, 5, 75, 50, 100);
radial.addColorStop(0, 'white');
radial.addColorStop(1, 'black');
ctx.fillStyle = radial;
```

---

### Dibujar Texto

Canvas soporta renderizar texto con control completo de estilo:

```js
ctx.font = '30px Arial';
ctx.fillStyle = 'black';
ctx.textAlign = 'center';    // 'left' | 'right' | 'center' | 'start' | 'end'
ctx.textBaseline = 'middle'; // 'top' | 'middle' | 'bottom' | 'alphabetic'

ctx.fillText('Hello, Canvas!', x, y);
ctx.strokeText('Outlined Text', x, y);

// Medir el ancho del texto
const metrics = ctx.measureText('Hello');
console.log(metrics.width);
```

---

### Animación con requestAnimationFrame

`requestAnimationFrame` programa una función para ejecutarse antes del siguiente repintado, habilitando animaciones fluidas a 60fps:

```js
function animate() {
  ctx.clearRect(0, 0, canvas.width, canvas.height); // Limpiar frame anterior
  // ... dibujar escena actualizada ...
  requestAnimationFrame(animate); // Programar el siguiente frame
}

requestAnimationFrame(animate); // Iniciar el bucle
```

---

### Manipulación de Píxeles

Puedes leer y escribir píxeles individuales usando `ImageData`:

```js
// Obtener datos de píxeles para todo el canvas
const imageData = ctx.getImageData(0, 0, canvas.width, canvas.height);
const data = imageData.data; // Uint8ClampedArray: [R, G, B, A, R, G, B, A, ...]

// Modificar un píxel en (x, y)
const index = (y * canvas.width + x) * 4;
data[index]     = 255; // Rojo
data[index + 1] = 0;   // Verde
data[index + 2] = 0;   // Azul
data[index + 3] = 255; // Alfa

// Poner los datos modificados de vuelta
ctx.putImageData(imageData, 0, 0);
```

function createAnimator() {
  let frame = 0;
  let running = false;
  const log = [];

  function tick() {
    if (!running) return;
    frame++;
    log.push(frame);
  }

  return {
    start() { running = true; },
    stop() { running = false; },
    tick,
    getFrame() { return frame; },
    getLog() { return log; },
    reset() { frame = 0; log.length = 0; }

const animator = createAnimator();

function runAnimation(steps) {
  animator.start();
  for (let i = 0; i < steps; i++) {
    animator.tick();
  }
  animator.stop();
  return animator.getFrame();
}

function wrapText(text, maxWidth, charWidth) {
  // Simple word-wrap based on estimated char width
  const words = text.split(' ');
  const lines = [];
  let currentLine = '';

  for (const word of words) {
    const testLine = currentLine ? currentLine + ' ' + word : word;
    if (testLine.length * charWidth > maxWidth && currentLine) {
      lines.push(currentLine);
      currentLine = word;
    } else {
      currentLine = testLine;
    }
  }
  if (currentLine) lines.push(currentLine);
  return lines;
}

function centerText(text, canvasWidth, charWidth) {
  const textWidth = text.length * charWidth;
  return (canvasWidth - textWidth) / 2;
}

function stackedTextPositions(lines, startY, lineHeight) {
  return lines.map((line, i) => ({ text: line, y: startY + i * lineHeight }));
}

### Proyecto 1: Efecto Lluvia Matrix

Los clásicos caracteres en cascada verde de The Matrix — construidos completamente en canvas usando `requestAnimationFrame`.

**Conceptos clave:** Columnas de canvas, caracteres aleatorios, superposiciones semitransparentes para el efecto de estela, bucle `requestAnimationFrame`.

<iframe
  src="/js-from-zero-to-hero/demos/matrix/index.html"
  width="100%"
  height="500"
  style={{border: '1px solid var(--ifm-color-emphasis-300)', borderRadius: '8px'}}
  title="Matrix Rain Effect Demo"
/>

#### Cómo Funciona

1. Crea un `<canvas>` que llene el viewport.
2. Divide el ancho del canvas en columnas de `fontSize` píxeles cada una.
3. Rastrea un array `drops` — un valor por columna, representando la posición y actual del carácter que cae.
4. En cada frame:
   - Dibuja un rectángulo negro semitransparente sobre todo el canvas (crea la estela de desvanecimiento).
   - Para cada gota, dibuja un carácter aleatorio en `(col * fontSize, drop * fontSize)`.
   - Reinicia aleatoriamente una gota a `0` cuando llega al final.

```js
const canvas = document.getElementById('canvas');
const ctx = canvas.getContext('2d');
canvas.width = window.innerWidth;
canvas.height = window.innerHeight;

const fontSize = 16;
const columns = Math.floor(canvas.width / fontSize);
const drops = new Array(columns).fill(1);
const chars = 'アイウエオ...ABCDEFGHIJKLMNOPQRSTUVWXYZ0123456789';

function draw() {
  ctx.fillStyle = 'rgba(0, 0, 0, 0.05)';
  ctx.fillRect(0, 0, canvas.width, canvas.height);

  ctx.fillStyle = '#0F0';
  ctx.font = `${fontSize}px monospace`;

  drops.forEach((y, i) => {
    const char = chars[Math.floor(Math.random() * chars.length)];
    ctx.fillText(char, i * fontSize, y * fontSize);
    if (y * fontSize > canvas.height && Math.random() > 0.975) {
      drops[i] = 0;
    }
    drops[i]++;
  });
}

setInterval(draw, 33);
```

#### Desafío 1

Cambia el color del carácter de verde a un gradiente que cambia entre verde y blanco dependiendo de la posición de la gota — los caracteres cerca de la parte superior de una estela deben ser blanco brillante.

#### Desafío 2

Agrega un modo "congelar": presionar la barra espaciadora pausa y reanuda la animación. Usa un indicador booleano y `cancelAnimationFrame` para implementarlo limpiamente.

### Proyecto 2: Herramienta de Dibujo en Canvas

Una aplicación de dibujo a mano alzada usando eventos de mouse y trazados de canvas.

**Conceptos clave:** Eventos `mousedown`, `mousemove`, `mouseup`, `beginPath`/`moveTo`/`lineTo`, ancho de línea y color dinámicos.

<iframe
  src="/js-from-zero-to-hero/demos/drawing/index.html"
  width="100%"
  height="500"
  style={{border: '1px solid var(--ifm-color-emphasis-300)', borderRadius: '8px'}}
  title="Canvas Drawing Tool Demo"
/>

#### Cómo Funciona

1. Rastrea si el botón del mouse está presionado (`isDrawing`).
2. En `mousedown`: establece `isDrawing = true`, llama `beginPath()`, `moveTo(x, y)`.
3. En `mousemove`: si está dibujando, llama `lineTo(x, y)` y `stroke()`, luego `moveTo(x, y)`.
4. En `mouseup` / `mouseleave`: establece `isDrawing = false`.

```js
let isDrawing = false;
let lastX = 0, lastY = 0;

canvas.addEventListener('mousedown', (e) => {
  isDrawing = true;
  [lastX, lastY] = [e.offsetX, e.offsetY];
});

canvas.addEventListener('mousemove', (e) => {
  if (!isDrawing) return;
  ctx.beginPath();
  ctx.moveTo(lastX, lastY);
  ctx.lineTo(e.offsetX, e.offsetY);
  ctx.stroke();
  [lastX, lastY] = [e.offsetX, e.offsetY];
});

canvas.addEventListener('mouseup', () => isDrawing = false);
canvas.addEventListener('mouseleave', () => isDrawing = false);
```

#### Desafío 1

Agrega un selector de color y un control deslizante de ancho de línea que actualicen `ctx.strokeStyle` y `ctx.lineWidth` en tiempo real. Permite a los usuarios elegir entre terminaciones de línea redondas y cuadradas (`ctx.lineCap`).

#### Desafío 2

Implementa una función de **deshacer** usando un array de instantáneas `ImageData`. Guarda el estado del canvas en cada `mousedown`, y restaura la instantánea anterior cuando el usuario presiona `Ctrl+Z`.

### Proyecto 3: Aplicación de Pintura

Una aplicación de pintura completa que combina formas, una paleta de colores, relleno con cubeta y herramienta de texto.

**Conceptos clave:** Máquina de estados de selección de herramientas, algoritmo de relleno por inundación, `ctx.save()`/`ctx.restore()` para previsualizaciones de herramientas.

<iframe

  width="100%"
  height="500"
  style={{border: '1px solid var(--ifm-color-emphasis-300)', borderRadius: '8px'}}
  title="Paint App Demo"
/>

#### Cómo Funciona

La aplicación de pintura usa un estado de **herramienta actual** para determinar qué sucede en los eventos del mouse:

- **Lápiz** — dibujo a mano alzada (igual que la herramienta de dibujo anterior).
- **Rectángulo / Círculo** — en `mousedown`, registra el punto de inicio. En `mousemove`, limpia una vista previa y dibuja la forma. En `mouseup`, confirma la forma.
- **Cubeta de relleno** — al hacer clic, ejecuta un algoritmo de relleno por inundación usando `getImageData`/`putImageData`.
- **Texto** — al hacer clic, solicita texto y lo renderiza en la posición clicada con `fillText`.

```js
let tool = 'pencil';
let startX, startY;
let snapshot; // ImageData taken on mousedown for shape preview

canvas.addEventListener('mousedown', (e) => {
  startX = e.offsetX;
  startY = e.offsetY;
  snapshot = ctx.getImageData(0, 0, canvas.width, canvas.height);
});

canvas.addEventListener('mousemove', (e) => {
  if (tool === 'rectangle') {
    ctx.putImageData(snapshot, 0, 0); // Restore before drawing preview
    ctx.strokeRect(startX, startY, e.offsetX - startX, e.offsetY - startY);
  }
});
```

## Resumen

En este módulo aprendiste:

- Cómo obtener y usar un `CanvasRenderingContext2D` a través de `getContext('2d')`.
- Primitivos de dibujo: rectángulos, arcos y trazados arbitrarios con líneas y curvas.
- Estilizado con colores sólidos, gradientes lineales y gradientes radiales.
- Renderizar y medir texto en canvas.
- Crear animaciones fluidas usando `requestAnimationFrame` y un bucle de juego.
- Leer y escribir datos de píxeles con `getImageData` y `putImageData`.

La Canvas API es fundamental para juegos en el navegador, visualizaciones de datos, editores de imágenes y programación creativa. Los proyectos anteriores — Lluvia Matrix, la Herramienta de Dibujo y la Aplicación de Pintura — cada uno aplica una parte diferente de estas capacidades en un contexto real e interactivo.
