## Demo

The application allows users to:
1. Select from pre-defined text options or enter custom text
2. Adjust typing speed using the slider (1-50 WPM)
3. Control the animation with play, pause, and reset buttons
4. View real-time statistics including:
   - Characters typed
   - Words typed
   - Time elapsed
5. Use keyboard shortcuts for quick control

## Features

### Core Functionality:
- **Text Animation**: Smooth character-by-character typing effect
- **Speed Control**: Adjustable typing speed from 1 to 50 WPM
- **Text Selection**: Choose from multiple pre-defined texts
- **Custom Text**: Input and animate your own text
- **Statistics Tracking**: Real-time character, word, and time counting

### User Experience:
- **Visual Cursor**: Animated blinking cursor during typing
- **Smooth Controls**: Responsive buttons with hover effects
- **Speed Slider**: Intuitive speed adjustment with visual feedback
- **Text Options**: Easy selection from multiple text samples
- **Responsive Design**: Works on desktop and mobile devices

### Control Options:
- **Play Button**: Start the typing animation
- **Pause Button**: Pause the animation at any point
- **Reset Button**: Clear text and reset to beginning
- **Speed Slider**: Adjust typing speed in real-time
- **Text Selector**: Choose from different text options
- **Custom Input**: Enter and animate custom text

## Keyboard Shortcuts

- **Ctrl/Cmd + Space**: Play/Pause animation
- **Ctrl/Cmd + R**: Reset animation

## Speed Control

The speed slider allows adjustment from 1 to 50 WPM (Words Per Minute):
- **Slow (1-10 WPM)**: Easy to follow, good for demonstrations
- **Medium (11-25 WPM)**: Natural reading pace
- **Fast (26-50 WPM)**: Quick typing effect, good for impact
