# Progress Steps

> [pt-br version](README-PTBR.md)

A multi-step form with progress indicator, validation, and smooth transitions.

![Progress Steps](gifs/class.gif)

## CLASS

### Features

- **Step-by-Step Navigation**: Navigate through form steps with Previous/Next buttons
- **Progress Indicator**: Visual progress bar and step circles
- **Form Validation**: Real-time validation with error messages
- **Smooth Animations**: CSS transitions and animations between steps
- **Keyboard Navigation**: Arrow keys and Enter key support
- **Auto-Save**: Automatically saves form data to local storage
- **Responsive Design**: Works on desktop and mobile devices
- **Summary Display**: Shows all entered information on the final step

### How to Use

1. **Fill Out Forms**: Complete each step with required information
2. **Navigate Steps**: Use Previous/Next buttons or keyboard shortcuts
3. **Validate Input**: Real-time validation ensures data quality
4. **Review Summary**: Check all information on the final step
5. **Complete Setup**: Agree to terms and complete the process

### Form Steps

1. **Account Setup**: Username and email
2. **Personal Information**: Name and age
3. **Preferences**: Theme, language, and notifications
4. **Confirmation**: Review and agree to terms

### Keyboard Shortcuts

- `Left Arrow`: Previous step
- `Right Arrow` / `Enter`: Next step
- `Tab`: Navigate between form fields

### Technologies Used

- HTML5
- CSS3 (with animations and transitions)
- Vanilla JavaScript
- Local Storage API
- Google Fonts (Roboto)
