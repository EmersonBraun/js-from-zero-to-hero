# Forms & Validation

Forms are how users send data to your application. JavaScript lets you read values, respond to user input in real time, validate data before submission, and give clear feedback — all without a page reload.

## Theory

### Form Elements

The main form elements and how to access them in JavaScript:

| Element | How to get value |
|---------|-----------------|
| `<input type="text">` | `element.value` |
| `<input type="number">` | `Number(element.value)` |
| `<input type="checkbox">` | `element.checked` |
| `<input type="radio">` | `element.checked` on each option |
| `<select>` | `element.value` |
| `<textarea>` | `element.value` |

```js
const nameInput = document.querySelector("#name");
const ageInput  = document.querySelector("#age");
const colorSelect = document.querySelector("#color");

console.log(nameInput.value);   // current text
console.log(Number(ageInput.value));
console.log(colorSelect.value);
```

MDN Reference: [HTMLInputElement](https://developer.mozilla.org/en-US/docs/Web/API/HTMLInputElement) | [HTMLSelectElement](https://developer.mozilla.org/en-US/docs/Web/API/HTMLSelectElement)

### Getting and Setting Form Values

Read values with `.value`, set them the same way:

```js
// Read
const text = input.value.trim(); // .trim() removes surrounding whitespace

// Write (update the UI)
input.value = "default text";
checkbox.checked = true;
select.value = "option2"; // selects matching <option>
```

To read all fields at once, use `FormData`:

```js
const form = document.querySelector("form");
const data = new FormData(form);

data.get("username"); // value of input[name="username"]
Object.fromEntries(data); // convert all fields to a plain object
```

MDN Reference: [FormData](https://developer.mozilla.org/en-US/docs/Web/API/FormData)

### Form Events

| Event | When it fires |
|-------|--------------|
| `input` | Every keystroke / value change |
| `change` | When an element loses focus after its value changed |
| `focus` | When an element gains focus |
| `blur` | When an element loses focus |
| `submit` | When the form is submitted |
| `reset` | When the form is reset |

```js
input.addEventListener("input", (e) => {
  console.log(e.target.value); // live value on every keystroke
});

form.addEventListener("submit", (e) => {
  e.preventDefault(); // stop the page from reloading
  validate(new FormData(form));
});
```

MDN Reference: [HTMLElement: input event](https://developer.mozilla.org/en-US/docs/Web/API/HTMLElement/input_event) | [HTMLFormElement: submit event](https://developer.mozilla.org/en-US/docs/Web/API/HTMLFormElement/submit_event)

### Basic Validation Patterns

**Manual validation** — check values yourself and show error messages:

```js
function validate(fields) {
  const errors = {};

  if (!fields.name || fields.name.trim().length < 2) {
    errors.name = "Name must be at least 2 characters.";
  }

  if (isNaN(fields.age) || fields.age < 0 || fields.age > 120) {
    errors.age = "Age must be a number between 0 and 120.";
  }

  return errors; // empty object means valid
}
```

**Constraint Validation API** — the browser validates using HTML attributes:

```html
<input type="email" required minlength="5" />
```

```js
input.checkValidity();   // true / false
input.validationMessage; // built-in error message
form.checkValidity();    // true if all fields are valid
```

### Regular Expressions Basics

A **regular expression** (regex) is a pattern for matching strings.

```js
// Test if a string matches the pattern
/^\d{4}$/.test("2024");  // true — exactly 4 digits
/^\d{4}$/.test("24");    // false

// Common patterns
const emailPattern = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;
const phonePattern = /^\+?[\d\s\-()]{7,15}$/;
const upperPattern = /[A-Z]/;
const numberPattern = /[0-9]/;
const specialPattern = /[!@#$%^&*]/;
```

MDN Reference: [Regular Expressions](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide/Regular_expressions)

### Showing Validation Feedback

A common pattern is to add/remove CSS classes on the container element:

```js
function showError(input, message) {
  const field = input.parentElement;
  field.classList.add("error");
  field.classList.remove("success");
  field.querySelector(".error-msg").textContent = message;
}

function showSuccess(input) {
  const field = input.parentElement;
  field.classList.remove("error");
  field.classList.add("success");
  field.querySelector(".error-msg").textContent = "";
}
```

### Walkthrough

The generator reads checkbox states and a range input to compose a character set:

```js
const CHARS = {
  lowercase: "abcdefghijklmnopqrstuvwxyz",
  uppercase: "ABCDEFGHIJKLMNOPQRSTUVWXYZ",
  numbers:   "0123456789",
  symbols:   "!@#$%^&*()_+-=[]{}|;:,.<>?",
};

function generatePassword(options) {
  const { length, useLower, useUpper, useNumbers, useSymbols } = options;

  let charset = "";
  if (useLower)   charset += CHARS.lowercase;
  if (useUpper)   charset += CHARS.uppercase;
  if (useNumbers) charset += CHARS.numbers;
  if (useSymbols) charset += CHARS.symbols;

  if (!charset) return ""; // no options selected

  return Array.from({ length }, () =>
    charset[Math.floor(Math.random() * charset.length)]
  ).join("");
}
```

The form listens to `input` events on the length slider to update the display in real time:

```js
lengthSlider.addEventListener("input", () => {
  lengthDisplay.textContent = lengthSlider.value;
});

generateBtn.addEventListener("click", () => {
  const options = {
    length:     Number(lengthSlider.value),
    useLower:   lowercaseCheckbox.checked,
    useUpper:   uppercaseCheckbox.checked,
    useNumbers: numbersCheckbox.checked,
    useSymbols: symbolsCheckbox.checked,
  };
  output.value = generatePassword(options);
});
```

### Walkthrough

Questions are stored as an array of objects:

```js
const questions = [
  {
    question: "What does typeof null return?",
    choices: ["null", "undefined", "object", "string"],
    answer: "object",
  },
  {
    question: "Which method adds an element to the end of an array?",
    choices: ["push", "pop", "shift", "unshift"],
    answer: "push",
  },
];
```

State is tracked in a simple object:

```js
let state = {
  currentIndex: 0,
  score: 0,
  answers: [],
};
```

The `submit` handler reads the checked radio button, checks it against the answer, and advances to the next question:

```js
form.addEventListener("submit", (e) => {
  e.preventDefault();
  const selected = form.querySelector("input[name='choice']:checked");
  if (!selected) return; // nothing chosen

  const answer = selected.value;
  const correct = questions[state.currentIndex].answer;
  const isCorrect = answer === correct;

  state.answers.push({ answer, isCorrect });
  if (isCorrect) state.score++;
  state.currentIndex++;

  if (state.currentIndex < questions.length) {
    renderQuestion();
  } else {
    renderResults();
  }
});
```

## Summary

- Access form values with `.value` (text, number, select, textarea) and `.checked` (checkbox, radio).
- Use `e.preventDefault()` on the `submit` event to handle forms without a page reload.
- The `input` event fires on every keystroke — great for real-time feedback. The `change` event fires when focus leaves.
- `FormData` converts a whole form to a key-value collection with one line.
- Manual validation returns an errors object; show messages to the user and never assume input is safe.
- Regular expressions are powerful for pattern matching (emails, passwords, phone numbers) — test them at [regex101.com](https://regex101.com).
- Always sanitize user input before displaying it back to the page to prevent XSS.
