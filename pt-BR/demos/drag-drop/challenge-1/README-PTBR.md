# Drag and Drop - Challenge 1

> [versão em inglês](README.md)

Uma interface moderna de upload de arquivos com funcionalidade de arrastar e soltar, validação de arquivos e recursos de visualização.

## CLASS

Upload básico de arquivos com arrastar e soltar:
- Upload de arquivos por arrastar e soltar
- Validação de arquivos e limites de tamanho
- Visualização e exibição de informações de arquivos
- Funcionalidade de download
- Visualização modal de arquivos
- Mensagens de status e feedback

## CHALLENGE 01

Implemente um sistema completo de upload de arquivos com arrastar e soltar:

### Requisitos:
- [x] **Interface de Arrastar e Soltar**: Área visual de arrasto com efeitos de hover
- [x] **Validação de Arquivos**: Verificar tamanho, tipo e limites de contagem de arquivos
- [x] **Exibição de Informações**: Mostrar detalhes dos arquivos em layout de grade
- [x] **Visualizações de Arquivos**: Miniaturas para imagens e ícones para documentos
- [x] **Visualização Modal**: Clique para ver conteúdo completo do arquivo no modal
- [x] **Gerenciamento de Arquivos**: Remover arquivos individuais ou limpar todos
- [x] **Funcionalidade de Download**: Baixar todos os arquivos individualmente
- [x] **Mensagens de Status**: Feedback do usuário para todas as ações
- [x] **Design Responsivo**: Funciona em todos os tamanhos de tela

### Funcionalidades:
- **Suporte a Múltiplos Arquivos**: Upload de vários arquivos de uma vez
- **Validação de Tipo de Arquivo**: Imagens, PDFs, documentos e arquivos de texto
- **Limites de Tamanho**: Tamanho máximo de arquivo configurável (padrão 10MB)
- **Feedback Visual**: Efeitos de arrasto e animações de hover
- **Ícones de Arquivo**: Ícones apropriados para diferentes tipos de arquivo
- **Visualização de Texto**: Ler arquivos de texto diretamente no modal
- **Visualização de Imagem**: Visualização de imagem em tamanho completo
- **Tratamento de Erros**: Mensagens de erro claras para arquivos inválidos

### Tipos de Arquivo Suportados:
- **Imagens**: Todos os formatos de imagem (jpg, png, gif, etc.)
- **Documentos**: PDF, DOC, DOCX
- **Arquivos de Texto**: Arquivos TXT com visualização
- **Outros**: Ícone genérico para tipos não suportados

### Controles:
- **Arrastar e Soltar**: Arraste arquivos diretamente para a área de upload
- **Clicar para Navegar**: Clique na área de upload para abrir diálogo de arquivo
- **Remover Arquivos**: Botões de remoção individuais nos itens de arquivo
- **Limpar Tudo**: Remover todos os arquivos carregados
- **Baixar Tudo**: Baixar cada arquivo individualmente
- **Visualizar**: Clique nas visualizações de arquivo para abrir modal
