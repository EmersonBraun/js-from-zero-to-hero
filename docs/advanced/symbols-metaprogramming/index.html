Symbols & Metaprogramming

Metaprogramming is the practice of writing code that operates on other code — inspecting it, modifying its behavior, or intercepting its operations at runtime. JavaScript provides three pillars for this: Symbols (unique keys that avoid collisions), Proxy (intercept fundamental object operations), and Reflect (a clean API for those same operations).

1. What Are Symbols and Why They Exist​

Before Symbols, all object keys were strings. This created problems when multiple libraries tried to add properties to the same object — names could collide silently.

Symbol() creates a guaranteed-unique primitive value. No two symbols are ever equal, even if created with the same description.

const a = Symbol('id');
const b = Symbol('id');
console.log(a === b); // false — always unique
console.log(typeof a); // "symbol"
console.log(a.toString()); // "Symbol(id)"
console.log(a.description); // "id"

Symbols are not enumerable in for...in loops, do not appear in Object.keys(), and are excluded from JSON.stringify(). This makes them ideal for attaching metadata or extension points without polluting public APIs.

MDN Reference: Symbol

2. Creating Symbols: Symbol() vs Symbol.for()​

Symbol() always creates a new, unique symbol.

Symbol.for(key) uses a global symbol registry — it returns the same symbol for the same key string, across realms (iframes, workers).

const s1 = Symbol.for('app.user');
const s2 = Symbol.for('app.user');
console.log(s1 === s2); // true

// Reverse lookup
console.log(Symbol.keyFor(s1)); // "app.user"

// Local symbols have no registry key
const local = Symbol('local');
console.log(Symbol.keyFor(local)); // undefined

Use Symbol.for() when you need cross-realm or cross-module shared symbols. Use Symbol() for private/internal extension points.

3. Symbols as Object Keys​

const ID = Symbol('id');
const ROLE = Symbol('role');

const user = {
  name: 'Alice',
  [ID]: 42,
  [ROLE]: 'admin',
};

console.log(user[ID]); // 42
console.log(Object.keys(user)); // ["name"] — symbols excluded
console.log(Object.getOwnPropertySymbols(user)); // [Symbol(id), Symbol(role)]

// JSON.stringify ignores symbols
console.log(JSON.stringify(user)); // {"name":"Alice"}

This pattern is used by libraries to attach non-enumerable internal state to user objects without risking key collisions.

4. Well-Known Symbols​

JavaScript uses built-in symbols (stored on Symbol.*) to hook into core language behavior. These are called well-known symbols.

Symbol.iterator​

Defines the default iterator for an object. Used by for...of, spread, and destructuring.

class Counter {
  constructor(max) { this.max = max; }

  [Symbol.iterator]() {
    let n = 0, max = this.max;
    return {
      next() {
        return n < max
          ? { value: n++, done: false }
          : { value: undefined, done: true };
      }
    };
  }
}

console.log([...new Counter(4)]); // [0, 1, 2, 3]

Symbol.toPrimitive​

Controls how an object is coerced to a primitive (number, string, or default).

class Temperature {
  constructor(celsius) { this.celsius = celsius; }

  [Symbol.toPrimitive](hint) {
    if (hint === 'number') return this.celsius;
    if (hint === 'string') return `${this.celsius}°C`;
    return this.celsius; // default
  }
}

const temp = new Temperature(22);
console.log(+temp);           // 22  (numeric hint)
console.log(`Temp: ${temp}`); // "Temp: 22°C"  (string hint)
console.log(temp + 0);        // 22  (default hint)

MDN Reference: Symbol.toPrimitive

Symbol.hasInstance​

Controls the behavior of instanceof.

class EvenNumber {
  static [Symbol.hasInstance](value) {
    return typeof value === 'number' && value % 2 === 0;
  }
}

console.log(4 instanceof EvenNumber); // true
console.log(3 instanceof EvenNumber); // false

Symbol.toStringTag​

Customizes the output of Object.prototype.toString().

class Database {
  get [Symbol.toStringTag]() { return 'Database'; }
}

const db = new Database();
console.log(Object.prototype.toString.call(db)); // "[object Database]"

Symbol.species​

Specifies the constructor used when derived objects are created by methods like map, filter, slice. Rarely needed outside of framework/library code.

MDN Reference: Well-known symbols

5. The Proxy Object​

Proxy wraps a target object and intercepts fundamental operations through handler traps. Every operation you can perform on an object has a corresponding trap.

const proxy = new Proxy(target, handler);

The handler is an object whose methods (traps) intercept operations on the target.

MDN Reference: Proxy

get trap​

const handler = {
  get(target, prop, receiver) {
    console.log(`Getting: ${String(prop)}`);
    return Reflect.get(target, prop, receiver);
  }
};

const obj = new Proxy({ x: 1 }, handler);
obj.x; // logs "Getting: x", returns 1

set trap​

const validator = {
  set(target, prop, value, receiver) {
    if (prop === 'age' && (typeof value !== 'number' || value < 0)) {
      throw new TypeError('Age must be a non-negative number');
    }
    return Reflect.set(target, prop, value, receiver);
  }
};

const person = new Proxy({}, validator);
person.age = 25;  // OK
person.age = -1;  // TypeError

has trap​

Intercepts the in operator.

const rangeProxy = new Proxy({}, {
  has(target, prop) {
    const num = Number(prop);
    return num >= 1 && num <= 100;
  }
});

console.log(50 in rangeProxy);  // true
console.log(101 in rangeProxy); // false

deleteProperty trap​

const frozen = new Proxy({ a: 1, b: 2 }, {
  deleteProperty(target, prop) {
    console.warn(`Deletion of "${prop}" was blocked`);
    return false; // prevents deletion
  }
});

apply trap​

Intercepts function calls.

function greet(name) { return `Hello, ${name}!`; }

const tracedGreet = new Proxy(greet, {
  apply(target, thisArg, args) {
    console.log(`Called with args: ${JSON.stringify(args)}`);
    return Reflect.apply(target, thisArg, args);
  }
});

tracedGreet('Alice'); // logs args, returns "Hello, Alice!"

6. The Reflect API​

Reflect provides static methods mirroring every Proxy trap. It serves two purposes:

  1. Forward operations from Proxy traps — always use Reflect instead of operating directly on the target to preserve correct this behavior with inheritance.
  2. Functional alternatives to operators — Reflect.has(obj, key) vs key in obj.
// Instead of:
target[prop] = value;
// Use in traps:
Reflect.set(target, prop, value, receiver);

// Instead of:
delete target[prop];
Reflect.deleteProperty(target, prop);

// Instead of:
new Ctor(...args);
Reflect.construct(Ctor, args);

MDN Reference: Reflect

7. Practical Metaprogramming Patterns​

Validation Proxy​

function createValidated(schema) {
  return new Proxy({}, {
    set(target, prop, value) {
      if (schema[prop] && !schema[prop](value)) {
        throw new TypeError(`Validation failed for "${prop}"`);
      }
      return Reflect.set(target, prop, value);
    }
  });
}

const user = createValidated({
  name: v => typeof v === 'string' && v.length > 0,
  age: v => Number.isInteger(v) && v >= 0 && v <= 150,
});

Logging / Tracing Proxy​

function createLogged(target, label = 'Object') {
  return new Proxy(target, {
    get(t, prop, receiver) {
      const value = Reflect.get(t, prop, receiver);
      if (typeof value === 'function') {
        return function(...args) {
          console.log(`[${label}] ${String(prop)}(${args.map(JSON.stringify).join(', ')})`);
          return value.apply(this, args);
        };
      }
      return value;
    }
  });
}

Reactive Data (Vue-style)​

function reactive(data, onChange) {
  return new Proxy(data, {
    set(target, prop, value, receiver) {
      const old = target[prop];
      const result = Reflect.set(target, prop, value, receiver);
      if (old !== value) onChange(prop, old, value);
      return result;
    }
  });
}

const state = reactive({ count: 0 }, (key, from, to) => {
  console.log(`${key}: ${from} → ${to}`);
});

state.count = 1; // logs "count: 0 → 1"

Summary​

  • Symbols are unique, non-enumerable primitives used as collision-free object keys or to attach non-public metadata.
  • Symbol() creates an always-unique local symbol; Symbol.for(key) registers and retrieves symbols from a global registry.
  • Well-known symbols are the extension hooks for built-in language behaviors: Symbol.iterator (iteration), Symbol.toPrimitive (coercion), Symbol.hasInstance (instanceof), Symbol.toStringTag (type tag), Symbol.species (derived constructor).
  • Proxy wraps any object and intercepts operations via traps (get, set, has, deleteProperty, apply, and more).
  • Always forward to Reflect inside proxy traps to preserve correct prototype chain behavior.
  • Reflect provides a functional API mirroring every proxy trap and every object operation operator.
  • Practical metaprogramming patterns include validation proxies (enforce invariants on assignment), logging proxies (trace all operations), and reactive data (trigger side effects on mutations, as seen in Vue and MobX).
  • These primitives are the foundation of modern JavaScript frameworks — understanding them reveals the machinery behind computed properties, two-way binding, and observable state.
