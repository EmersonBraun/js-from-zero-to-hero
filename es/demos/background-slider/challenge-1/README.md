# Background Slider - Challenge 1

> [pt-br version](README-PTBR.md)

A dynamic background image slider with smooth transitions and interactive controls.

## CLASS

Basic background slider with:
- Multiple background images
- Smooth fade transitions
- Navigation arrows
- Dot indicators
- Auto-play functionality
- Play/pause controls
- Fullscreen mode
- Keyboard navigation
- Touch/swipe support

## CHALLENGE 01

Enhance the basic slider with:

### Requirements:
- [x] **Smooth Transitions**: Implement fade transitions between slides
- [x] **Navigation Controls**: Add previous/next buttons and dot indicators
- [x] **Auto-play**: Automatic slide progression with play/pause toggle
- [x] **Slide Information**: Display current slide number and title
- [x] **Fullscreen Mode**: Toggle fullscreen viewing
- [x] **Keyboard Support**: Arrow keys for navigation, space for play/pause
- [x] **Touch Support**: Swipe gestures for mobile devices
- [x] **Responsive Design**: Works on all screen sizes

### Features:
- **5 Beautiful Background Images**: Mountain landscapes, forests, oceans, sunsets, and deserts
- **Interactive Controls**: Click navigation, keyboard shortcuts, and touch gestures
- **Visual Feedback**: Active dot indicators and slide counter
- **Smooth Animations**: CSS transitions for professional appearance
- **Mobile Optimized**: Touch-friendly interface with swipe support

### Controls:
- **Mouse**: Click arrows, dots, or control buttons
- **Keyboard**: 
  - Arrow Left/Right: Navigate slides
  - Space: Play/pause auto-play
  - F: Toggle fullscreen
- **Touch**: Swipe left/right to navigate
