# Insect Catch Game - Challenge 1

> [pt-br version](README-PTBR.md)

## CLASS

Basic insect catching game with simple mechanics.

### Features:
- Click on insects to catch them
- Score tracking
- Timer countdown
- Game over screen

### Controls:
- **Mouse Click**: Catch insects
- **Start Button**: Begin the game
- **Restart Button**: Restart current game
- **Play Again Button**: Return to main menu

---

## CHALLENGE 01

Enhanced insect catching game with difficulty levels and moving insects.

### New Features:
- **Difficulty Selection**: Choose between Easy, Medium, and Hard modes
- **Insect Selection**: Choose from 4 different insect types
- **Moving Insects**: Insects move around the screen in higher difficulties
- **Dynamic Scoring**: Different points based on difficulty level
- **Enhanced UI**: Better visual feedback and animations
- **High Score System**: Persistent high score storage

### Difficulty Levels:
- **Easy**: 30 seconds, slow insects, 1 point each
- **Medium**: 45 seconds, moving insects, 2 points each  
- **Hard**: 60 seconds, fast moving insects, 3 points each

### Insect Types:
- **Fly**: Basic insect
- **Mosquito**: Common pest
- **Spider**: Eight-legged hunter
- **Roach**: Resilient insect

### Controls:
- **Mouse Click**: Catch insects
- **Difficulty Selection**: Click on difficulty options
- **Insect Selection**: Click on insect type
- **Start Button**: Begin the game
- **Restart Button**: Restart current game
- **Play Again Button**: Return to main menu

### Game Mechanics:
- Insects spawn at random positions
- In Medium/Hard modes, insects move to new positions
- Insects disappear after 3 seconds if not caught
- Score increases based on difficulty level
- High score is saved locally

### Visual Enhancements:
- Smooth animations for insect movement
- Catch effect animations
- Score popup effects
- Hover effects on UI elements
- Responsive design for mobile devices

---

## CHALLENGE 02

Advanced insect catching game with power-ups, boss battles, and multiple game modes.

### New Features:
- **Game Modes**: Story, Endless, and Multiplayer modes
- **Power-ups**: Freeze time, insect magnet, and area bomb
- **Boss Battles**: Special boss insects with health bars
- **Level System**: Progressive difficulty in story mode
- **Achievements**: Unlock achievements for special feats
- **Enhanced Scoring**: Time bonuses and level multipliers

### Game Modes:
- **Story Mode**: Progressive levels with boss battles
- **Endless Mode**: Survive as long as possible
- **Multiplayer Mode**: Local competition with friends

### Power-ups:
- **❄️ Freeze Time (F)**: Temporarily stops insect movement
- **🧲 Insect Magnet (M)**: Attracts nearby insects
- **💣 Area Bomb (B)**: Destroys all insects in area

### Boss Insects:
- Special insects with health bars
- Require multiple hits to defeat
- Drop bonus points and power-ups
- Appear at specific level milestones

### Controls:
- **Mouse Click**: Catch insects
- **F Key**: Activate freeze power-up
- **M Key**: Activate magnet power-up
- **B Key**: Activate bomb power-up
- **All previous controls from Challenge 1**

### Advanced Mechanics:
- Power-up cooldown system
- Boss health tracking
- Level progression
- Achievement system
- Enhanced scoring with multipliers
