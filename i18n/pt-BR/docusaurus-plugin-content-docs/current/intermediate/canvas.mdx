# Canvas API

O elemento Canvas do HTML5 fornece uma poderosa superfície de desenho 2D que você pode controlar inteiramente com JavaScript. De formas simples a animações complexas e até manipulação de pixels, a Canvas API é uma peça fundamental dos gráficos no navegador.

**Referências MDN:**
- [HTMLCanvasElement](https://developer.mozilla.org/en-US/docs/Web/API/HTMLCanvasElement)
- [CanvasRenderingContext2D](https://developer.mozilla.org/en-US/docs/Web/API/CanvasRenderingContext2D)
- [requestAnimationFrame](https://developer.mozilla.org/en-US/docs/Web/API/window/requestAnimationFrame)

---

## Teoria

### Primeiros Passos com Canvas

O elemento `<canvas>` é apenas uma superfície de desenho em branco. Você obtém acesso ao seu contexto de desenho via `getContext('2d')`:

```js
const canvas = document.getElementById('myCanvas');
const ctx = canvas.getContext('2d');
```

O sistema de coordenadas começa no canto superior esquerdo `(0, 0)`, com `x` aumentando para a direita e `y` aumentando para baixo.

---

### Desenhando Retângulos

Retângulos são a forma mais simples no canvas:

```js
// Retângulo preenchido
ctx.fillStyle = 'blue';
ctx.fillRect(x, y, width, height);

// Retângulo com contorno
ctx.strokeStyle = 'red';
ctx.lineWidth = 2;
ctx.strokeRect(x, y, width, height);

// Limpar uma área retangular
ctx.clearRect(x, y, width, height);
```

---

### Caminhos, Linhas e Arcos

A maioria das formas complexas é construída usando caminhos (paths):

```js
ctx.beginPath();
ctx.moveTo(50, 50);       // Mover para o ponto inicial sem desenhar
ctx.lineTo(200, 50);      // Desenhar uma linha até este ponto
ctx.lineTo(200, 150);
ctx.closePath();           // Fechar o caminho de volta ao início
ctx.stroke();              // Renderizar o contorno do caminho

// Círculos e arcos
ctx.beginPath();
ctx.arc(x, y, radius, startAngle, endAngle, anticlockwise);
// Círculo completo: startAngle = 0, endAngle = Math.PI * 2
ctx.fill();
```

---

### Estilos de Preenchimento e Contorno

Você pode usar cores, gradientes e padrões como estilos de preenchimento ou contorno:

```js
// Cor sólida
ctx.fillStyle = '#ff6347';

// Gradiente linear
const gradient = ctx.createLinearGradient(0, 0, 200, 0);
gradient.addColorStop(0, 'red');
gradient.addColorStop(1, 'blue');
ctx.fillStyle = gradient;

// Gradiente radial
const radial = ctx.createRadialGradient(75, 50, 5, 75, 50, 100);
radial.addColorStop(0, 'white');
radial.addColorStop(1, 'black');
ctx.fillStyle = radial;
```

---

### Desenhando Texto

Canvas suporta renderização de texto com controle total de estilo:

```js
ctx.font = '30px Arial';
ctx.fillStyle = 'black';
ctx.textAlign = 'center';    // 'left' | 'right' | 'center' | 'start' | 'end'
ctx.textBaseline = 'middle'; // 'top' | 'middle' | 'bottom' | 'alphabetic'

ctx.fillText('Hello, Canvas!', x, y);
ctx.strokeText('Outlined Text', x, y);

// Medir a largura do texto
const metrics = ctx.measureText('Hello');
console.log(metrics.width);
```

---

### Animação com requestAnimationFrame

`requestAnimationFrame` agenda uma função para executar antes do próximo repaint, permitindo animações suaves a 60fps:

```js
function animate() {
  ctx.clearRect(0, 0, canvas.width, canvas.height); // Limpar frame anterior
  // ... desenhar cena atualizada ...
  requestAnimationFrame(animate); // Agendar próximo frame
}

requestAnimationFrame(animate); // Iniciar o loop
```

---

### Manipulação de Pixels

Você pode ler e escrever pixels individuais usando `ImageData`:

```js
// Obter dados de pixels para todo o canvas
const imageData = ctx.getImageData(0, 0, canvas.width, canvas.height);
const data = imageData.data; // Uint8ClampedArray: [R, G, B, A, R, G, B, A, ...]

// Modificar um pixel em (x, y)
const index = (y * canvas.width + x) * 4;
data[index]     = 255; // Vermelho
data[index + 1] = 0;   // Verde
data[index + 2] = 0;   // Azul
data[index + 3] = 255; // Alpha

// Colocar os dados modificados de volta
ctx.putImageData(imageData, 0, 0);
```

function createAnimator() {
  let frame = 0;
  let running = false;
  const log = [];

  function tick() {
    if (!running) return;
    frame++;
    log.push(frame);
  }

  return {
    start() { running = true; },
    stop() { running = false; },
    tick,
    getFrame() { return frame; },
    getLog() { return log; },
    reset() { frame = 0; log.length = 0; }
  };
}

const animator = createAnimator();

function runAnimation(steps) {
  animator.start();
  for (let i = 0; i < steps; i++) {
    animator.tick();
  }
  animator.stop();
  return animator.getFrame();
}

function wrapText(text, maxWidth, charWidth) {
  // Simple word-wrap based on estimated char width
  const words = text.split(' ');
  const lines = [];
  let currentLine = '';

  for (const word of words) {
    const testLine = currentLine ? currentLine + ' ' + word : word;
    if (testLine.length * charWidth > maxWidth && currentLine) {
      lines.push(currentLine);
      currentLine = word;
    } else {
      currentLine = testLine;
    }
  }
  if (currentLine) lines.push(currentLine);
  return lines;
}

function centerText(text, canvasWidth, charWidth) {
  const textWidth = text.length * charWidth;
  return (canvasWidth - textWidth) / 2;
}

function stackedTextPositions(lines, startY, lineHeight) {
  return lines.map((line, i) => ({ text: line, y: startY + i * lineHeight }));
}

### Projeto 1: Efeito Chuva Matrix

Os clássicos caracteres verdes em cascata de Matrix — construídos inteiramente no canvas usando `requestAnimationFrame`.

**Conceitos-chave:** Colunas no canvas, caracteres aleatórios, sobreposições semi-transparentes para o efeito de trilha, loop com `requestAnimationFrame`.

<iframe

  width="100%"
  height="500"
  style={{border: '1px solid var(--ifm-color-emphasis-300)', borderRadius: '8px'}}
  title="Matrix Rain Effect Demo"
/>

#### Como Funciona

1. Criar um `<canvas>` que preenche a viewport.
2. Dividir a largura do canvas em colunas de `fontSize` pixels cada.
3. Rastrear um array `drops` — um valor por coluna, representando a posição y atual do caractere que cai.
4. Em cada frame:
   - Desenhar um retângulo preto semi-transparente sobre todo o canvas (cria a trilha de fade).
   - Para cada drop, desenhar um caractere aleatório em `(col * fontSize, drop * fontSize)`.
   - Resetar aleatoriamente um drop para `0` quando atingir o final.

```js
const canvas = document.getElementById('canvas');
const ctx = canvas.getContext('2d');
canvas.width = window.innerWidth;
canvas.height = window.innerHeight;

const fontSize = 16;
const columns = Math.floor(canvas.width / fontSize);
const drops = new Array(columns).fill(1);
const chars = 'アイウエオ...ABCDEFGHIJKLMNOPQRSTUVWXYZ0123456789';

function draw() {
  ctx.fillStyle = 'rgba(0, 0, 0, 0.05)';
  ctx.fillRect(0, 0, canvas.width, canvas.height);

  ctx.fillStyle = '#0F0';
  ctx.font = `${fontSize}px monospace`;

  drops.forEach((y, i) => {
    const char = chars[Math.floor(Math.random() * chars.length)];
    ctx.fillText(char, i * fontSize, y * fontSize);
    if (y * fontSize > canvas.height && Math.random() > 0.975) {
      drops[i] = 0;
    }
    drops[i]++;
  });
}

setInterval(draw, 33);
```

#### Desafio 1

Mude a cor do caractere de verde para um gradiente que alterna entre verde e branco dependendo da posição do drop — caracteres próximos ao topo de uma trilha devem ser branco brilhante.

#### Desafio 2

Adicione um modo "freeze": pressionar a barra de espaço pausa e retoma a animação. Use uma flag booleana e `cancelAnimationFrame` para implementar de forma limpa.

### Projeto 2: Ferramenta de Desenho no Canvas

Uma aplicação de desenho à mão livre usando eventos de mouse e caminhos no canvas.

**Conceitos-chave:** Eventos `mousedown`, `mousemove`, `mouseup`, `beginPath`/`moveTo`/`lineTo`, largura de linha e cor dinâmicas.

  width="100%"
  height="500"
  style={{border: '1px solid var(--ifm-color-emphasis-300)', borderRadius: '8px'}}
  title="Canvas Drawing Tool Demo"
/>

#### Como Funciona

1. Rastrear se o botão do mouse está pressionado (`isDrawing`).
2. No `mousedown`: definir `isDrawing = true`, chamar `beginPath()`, `moveTo(x, y)`.
3. No `mousemove`: se estiver desenhando, chamar `lineTo(x, y)` e `stroke()`, depois `moveTo(x, y)`.
4. No `mouseup` / `mouseleave`: definir `isDrawing = false`.

```js
let isDrawing = false;
let lastX = 0, lastY = 0;

canvas.addEventListener('mousedown', (e) => {
  isDrawing = true;
  [lastX, lastY] = [e.offsetX, e.offsetY];
});

canvas.addEventListener('mousemove', (e) => {
  if (!isDrawing) return;
  ctx.beginPath();
  ctx.moveTo(lastX, lastY);
  ctx.lineTo(e.offsetX, e.offsetY);
  ctx.stroke();
  [lastX, lastY] = [e.offsetX, e.offsetY];
});

canvas.addEventListener('mouseup', () => isDrawing = false);
canvas.addEventListener('mouseleave', () => isDrawing = false);
```

#### Desafio 1

Adicione um seletor de cor e um slider de largura de linha que atualizam `ctx.strokeStyle` e `ctx.lineWidth` em tempo real. Permita que os usuários escolham entre caps de linha redondas e quadradas (`ctx.lineCap`).

#### Desafio 2

Implemente uma funcionalidade de **desfazer** usando um array de snapshots `ImageData`. Salve o estado do canvas em cada `mousedown` e restaure o snapshot anterior quando o usuário pressionar `Ctrl+Z`.

### Projeto 3: Aplicativo de Pintura

Uma aplicação de pintura completa combinando formas, paleta de cores, balde de preenchimento e ferramenta de texto.

**Conceitos-chave:** Máquina de estados para seleção de ferramenta, algoritmo flood-fill, `ctx.save()`/`ctx.restore()` para pré-visualizações de ferramenta.

#### Como Funciona

O aplicativo de pintura usa um estado de **ferramenta atual** para determinar o que acontece nos eventos de mouse:

- **Lápis** — desenho à mão livre (igual à ferramenta de desenho acima).
- **Retângulo / Círculo** — no `mousedown`, registrar o ponto inicial. No `mousemove`, limpar uma pré-visualização e desenhar a forma. No `mouseup`, confirmar a forma.
- **Balde de preenchimento** — no clique, executar um algoritmo flood-fill usando `getImageData`/`putImageData`.
- **Texto** — no clique, solicitar texto e renderizá-lo na posição clicada com `fillText`.

```js
let tool = 'pencil';
let startX, startY;
let snapshot; // ImageData taken on mousedown for shape preview

canvas.addEventListener('mousedown', (e) => {
  startX = e.offsetX;
  startY = e.offsetY;
  snapshot = ctx.getImageData(0, 0, canvas.width, canvas.height);
});

canvas.addEventListener('mousemove', (e) => {
  if (tool === 'rectangle') {
    ctx.putImageData(snapshot, 0, 0); // Restaurar antes de desenhar pré-visualização
    ctx.strokeRect(startX, startY, e.offsetX - startX, e.offsetY - startY);
  }
});
```

## Resumo

Neste módulo você aprendeu:

- Como obter e usar um `CanvasRenderingContext2D` via `getContext('2d')`.
- Primitivos de desenho: retângulos, arcos e caminhos arbitrários com linhas e curvas.
- Estilização com cores sólidas, gradientes lineares e radiais.
- Renderização e medição de texto no canvas.
- Criação de animações suaves usando `requestAnimationFrame` e um game loop.
- Leitura e escrita de dados de pixels com `getImageData` e `putImageData`.

A Canvas API é fundamental para jogos no navegador, visualizações de dados, editores de imagem e programação criativa. Os projetos acima — Chuva Matrix, Ferramenta de Desenho e Aplicativo de Pintura — cada um aplica uma fatia diferente dessas capacidades em um contexto real e interativo.
